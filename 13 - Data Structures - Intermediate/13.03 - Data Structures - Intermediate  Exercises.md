### Example 1: Building a Grade Book System with Multiple Data Structures
**Problem:** Create a gradebook system that uses tuples for student records (name, id), a dictionary to store grades, and calculates class statistics. Each student can have multiple grades stored in a list. Implement functions to add grades, calculate averages, and find the top performer.

**Detailed Solution:**

**Step 1: Understand the data structure design**
- Tuples: Immutable student identifiers (name, id)
- Dictionary: Maps student tuples to their grade lists
- Lists: Store multiple grades per student
- Need to handle: adding grades, calculating averages, finding top student

**Step 2: Plan the structure**
```python
gradebook = {
    ("Alice", "001"): [85, 90, 92],
    ("Bob", "002"): [78, 85, 88]
}
```

**Step 3: Design functions for each operation**
- add_grade(): Add grade to student's list
- calculate_average(): Get student's average
- get_top_student(): Find highest average

**Complete Solution:**
```python
def create_gradebook():
    """Initialize empty gradebook."""
    return {}


def add_student(gradebook, name, student_id):
    """Add new student to gradebook."""
    student_key = (name, student_id)
    if student_key not in gradebook:
        gradebook[student_key] = []
        print(f"✓ Added student: {name} (ID: {student_id})")
        return True
    else:
        print(f"✗ Student {name} already exists")
        return False


def add_grade(gradebook, name, student_id, grade):
    """Add grade for a student."""
    student_key = (name, student_id)
    
    if student_key in gradebook:
        if 0 <= grade <= 100:
            gradebook[student_key].append(grade)
            print(f"✓ Added grade {grade} for {name}")
            return True
        else:
            print(f"✗ Invalid grade: {grade} (must be 0-100)")
            return False
    else:
        print(f"✗ Student not found: {name}")
        return False


def calculate_average(grades):
    """Calculate average of grades."""
    if not grades:
        return 0
    return sum(grades) / len(grades)


def get_student_average(gradebook, name, student_id):
    """Get specific student's average."""
    student_key = (name, student_id)
    
    if student_key in gradebook:
        grades = gradebook[student_key]
        avg = calculate_average(grades)
        return avg
    return None


def display_gradebook(gradebook):
    """Display all students and their grades."""
    print("\n" + "=" * 60)
    print("GRADEBOOK")
    print("=" * 60)
    
    if not gradebook:
        print("No students in gradebook")
        return
    
    for (name, student_id), grades in gradebook.items():
        avg = calculate_average(grades)
        print(f"\n{name} (ID: {student_id})")
        print(f"  Grades: {grades}")
        print(f"  Average: {avg:.1f}")
    
    print("\n" + "=" * 60)


def get_top_student(gradebook):
    """Find student with highest average."""
    if not gradebook:
        return None
    
    top_student = None
    top_average = -1
    
    for student, grades in gradebook.items():
        avg = calculate_average(grades)
        if avg > top_average:
            top_average = avg
            top_student = student
    
    return top_student, top_average


def get_class_statistics(gradebook):
    """Calculate class-wide statistics."""
    if not gradebook:
        return None
    
    all_averages = []
    for grades in gradebook.values():
        if grades:
            all_averages.append(calculate_average(grades))
    
    if not all_averages:
        return None
    
    stats = {
        'class_average': sum(all_averages) / len(all_averages),
        'highest_average': max(all_averages),
        'lowest_average': min(all_averages),
        'num_students': len(gradebook)
    }
    
    return stats
```

### Example 2: Set Operations for Data Analysis
**Problem:** Given two lists of user IDs (active users and premium users), use sets to find: users who are active but not premium, premium users who are inactive, and users who are both active and premium. Also track unique visitors and identify returning visitors.

**Detailed Solution:**

**Step 1: Understand set operations needed**
- Union (|): All users
- Intersection (&): Both active AND premium
- Difference (-): In one set but not the other
- Membership testing: Fast lookup

**Step 2: Plan the analysis**
- Convert lists to sets for fast operations
- Use set operations to categorize users
- Track visitors to identify returners

**Complete Solution:**
```python
def analyze_users(active_users, premium_users):
    """Analyze user data using set operations."""
    
    # Convert to sets
    active_set = set(active_users)
    premium_set = set(premium_users)
    
    # Perform set operations
    both = active_set & premium_set  # Intersection
    active_only = active_set - premium_set  # Difference
    premium_only = premium_set - active_set  # Difference
    all_users = active_set | premium_set  # Union
    
    analysis = {
        'total_users': len(all_users),
        'active_users': len(active_set),
        'premium_users': len(premium_set),
        'active_premium': list(both),
        'active_not_premium': list(active_only),
        'premium_not_active': list(premium_only)
    }
    
    return analysis


def display_analysis(analysis):
    """Display user analysis results."""
    print("=" * 60)
    print("USER ANALYSIS REPORT")
    print("=" * 60)
    
    print(f"\nTotal Unique Users: {analysis['total_users']}")
    print(f"Active Users: {analysis['active_users']}")
    print(f"Premium Users: {analysis['premium_users']}")
    
    print(f"\n--- Active AND Premium ({len(analysis['active_premium'])}) ---")
    for user in sorted(analysis['active_premium']):
        print(f"  • {user}")
    
    print(f"\n--- Active but NOT Premium ({len(analysis['active_not_premium'])}) ---")
    for user in sorted(analysis['active_not_premium']):
        print(f"  • {user}")
    
    print(f"\n--- Premium but NOT Active ({len(analysis['premium_not_active'])}) ---")
    for user in sorted(analysis['premium_not_active']):
        print(f"  • {user}")
    
    print("\n" + "=" * 60)


class VisitorTracker:
    """Track unique and returning visitors."""
    
    def __init__(self):
        self.all_visitors = set()
        self.returning_visitors = set()
    
    def visit(self, visitor_id):
        """Record a visitor."""
        if visitor_id in self.all_visitors:
            # Returning visitor
            self.returning_visitors.add(visitor_id)
            return "returning"
        else:
            # New visitor
            self.all_visitors.add(visitor_id)
            return "new"
    
    def get_stats(self):
        """Get visitor statistics."""
        return {
            'total_unique': len(self.all_visitors),
            'returning': len(self.returning_visitors),
            'new_only': len(self.all_visitors) - len(self.returning_visitors)
        }
```

### Example 3: Nested Dictionary for Restaurant Menu System

```python
def find_items_by_price_range(menu, min_price, max_price):
    """Find all items within price range."""
    results = []
    
    for category, items in menu.items():
        for item_name, details in items.items():
            price = details['price']
            if min_price <= price <= max_price:
                results.append({
                    'category': category,
                    'name': item_name,
                    'price': price,
                    'description': details['description']
                })
    
    return results


def calculate_order_total(menu, order):
    """
    Calculate total for an order.
    order format: {'item_name': quantity, ...}
    """
    total = 0
    items_found = []
    items_not_found = []
    
    for item_name, quantity in order.items():
        found = False
        
        # Search through all categories
        for category, items in menu.items():
            if item_name in items:
                price = items[item_name]['price']
                subtotal = price * quantity
                total += subtotal
                items_found.append({
                    'name': item_name,
                    'quantity': quantity,
                    'price': price,
                    'subtotal': subtotal
                })
                found = True
                break
        
        if not found:
            items_not_found.append(item_name)
    
    return total, items_found, items_not_found


def display_order(items_found, items_not_found, total):
    """Display order summary."""
    print("\n" + "=" * 60)

    print("=" * 60)
    
    if items_not_found:
        print("\n⚠ Items not found:")
        for item in items_not_found:
            print(f"  • {item}")
    
    if items_found:
        print("\nItems:")
        for item in items_found:
            print(f"  {item['name']} x{item['quantity']}")
            print(f"    ${item['price']:.2f} each = ${item['subtotal']:.2f}")
        
        print(f"\nTOTAL: ${total:.2f}")
    
    print("=" * 60)
```

## Tips for Solving These Problems

### Choosing the Right Data Structure

**Use Tuples When:**
- Data shouldn't change (coordinates, RGB colors, dates)
- Need hashable type for dict keys
- Returning multiple values from function
- Memory efficiency matters

**Use Sets When:**
- Need unique values only
- Checking membership frequently
- Mathematical set operations
- Removing duplicates

**Use Dictionaries When:**
- Lookup by meaningful key
- Counting/frequency analysis
- Key-value relationships
- JSON-like structured data

### Common Patterns

**Pattern 1: Tuple as Dictionary Key**
```python
locations = {
    (0, 0): "Origin",
    (1, 2): "Point A",
    (3, 4): "Point B"
}
```

**Pattern 2: Set for Deduplication**
```python
items = [1, 2, 2, 3, 3, 3]
unique = list(set(items))
```

**Pattern 3: Dictionary for Counting**
```python
counts = {}
for item in items:
    counts[item] = counts.get(item, 0) + 1
```

**Pattern 4: Nested Structures**
```python
data = {
    "category1": {
        "item1": [val1, val2],
        "item2": [val3, val4]
    }
}
```

### Set Operations Quick Reference
```python
a = {1, 2, 3}
b = {3, 4, 5}

a | b  # Union: {1, 2, 3, 4, 5}
a & b  # Intersection: {3}
a - b  # Difference: {1, 2}
a ^ b  # Symmetric difference: {1, 2, 4, 5}
```

### Dictionary Methods
```python
d = {"a": 1, "b": 2}

d.keys()     # Get all keys
d.values()   # Get all values
d.items()    # Get key-value pairs
d.get(key, default)  # Safe access
d.pop(key)   # Remove and return
```

### Common Mistakes to Avoid

**Mistake 1: Single-item tuple without comma**
```python
# WRONG
t = (42)    # This is just an int!

# RIGHT
t = (42,)   # This is a tuple
```

**Mistake 2: Using {} for empty set**
```python
# WRONG
s = {}      # This is a dict!

# RIGHT
s = set()   # This is a set
```

**Mistake 3: Modifying dict while iterating**
```python
# WRONG
for key in dict:
    del dict[key]  # Error!

# RIGHT
for key in list(dict.keys()):
    del dict[key]
```

**Mistake 4: Using mutable type as dict key**
```python
# WRONG
d = {[1,2]: "value"}  # Lists can't be keys!

# RIGHT
d = {(1,2): "value"}  # Tuples can be keys
```
