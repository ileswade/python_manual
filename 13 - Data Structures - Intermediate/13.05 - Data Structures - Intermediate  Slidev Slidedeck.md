# Tuples: Immutable Collections 📦

**Tuples** are like lists, but you can't change them after creation. They're perfect for data that should never change!

<v-clicks>

### Creating Tuples

```python
# Using parentheses
coordinates = (10, 20)
colors = ("red", "green", "blue")

# Parentheses optional (but recommended for clarity)
point = 5, 3
name_age = "Alice", 25

# Empty tuple
empty = ()

# Single item tuple (note the comma!)
single = (42,)  # Without comma, it's just parentheses
```

**Key difference from lists:** Use `()` instead of `[]`, and they're immutable!

</v-clicks>

---

# Tuple Characteristics 📏

<v-clicks>

### Accessing Tuple Elements (Like Lists)

```python
coordinates = (10, 20, 30)

print(coordinates[0])   # 10
print(coordinates[1])   # 20
print(coordinates[-1])  # 30 (last element)
```

### Immutable - Cannot Change

```python
coordinates = (10, 20, 30)

# ❌ This will cause an error!
coordinates[0] = 15  # TypeError: 'tuple' object does not support item assignment

# ✅ But you can create a new tuple
new_coordinates = (15, 20, 30)
```

### Can Iterate Like Lists

```python
colors = ("red", "green", "blue")

for color in colors:
    print(color)
```

</v-clicks>

# When to Use Tuples vs Lists 🤔

<div class="grid grid-cols-2 gap-6">

<div>

<v-click>

### Use Tuples When:
✅ **Data shouldn't change** - coordinates, RGB colors
✅ **Related data** - (name, age), (x, y, z)
✅ **Function returns** - multiple values
✅ **Dictionary keys** - tuples can be keys
✅ **Configuration** - settings that don't change

```python
# Coordinates don't change
point = (100, 200)

# RGB color values
red = (255, 0, 0)

# Person info
student = ("Alice", 20, "CS")
```

</v-click>

</div>

<div>

<v-click>

### Use Lists When:
✅ **Data will change** - adding/removing items
✅ **Unknown size** - growing collections
✅ **Need sorting** - lists have sort methods
✅ **Homogeneous data** - all same type
✅ **Processing sequences** - filtering, mapping

```python
# Shopping cart changes
cart = ["apples", "bread"]
cart.append("milk")

# Scores that get added
scores = [85, 92, 78]
scores.append(91)
```

</v-click>

cities = [

# Tuple Unpacking: Multiple Assignment ✨

**Tuple unpacking** lets you assign multiple variables at once:

<v-clicks>

### Basic Unpacking

```python
point = (10, 20)
x, y = point  # Unpacks tuple into two variables

print(x)  # 10
print(y)  # 20

# Works with any tuple
person = ("Alice", 25, "Engineer")
name, age, job = person
```

### Function Returns

```python
def get_name_age():
    name = input("Enter name: ")
    age = int(input("Enter age: "))
    return name, age  # Returns a tuple

# Unpack the returned tuple
student_name, student_age = get_name_age()
print(f"{student_name} is {student_age} years old")
```

### Swapping Variables

```python
a = 10
b = 20

# Swap values elegantly
a, b = b, a

print(a)  # 20
print(b)  # 10
```

# Sets: Collections of Unique Elements 🎯

**Sets** store unique elements - no duplicates allowed! They're perfect for membership testing and removing duplicates.

<v-clicks>

### Creating Sets

```python
# Using curly braces
fruits = {"apple", "banana", "orange"}

# Using set() function
numbers = set([1, 2, 3, 4, 5])

# From a string (unique characters)
letters = set("hello")  # {'h', 'e', 'l', 'o'}

# Empty set (must use set(), not {})
empty_set = set()
```

### Automatic Duplicate Removal

```python
# Duplicates are automatically removed
numbers = {1, 2, 2, 3, 3, 3, 4}
print(numbers)  # {1, 2, 3, 4}

# Convert list to set to remove duplicates
grades = [85, 90, 85, 78, 90, 92, 78]
unique_grades = set(grades)
print(unique_grades)  # {78, 85, 90, 92}
```

</v-clicks>

---

# Set Operations: Mathematical Power 🧮

<v-clicks>

### Adding and Removing Elements

```python
fruits = {"apple", "banana"}

# Add single element
fruits.add("orange")
print(fruits)  # {'apple', 'banana', 'orange'}

# Add multiple elements
fruits.update(["grape", "kiwi"])

# Remove element
fruits.remove("banana")  # Error if not found
fruits.discard("mango")  # No error if not found
```

### Membership Testing (Very Fast!)

```python
large_dataset = set(range(1000000))  # Million numbers

# This is very fast with sets!
if 500000 in large_dataset:
    print("Found it!")

# Compare with list (much slower)
large_list = list(range(1000000))
if 500000 in large_list:  # Much slower for large data
    print("Found it!")
```

</v-clicks>

# Set Mathematical Operations 📊

<v-clicks>

```python
students_math = {"Alice", "Bob", "Charlie", "Diana"}
students_science = {"Bob", "Diana", "Eve", "Frank"}

# Union - all students in either class
all_students = students_math | students_science
# or: all_students = students_math.union(students_science)
print(all_students)  # {'Alice', 'Bob', 'Charlie', 'Diana', 'Eve', 'Frank'}

# Intersection - students in both classes
both_classes = students_math & students_science
# or: both_classes = students_math.intersection(students_science)
print(both_classes)  # {'Bob', 'Diana'}

# Difference - students only in math
math_only = students_math - students_science
# or: math_only = students_math.difference(students_science)
print(math_only)  # {'Alice', 'Charlie'}

# Symmetric difference - students in exactly one class
one_class_only = students_math ^ students_science
print(one_class_only)  # {'Alice', 'Charlie', 'Eve', 'Frank'}
```

</v-clicks>

# Practical Set Applications 🌟

<v-clicks>

### 1. Finding Common Elements

```python
def find_common_interests(person1_interests, person2_interests):
    """Find interests shared by two people."""
    set1 = set(person1_interests)
    set2 = set(person2_interests)
    return set1 & set2

alice_interests = ["reading", "hiking", "cooking", "gaming"]
bob_interests = ["gaming", "movies", "cooking", "sports"]

common = find_common_interests(alice_interests, bob_interests)
print(f"Alice and Bob both like: {common}")  # {'gaming', 'cooking'}
```

### 2. Removing Duplicates from Data

```python
def clean_email_list(email_list):
    """Remove duplicate emails and return sorted list."""
    unique_emails = set(email_list)
    return sorted(list(unique_emails))

emails = [
    "alice@test.com", "bob@test.com", "alice@test.com",
    "charlie@test.com", "bob@test.com", "diana@test.com"
]

clean_emails = clean_email_list(emails)
print(clean_emails)  # ['alice@test.com', 'bob@test.com', 'charlie@test.com', 'diana@test.com']
```

# Dictionaries: Key-Value Powerhouses 🗂️

**Dictionaries** store data as key-value pairs. They're like real dictionaries where you look up a word (key) to get its definition (value).

<v-clicks>

### Creating Dictionaries

```python
# Using curly braces with key-value pairs
student = {
    "name": "Alice",
    "age": 20,
    "major": "Computer Science",
    "gpa": 3.8
}

# Using dict() constructor
colors = dict(red="#FF0000", green="#00FF00", blue="#0000FF")

# Empty dictionary
empty_dict = {}
# or: empty_dict = dict()
```

### Accessing Values

```python
student = {"name": "Alice", "age": 20, "major": "CS"}

# Access by key
print(student["name"])    # Alice
print(student["age"])     # 20

# Safe access with get() - returns None if key doesn't exist
print(student.get("gpa"))        # None
print(student.get("gpa", 0.0))   # 0.0 (default value)
```

</v-clicks>

---

# Dictionary Operations 🔧

<v-clicks>

### Adding and Modifying

```python
student = {"name": "Alice", "age": 20}

# Add new key-value pair
student["major"] = "Computer Science"
student["gpa"] = 3.8

# Modify existing value
student["age"] = 21

print(student)
# {'name': 'Alice', 'age': 21, 'major': 'Computer Science', 'gpa': 3.8}
```

### Removing Elements

```python
student = {"name": "Alice", "age": 20, "major": "CS", "gpa": 3.8}

# Remove by key
del student["gpa"]

# Remove and return value
major = student.pop("major")  # Returns "CS"

# Remove and return last item (Python 3.7+)
last_item = student.popitem()

print(student)  # {'name': 'Alice', 'age': 20}
```

</v-clicks>

---

# Dictionary Iteration 🔄

<v-clicks>

```python
student = {"name": "Alice", "age": 20, "major": "CS", "gpa": 3.8}

# Iterate over keys (default)
for key in student:
    print(f"{key}: {student[key]}")

# Explicitly iterate over keys
for key in student.keys():
    print(key)

# Iterate over values
for value in student.values():
    print(value)

# Iterate over key-value pairs (most common!)
for key, value in student.items():
    print(f"{key}: {value}")
```

**Output:**
```
name: Alice
age: 20
major: CS
gpa: 3.8
```

</v-clicks>

# Dictionary Methods and Operations 🛠️

<v-clicks>

```python
student = {"name": "Alice", "age": 20, "major": "CS"}

# Check if key exists
if "name" in student:
    print(f"Student name: {student['name']}")

if "gpa" not in student:
    print("GPA not recorded")

# Get all keys, values, or items
keys = list(student.keys())      # ['name', 'age', 'major']
values = list(student.values())  # ['Alice', 20, 'CS']
items = list(student.items())    # [('name', 'Alice'), ('age', 20), ('major', 'CS')]

# Update with another dictionary
additional_info = {"gpa": 3.8, "year": "sophomore"}
student.update(additional_info)

# Clear all items
student.clear()  # {}

# Copy dictionary
original = {"a": 1, "b": 2}
copy_dict = original.copy()
```

# Practical Dictionary Examples 🌟

<v-clicks>

### 1. Student Grade Book

```python
# Grade book with student names as keys
gradebook = {
    "Alice": [85, 90, 88, 92],
    "Bob": [78, 85, 80, 87],
    "Charlie": [92, 95, 89, 94],
    "Diana": [88, 91, 86, 90]
}

def calculate_average(grades):
    return sum(grades) / len(grades)

# Calculate and display averages
for student, grades in gradebook.items():
    average = calculate_average(grades)
    print(f"{student}: {average:.1f}")
```

### 2. Word Frequency Counter

```python
def count_words(text):
    """Count frequency of each word in text."""
    words = text.lower().split()
    word_count = {}

    for word in words:
        if word in word_count:
            word_count[word] += 1
        else:
            word_count[word] = 1

    return word_count

text = "the quick brown fox jumps over the lazy dog the fox is quick"
frequencies = count_words(text)
print(frequencies)
# {'the': 3, 'quick': 2, 'brown': 1, 'fox': 2, 'jumps': 1, ...}
```

# Advanced Dictionary Techniques 🚀

<v-clicks>

### Dictionary Comprehensions

```python
# Create dictionary with comprehension
squares = {x: x**2 for x in range(1, 6)}
print(squares)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Filter while creating
even_squares = {x: x**2 for x in range(1, 11) if x % 2 == 0}
print(even_squares)  # {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}

# Transform existing dictionary
scores = {"Alice": 85, "Bob": 92, "Charlie": 78}
letter_grades = {name: "A" if score >= 90 else "B" if score >= 80 else "C"
                for name, score in scores.items()}
print(letter_grades)  # {'Alice': 'B', 'Bob': 'A', 'Charlie': 'C'}
```

### Nested Dictionaries

```python
students = {
    "Alice": {
        "age": 20,
        "courses": ["Math", "Physics", "CS"],
        "grades": {"Math": 90, "Physics": 85, "CS": 95}
    },
    "Bob": {
        "age": 19,
        "courses": ["Math", "Chemistry", "Biology"],
        "grades": {"Math": 88, "Chemistry": 92, "Biology": 87}
    }
}

# Access nested data
print(students["Alice"]["grades"]["CS"])  # 95
```

# Choosing the Right Data Structure 🤔

<div class="grid grid-cols-2 gap-4 text-sm">

<div>

<v-click>

### Lists `[1, 2, 3]`
✅ **Ordered collection**
✅ **Allows duplicates**
✅ **Mutable (changeable)**
✅ **Integer indexing**
✅ **When:** Sequential data, changing size

</v-click>

<v-click>

### Tuples `(1, 2, 3)`
✅ **Ordered collection**
✅ **Allows duplicates**
✅ **Immutable (unchangeable)**
✅ **Integer indexing**
✅ **When:** Fixed data, coordinates, function returns

</v-click>

</div>

<div>

<v-click>

### Sets `{1, 2, 3}`
✅ **Unordered collection**
✅ **No duplicates**
✅ **Mutable**
✅ **No indexing**
✅ **When:** Unique items, fast membership testing

</v-click>

<v-click>

### Dictionaries `{"a": 1}`
✅ **Ordered (Python 3.7+)**
✅ **Unique keys**
✅ **Mutable**
✅ **Key-based access**
✅ **When:** Key-value relationships, lookups

</v-click>

# Real-World Application: Student Management System 🎓

<v-clicks>

```python
# Student management system using all data structures
class StudentManager:
    def __init__(self):
        # Dictionary: student_id -> student info
        self.students = {}
        # Set: all unique courses offered
        self.available_courses = set()
        # List: enrollment history (chronological)
        self.enrollment_history = []

    def add_student(self, student_id, name, age):
        """Add a new student."""
        # Tuple for immutable student basic info
        basic_info = (name, age)
        self.students[student_id] = {
            "info": basic_info,
            "courses": set(),  # Set for unique courses
            "grades": {}       # Dict for course -> grade mapping
        }
        print(f"Added student: {name}")

    def add_course(self, course_name):
        """Add a course to available courses."""
        self.available_courses.add(course_name)
        print(f"Added course: {course_name}")

    def enroll_student(self, student_id, course_name):
        """Enroll student in a course."""
        if student_id not in self.students:
            print("Student not found!")
            return

        if course_name not in self.available_courses:
            print("Course not available!")
            return

        # Add to student's courses (set prevents duplicates)
        self.students[student_id]["courses"].add(course_name)

        # Record in enrollment history (list maintains order)
        enrollment_record = (student_id, course_name, "enrolled")
        self.enrollment_history.append(enrollment_record)

        name = self.students[student_id]["info"][0]  # Tuple unpacking
        print(f"Enrolled {name} in {course_name}")
```

# Student Management System (continued) 📚

<v-clicks>

```python
    def add_grade(self, student_id, course_name, grade):
        """Add a grade for a student in a course."""
        if student_id not in self.students:
            print("Student not found!")
            return

        if course_name not in self.students[student_id]["courses"]:
            print("Student not enrolled in this course!")
            return

        # Add grade to dictionary
        self.students[student_id]["grades"][course_name] = grade
        name = self.students[student_id]["info"][0]
        print(f"Added grade {grade} for {name} in {course_name}")

    def get_student_info(self, student_id):
        """Get complete student information."""
        if student_id not in self.students:
            return None

        student = self.students[student_id]
        name, age = student["info"]  # Tuple unpacking

        return {
            "name": name,
            "age": age,
            "courses": list(student["courses"]),  # Convert set to list
            "grades": student["grades"].copy(),   # Copy dict
            "gpa": self.calculate_gpa(student_id)
        }

    def calculate_gpa(self, student_id):
        """Calculate student's GPA."""
        if student_id not in self.students:
            return 0.0

        grades = self.students[student_id]["grades"]
        if not grades:
            return 0.0

        return sum(grades.values()) / len(grades)
```
