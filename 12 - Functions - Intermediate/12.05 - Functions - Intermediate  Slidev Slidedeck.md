# Named Arguments (Keyword Arguments) 🏷️

You can call functions by naming the parameters instead of relying on order:

<v-clicks>

### Normal Positional Arguments

```python
def create_user(name, age, email, city):
    return f"{name}, {age}, from {city}, email: {email}"

# Must remember the exact order!
user = create_user("Alice", 25, "alice@email.com", "Toronto")
```

### Named Arguments (Keywords)

```python
def create_user(name, age, email, city):
    return f"{name}, {age}, from {city}, email: {email}"

# Can specify by name - any order!
user = create_user(
    name="Alice",
    city="Toronto",
    age=25,
    email="alice@email.com"
)
```

Same result, but more readable and flexible!

</v-clicks>

---

# Benefits of Named Arguments ✅

<v-clicks>

### 1. Self-Documenting Code

```python
# Hard to understand
result = calculate_payment(1000, 0.05, 12, True)

# Clear and readable
result = calculate_payment(
    principal=1000,
    interest_rate=0.05,
    months=12,
    compound_monthly=True
)
```

### 2. Order Independence

```python
def send_email(to, subject, body, from_address):
    print(f"To: {to}")
    print(f"From: {from_address}")
    print(f"Subject: {subject}")
    print(f"Body: {body}")

# These calls are equivalent
send_email("alice@test.com", "Hello", "How are you?", "me@test.com")
send_email(subject="Hello", to="alice@test.com",
          body="How are you?", from_address="me@test.com")
```

# Default Parameters: Optional Arguments ⚙️

**Default parameters** have preset values and become optional when calling the function:

<v-clicks>

### Basic Default Parameters

```python
def greet(name, greeting="Hello", punctuation="!"):
    return f"{greeting}, {name}{punctuation}"

# Different ways to call
print(greet("Alice"))                    # Hello, Alice!
print(greet("Bob", "Hi"))               # Hi, Bob!
print(greet("Charlie", "Hey", "."))     # Hey, Charlie.
```

### Practical Example: Database Connection

```python
def connect_to_database(host, port=5432, username="admin",
                       password="", timeout=30):
    print(f"Connecting to {host}:{port}")
    print(f"Username: {username}")
    print(f"Timeout: {timeout} seconds")
    return "Connected!"

# Use defaults
connect_to_database("localhost")

# Override some defaults
connect_to_database("server.com", port=3306, username="user123")
```

</v-clicks>

---

# Default Parameter Rules 📏

<v-clicks>

### Rule 1: Defaults Come After Required Parameters

```python
# ✅ Correct
def process_data(data, format="json", validate=True):
    pass

# ❌ Wrong - required parameter after default
def bad_function(format="json", data, validate=True):
    pass
```

### Rule 2: Mutable Defaults Can Be Dangerous

```python
# ❌ Dangerous - shared mutable default!
def add_item(item, items=[]):
    items.append(item)
    return items

list1 = add_item("apple")      # ['apple']
list2 = add_item("banana")     # ['apple', 'banana'] - Oops!

# ✅ Safe pattern
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

</v-clicks>

# Advanced Recursion: The Fibonacci Sequence 🌀

The **Fibonacci sequence** is perfect for exploring advanced recursion: 0, 1, 1, 2, 3, 5, 8, 13, 21...

<v-clicks>

### Mathematical Definition
- F(0) = 0
- F(1) = 1
- F(n) = F(n-1) + F(n-2) for n > 1

### Basic Recursive Implementation

```python
def fibonacci(n):
    # Base cases
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        # Recursive case
        return fibonacci(n - 1) + fibonacci(n - 2)

# Test it
for i in range(8):
    print(f"F({i}) = {fibonacci(i)}")
```

**Output:** 0, 1, 1, 2, 3, 5, 8, 13

</v-clicks>

---

# Fibonacci Call Tree: Understanding Recursion 🌳

<v-clicks>

**What happens when we call `fibonacci(4)`?**

```
fibonacci(4)
├── fibonacci(3)
│   ├── fibonacci(2)
│   │   ├── fibonacci(1) → 1
│   │   └── fibonacci(0) → 0
│   │   └── returns 1
│   └── fibonacci(1) → 1
│   └── returns 2
└── fibonacci(2)
    ├── fibonacci(1) → 1
    └── fibonacci(0) → 0
    └── returns 1
└── returns 3
```

**Notice:** `fibonacci(2)` is calculated twice! This is inefficient.

As numbers get larger, the redundant calculations grow exponentially.

</v-clicks>

---

# Optimizing Recursion: Memoization 🧠

**Memoization** stores results to avoid recalculating the same values:

<v-clicks>

```python
# Global cache for storing results
fib_cache = {}

def fibonacci_memo(n):
    # Check if we already calculated this
    if n in fib_cache:
        return fib_cache[n]

    # Base cases
    if n == 0:
        result = 0
    elif n == 1:
        result = 1
    else:
        # Recursive case
        result = fibonacci_memo(n - 1) + fibonacci_memo(n - 2)

    # Store result for future use
    fib_cache[n] = result
    return result

# Much faster for larger numbers!
print(fibonacci_memo(10))  # 55
print(fibonacci_memo(20))  # 6765
```

</v-clicks>

---

# Performance Comparison 📊

<v-clicks>

Let's see the dramatic difference:

```python
import time

def time_function(func, n):
    start = time.time()
    result = func(n)
    end = time.time()
    return result, end - start

# Test both versions
n = 30

# Basic recursion (slow!)
basic_result, basic_time = time_function(fibonacci, n)
print(f"Basic: {basic_result} in {basic_time:.4f} seconds")

# Memoized recursion (fast!)
memo_result, memo_time = time_function(fibonacci_memo, n)
print(f"Memo: {memo_result} in {memo_time:.4f} seconds")

# The memoized version is hundreds of times faster!
```

**For `fibonacci(35)`:**
- Basic version: ~5 seconds
- Memoized version: ~0.001 seconds

</v-clicks>

# Using Default Parameters with Memoization 🔧

<v-clicks>

We can make the cache part of the function:

```python
def fibonacci_advanced(n, cache=None):
    # Initialize cache if not provided
    if cache is None:
        cache = {0: 0, 1: 1}

    # Return cached result if available
    if n in cache:
        return cache[n]

    # Calculate and cache result
    cache[n] = fibonacci_advanced(n-1, cache) + fibonacci_advanced(n-2, cache)
    return cache[n]

# Clean interface - cache is hidden
print(fibonacci_advanced(10))  # 55
print(fibonacci_advanced(50))  # Works for much larger numbers!
```

**Benefits:**
- Clean interface (user doesn't see cache)
- Each call gets its own cache
- No global variables

</v-clicks>

# Function Documentation: Docstrings 📝

**Docstrings** are the professional way to document functions:

<v-clicks>

```python
def calculate_compound_interest(principal, rate, time, compounds_per_year=1):
    """
    Calculate compound interest on an investment.

    Args:
        principal (float): Initial amount invested
        rate (float): Annual interest rate (as decimal, e.g., 0.05 for 5%)
        time (float): Time period in years
        compounds_per_year (int): How many times interest compounds per year

    Returns:
        tuple: (final_amount, total_interest_earned)

    Example:
        >>> amount, interest = calculate_compound_interest(1000, 0.05, 2, 12)
        >>> print(f"Final amount: ${amount:.2f}")
        Final amount: $1104.89
    """
    amount = principal * (1 + rate/compounds_per_year) ** (compounds_per_year * time)
    interest = amount - principal
    return amount, interest
```

</v-clicks>

# Docstring Best Practices 📋

<v-clicks>

### 1. Use Triple Quotes

```python
def my_function():
```

### 2. Include All Important Information

```python
def process_payment(amount, payment_method="credit", discount=0.0):
    """
    Process a customer payment with optional discount.

    This function handles payment processing for various payment methods
    and applies discounts when provided.

    Args:
        amount (float): Payment amount in dollars
        payment_method (str): Payment type ("credit", "debit", "cash")
        discount (float): Discount percentage (0.0 to 1.0)

    Returns:
        dict: Payment confirmation with transaction details

    Raises:
        ValueError: If amount is negative or discount is invalid

    Example:
        >>> result = process_payment(100.0, "credit", 0.1)
        >>> print(result['final_amount'])
        90.0
    """
```

# Function Design Patterns 🏗️

<v-clicks>

### 1. Single Responsibility Principle

```python
# ❌ Function doing too much
def process_user_registration(name, email, password):
    # Validate input
    if not name or not email or not password:
        return False
    # Hash password
    hashed = hash_password(password)
    # Save to database
    save_user(name, email, hashed)
    # Send welcome email
    send_welcome_email(email, name)
    # Log registration
    log_activity(f"User {name} registered")
    return True

# ✅ Split into focused functions
def validate_registration_data(name, email, password):
    """Validate user registration input."""
    return name and email and password

def create_user_account(name, email, password):
    """Create new user account."""
    if not validate_registration_data(name, email, password):
        raise ValueError("Invalid registration data")

    hashed_password = hash_password(password)
    user_id = save_user(name, email, hashed_password)
    return user_id
```

# More Design Patterns 🎨

<v-clicks>

### 2. Early Return Pattern

```python
# ❌ Deep nesting
def calculate_discount(customer_type, order_amount, is_member):
    if customer_type == "premium":
        if order_amount > 100:
            if is_member:
                return order_amount * 0.2  # 20% discount
            else:
                return order_amount * 0.15  # 15% discount
        else:
            return order_amount * 0.1  # 10% discount
    else:
        return 0  # No discount

# ✅ Early return - cleaner logic
def calculate_discount(customer_type, order_amount, is_member):
    """Calculate customer discount based on criteria."""
    if customer_type != "premium":
        return 0

    if order_amount <= 100:
        return order_amount * 0.1

    if is_member:
        return order_amount * 0.2
    else:
        return order_amount * 0.15
```

# Advanced Function Example: Data Processor 📊

<v-clicks>

```python
def process_student_grades(grades,
                          remove_lowest=False,
                          curve_points=0.0,
                          min_grade=0.0,
                          max_grade=100.0):
    """
    Process a list of student grades with various options.

    Args:
        grades (list): List of numeric grades
        remove_lowest (bool): Whether to drop the lowest grade
        curve_points (float): Points to add to all grades
        min_grade (float): Minimum possible grade (for clamping)
        max_grade (float): Maximum possible grade (for clamping)

    Returns:
        dict: Processed grade statistics

    Example:
        >>> grades = [78, 85, 92, 67, 88]
        >>> result = process_student_grades(grades, remove_lowest=True, curve_points=2)
        >>> print(f"Average: {result['average']:.1f}")
        Average: 88.8
    """
    if not grades:
        return {"error": "No grades provided"}

    # Work with a copy to avoid modifying original
    processed_grades = grades.copy()

    # Remove lowest grade if requested
    if remove_lowest and len(processed_grades) > 1:
        processed_grades.remove(min(processed_grades))

    # Apply curve
    if curve_points != 0:
        processed_grades = [grade + curve_points for grade in processed_grades]

    # Clamp grades to valid range
    processed_grades = [max(min_grade, min(max_grade, grade))
                       for grade in processed_grades]

    # Calculate statistics
    average = sum(processed_grades) / len(processed_grades)
    highest = max(processed_grades)
    lowest = min(processed_grades)

    return {
        "original_count": len(grades),
        "processed_count": len(processed_grades),
        "grades": processed_grades,
        "average": average,
        "highest": highest,
        "lowest": lowest,
        "curve_applied": curve_points,
        "lowest_removed": remove_lowest
    }
```

# Using the Data Processor 🔧

<v-clicks>

```python
# Test data
student_grades = [78, 85, 92, 67, 88, 91, 73]

# Basic processing
basic_result = process_student_grades(student_grades)
print(f"Basic average: {basic_result['average']:.1f}")

# Remove lowest and add curve
curved_result = process_student_grades(
    student_grades,
    remove_lowest=True,
    curve_points=3.0
)
print(f"Curved average: {curved_result['average']:.1f}")

# Full processing with all options
full_result = process_student_grades(
    grades=student_grades,
    remove_lowest=True,
    curve_points=2.5,
    min_grade=50.0,  # Minimum failing grade
    max_grade=95.0   # Cap to prevent perfect scores
)

print(f"Processed grades: {full_result['grades']}")
print(f"Final average: {full_result['average']:.1f}")
```
