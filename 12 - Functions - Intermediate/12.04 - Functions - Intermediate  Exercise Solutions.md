**Problem:** Create a function `create_user_profile` that takes username (required), email (required), age (default 18), country (default "Canada"). Test with positional, named, and mixed arguments.

### Question 2: Currency Formatter
**Problem:** Write a function `format_currency` that takes amount (required), currency_symbol (default "$"), decimals (default 2). Return formatted string like "$123.45".

**Solution Approach:**
- Amount is required (no default)
- Currency symbol defaults to "$"
- Decimals defaults to 2
- Use f-string formatting for decimal places

**Complete Solution:**
```python
def format_currency(amount, currency_symbol="$", decimals=2):
    """
    Format number as currency string.
    
    Parameters:
        amount: Numeric amount (required)
        currency_symbol: Currency symbol (default "$")
        decimals: Number of decimal places (default 2)
    
    Returns:
        Formatted currency string
    """
    format_string = f"{currency_symbol}{amount:.{decimals}f}"
    return format_string
```

```python
def create_rectangle(width, height=None, color="black", filled=True):
    """
    Create rectangle with specified properties.
```

### Question 6: Universal Area Calculator
**Problem:** Create a single `calculate_area` function that can calculate area for circle (radius), rectangle (length, width), or square (side). Use default parameters to handle all three cases.

**Solution Approach:**
- Use shape type parameter to determine calculation
- Default parameters allow different combinations
- One function handles all shapes

**Complete Solution:**
```python
def calculate_area(shape="square", **dimensions):
    """
    Calculate area for different shapes using one function.
    
    Parameters:
        shape: Type of shape ("square", "rectangle", "circle")
        **dimensions: Keyword arguments for dimensions
            - square: side
            - rectangle: length, width
            - circle: radius
    
    Returns:
        Area of the shape
    """
    if shape == "square":
        side = dimensions.get('side', 1)
        return side ** 2
    
    elif shape == "rectangle":
        length = dimensions.get('length', 1)
        width = dimensions.get('width', 1)
        return length * width
    
    elif shape == "circle":
        radius = dimensions.get('radius', 1)
        pi = 3.14159
        return pi * radius ** 2
    
    else:
        return "Unknown shape"


# Alternative approach with separate parameters
def calculate_area_v2(dimension1=None, dimension2=None, is_circle=False):
    """
    Calculate area with flexible parameters.
    
    Parameters:
        dimension1: Side/length/radius (default None)
        dimension2: Width for rectangle (default None, makes it square)
        is_circle: True for circle calculation (default False)
    
    Returns:
        Calculated area
    """
    if dimension1 is None:
        return 0
    
    if is_circle:
        # Circle: dimension1 is radius
        pi = 3.14159
        return pi * dimension1 ** 2
    
    if dimension2 is None:
        # Square: dimension1 is side
        return dimension1 ** 2
    
    # Rectangle: dimension1 is length, dimension2 is width
    return dimension1 * dimension2


# Test both versions
print("=== Universal Area Calculator ===\n")

print(f"Square (side=5): {calculate_area('square', side=5)}")
print(f"Rectangle (4×6): {calculate_area('rectangle', length=4, width=6)}")
print(f"Circle (radius=3): {calculate_area('circle', radius=3):.2f}")

print("\nVersion 2 (flexible parameters):")
print(f"Square (5): {calculate_area_v2(5)}")
print(f"Rectangle (4×6): {calculate_area_v2(4, 6)}")
print(f"Circle (radius=3): {calculate_area_v2(3, is_circle=True):.2f}")
```

```python
from datetime import datetime

    """
```

```python
def connect_database(host, port=5432, username="admin", password=None, ssl=True):
    """
    Connect to database with flexible parameters.
    
    Parameters:
        host: Database host address (required)
        port: Database port (default 5432)
        username: Database username (default "admin")
        password: Database password (default None)
        ssl: Use SSL connection (default True)
    
    Returns:
        Connection details dictionary
    """
    # Check for password
    if password is None:
        return {"error": "Password required"}
    
    connection = {
        'host': host,
        'port': port,
        'username': username,
        'password': '***hidden***',  # Don't show actual password
        'ssl': ssl,
        'status': 'Connected',
        'connection_string': f"{username}@{host}:{port}"
    }
    
    return connection


def display_connection(conn):
```

```python
def list_sum(items):

    # Base case - empty list
    if len(items) == 0:

    if isinstance(first, list):

    # If first element is a number, add it
    return first + list_sum(rest)
```

### Question 22: Binary Search
**Problem:** Create a recursive `binary_search` function that searches for a value in a sorted list using the divide-and-conquer approach.

**Solution Approach:**
- Base case: empty list or value found
- Find middle element
- If value < middle: search left half
- If value > middle: search right half
- Return index or -1 if not found

**Complete Solution:**
```python
def binary_search(arr, target, left=0, right=None):
    """
    Recursively search for target in sorted array.
    
    Parameters:
        arr: Sorted list
        target: Value to find
        left: Left boundary (default 0)
        right: Right boundary (default None)
    
    Returns:
        Index of target, or -1 if not found
    """
    # Initialize right on first call
    if right is None:
        right = len(arr) - 1
    
    # Base case - not found
    if left > right:
        return -1
    
    # Find middle
    mid = (left + right) // 2
    
    # Base case - found
    if arr[mid] == target:
        return mid
    
    # Recursive cases
    if target < arr[mid]:
        # Search left half
        return binary_search(arr, target, left, mid - 1)
    else:
        # Search right half
        return binary_search(arr, target, mid + 1, right)


def binary_search_trace(arr, target, left=0, right=None, depth=0):
    """Show binary search process."""
    if right is None:
        right = len(arr) - 1
    
    indent = "  " * depth

        print(f"{indent}Range [{left}:{right}] - Not found")
        return -1
    
    mid = (left + right) // 2
    print(f"{indent}Searching [{left}:{right}], mid={mid}, arr[{mid}]={arr[mid]}")
    
    if arr[mid] == target:
        print(f"{indent}Found {target} at index {mid}!")
        return mid
    
    if target < arr[mid]:
        print(f"{indent}{target} < {arr[mid]}, search left")
        return binary_search_trace(arr, target, left, mid - 1, depth + 1)

        return binary_search_trace(arr, target, mid + 1, right, depth + 1)
```

### Question 25: Merge Sort
**Problem:** Write a `merge_sort` function that recursively sorts a list by dividing it in half, sorting each half, and merging results. Compare performance with bubble sort for large lists.

**Solution Approach:**
- Base case: list of 0 or 1 element is sorted
- Divide list in half
- Recursively sort each half
- Merge sorted halves
- Compare with O(n²) bubble sort

**Complete Solution:**
```python
import time
import random

def merge_sort(arr):
    """
    Sort list using merge sort (recursive).
    Time complexity: O(n log n)
    """
    # Base case
    if len(arr) <= 1:
        return arr
    
    # Divide
    mid = len(arr) // 2
    left = arr[:mid]
    right = arr[mid:]
    
    # Conquer (recursive sort)
    left_sorted = merge_sort(left)
    right_sorted = merge_sort(right)
    
    # Combine (merge)
    return merge(left_sorted, right_sorted)


def merge(left, right):
    """Merge two sorted lists into one sorted list."""
    result = []
    i = j = 0
    
    # Merge elements in order
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    
    # Add remaining elements
    result.extend(left[i:])
    result.extend(right[j:])
    
    return result


def bubble_sort(arr):
    """
    Sort list using bubble sort (for comparison).
    Time complexity: O(n²)
    """
    arr = arr.copy()  # Don't modify original
    n = len(arr)
    
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    
    return arr


def test_sorting():
    """Compare merge sort vs bubble sort performance."""
    print("=== Sorting Algorithm Comparison ===\n")
    
    sizes = [100, 500, 1000, 2000]
    
    for size in sizes:
        # Generate random list
        test_list = [random.randint(1, 1000) for _ in range(size)]
        
        # Test merge sort
        start = time.time()
        merge_sorted = merge_sort(test_list)
        merge_time = time.time() - start
        
        # Test bubble sort
        start = time.time()
        bubble_sorted = bubble_sort(test_list)
        bubble_time = time.time() - start
        
        # Verify both work correctly
        correct = merge_sorted == bubble_sorted == sorted(test_list)
        
        print(f"Size: {size} elements")
        print(f"  Merge Sort:  {merge_time:.4f} seconds")
        print(f"  Bubble Sort: {bubble_time:.4f} seconds")
        print(f"  Speedup:     {bubble_time/merge_time:.1f}x faster")
        print(f"  Correct:     {correct}")
        print()
```

## Summary: Key Patterns and Takeaways

### Default Parameters Best Practices
1. Required parameters first, optional last
2. Use None for mutable defaults
3. Sensible defaults reduce complexity
4. Named arguments improve clarity

### Recursion Essentials
1. Always have base case
2. Progress toward base case
3. Consider iterative alternatives
4. Use for naturally recursive problems

### When to Use Each Technique
- **Default parameters**: Flexible APIs, avoiding function overloading
- **Named arguments**: Many parameters, similar types, clarity
- **Recursion**: Trees, nested structures, divide-and-conquer, mathematical sequences

### Performance Considerations
- Recursion has overhead (function calls)
- May hit recursion depth limit
- Memoization can dramatically improve recursive performance
- Consider iterative solutions for critical performance
