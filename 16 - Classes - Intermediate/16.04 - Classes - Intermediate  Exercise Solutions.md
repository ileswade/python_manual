### Question 1
**Problem:** Create a `Dog` class with `name` and `age` attributes. Add a `bark()` method that prints "[name] says: Woof!" and a `get_age_in_dog_years()` method that returns age × 7.

**Solution Approach:**

### Question 2
**Problem:** Create a `Counter` class with a `count` attribute starting at 0. Add methods: `increment()` (adds 1), `decrement()` (subtracts 1), and `reset()` (sets to 0).

```python
class Counter:
    def __init__(self):
        """Initialize counter at 0."""
        self.count = 0

        """Increase count by 1."""
        self.count += 1
        print(f"Count: {self.count}")

        """Decrease count by 1."""
        self.count -= 1
        print(f"Count: {self.count}")

        """Reset count to 0."""

```


- Methods modify object state (instance variables)
- `self.count += 1` changes THIS object's count

### Question 3
**Problem:** Create a `Circle` class with `radius` attribute. Add methods `area()` and `circumference()` that return calculated values (π × r² and 2 × π × r).

**Solution Approach:**
- Store radius as instance variable
- Use math.pi for π value
- Calculate and return area and circumference

**Complete Solution:**
```python
import math

class Circle:
    def __init__(self, radius):
        """Initialize circle with radius."""
        self.radius = radius
    
    def area(self):
        """Calculate and return area (π × r²)."""
        return math.pi * (self.radius ** 2)
    
    def circumference(self):
        """Calculate and return circumference (2 × π × r)."""
        return 2 * math.pi * self.radius

# Create and test circles

circle2 = Circle(10)

print(f"Circle with radius {circle1.radius}:")
print(f"  Area: {circle1.area():.2f}")
print(f"  Circumference: {circle1.circumference():.2f}")

print(f"\nCircle with radius {circle2.radius}:")
print(f"  Area: {circle2.area():.2f}")
print(f"  Circumference: {circle2.circumference():.2f}")
```

**Sample Run:**
```

  Circumference: 31.42

Circle with radius 10:
  Area: 314.16
  Circumference: 62.83
```

- Methods return calculated values
- Use `self.radius` to access stored radius

```python
class Product:
```

```python
class BankAccount:
    def __init__(self, account_number, balance=0):
        """Initialize bank account."""
        self.account_number = account_number
        self.balance = balance
    
    def deposit(self, amount):
        """Deposit money into account."""
        if amount <= 0:
            print("Deposit must be positive!")
            return False
        
        self.balance += amount
        print(f"Deposited ${amount:.2f}. New balance: ${self.balance:.2f}")
        return True
    
    def withdraw(self, amount):
        """Withdraw money from account."""
        if amount <= 0:
            print("Withdrawal must be positive!")

        if amount > self.balance:
            print(f"Insufficient funds! Balance: ${self.balance:.2f}")
            return False
        
        self.balance -= amount
        print(f"Withdrew ${amount:.2f}. New balance: ${self.balance:.2f}")
        return True
    
    def __str__(self):
        """User-friendly representation."""
        return f"Account #{self.account_number}: ${self.balance:.2f}"
    
    def __repr__(self):
        """Developer-friendly representation."""
        return f"BankAccount('{self.account_number}', {self.balance})"
```

### Question 11
**Problem:** Create a `Player` class with `name` and `score` (starts at 0). Add methods `add_points(points)`, `remove_points(points)`, and `reset_score()`. Include `__str__`.

**Solution Approach:**
- Score starts at 0
- Methods modify score
- Prevent negative score in remove_points
- Include __str__ for display

**Complete Solution:**
```python
class Player:
    def __init__(self, name):
        """Initialize player with name and score of 0."""
        self.name = name
        self.score = 0
    
    def add_points(self, points):
        """Add points to player's score."""
        if points < 0:
            print("Points must be positive!")
            return
        
        self.score += points
        print(f"{self.name} earned {points} points! Total: {self.score}")
    
    def remove_points(self, points):
        """Remove points from player's score (can't go below 0)."""

            print("Points must be positive!")

        print(f"{self.name} lost {points} points! Total: {self.score}")
    
    def reset_score(self):
        """Reset score to 0."""
        self.score = 0
        print(f"{self.name}'s score reset to 0")
    
    def __str__(self):
        """Human-readable representation."""
        return f"{self.name}: {self.score} points"

# Test player
```

```python
class TodoList:
```

### Question 13
**Problem:** Create a `Inventory` class with `items` dictionary (item_name: quantity). Add methods `add_item(name, qty)`, `remove_item(name, qty)`, `check_stock(name)`, and `__str__`.

**Solution Approach:**
- Dictionary stores items and quantities
- Add increases quantity (or creates new item)
- Remove decreases quantity (check stock first)
- Check stock returns current quantity

**Complete Solution:**
```python
class Inventory:
    def __init__(self):
        """Initialize empty inventory."""
        self.items = {}
    
    def add_item(self, name, quantity):
        """Add items to inventory."""
        if quantity <= 0:
            print("Quantity must be positive!")
            return
        
        if name in self.items:
            self.items[name] += quantity
            print(f"Added {quantity} {name}. Total: {self.items[name]}")
        else:
            self.items[name] = quantity
            print(f"Added {quantity} {name} (new item)")
    
    def remove_item(self, name, quantity):
        """Remove items from inventory."""
        if name not in self.items:
            print(f"{name} not in inventory")
            return
        
        if quantity > self.items[name]:
            print(f"Not enough {name}! Available: {self.items[name]}")
            return
        
        self.items[name] -= quantity
        print(f"Removed {quantity} {name}. Remaining: {self.items[name]}")
        
        if self.items[name] == 0:
            del self.items[name]
            print(f"{name} out of stock")
    
    def check_stock(self, name):
        """Check quantity of an item."""
        if name in self.items:
            return self.items[name]
        else:
            return 0
    
    def __str__(self):
        """Display inventory."""
        if len(self.items) == 0:
            return "Inventory is empty"
        
        result = "Inventory:\n"
        for item, qty in self.items.items():
            result += f"  {item}: {qty}\n"
        return result.strip()

print(inv)
```

```python
import random

class Playlist:
    def __init__(self, name):
        """Initialize playlist with name."""
        self.name = name
        self.songs = []
    
    def add_song(self, song):
        """Add song to playlist."""
        self.songs.append(song)
        print(f"Added '{song}' to {self.name}")
    
    def remove_song(self, song):
        """Remove song from playlist."""
        if song in self.songs:
            self.songs.remove(song)
            print(f"Removed '{song}' from {self.name}")
        else:
            print(f"'{song}' not found in {self.name}")
    
    def shuffle(self):
        """Shuffle the playlist."""
        random.shuffle(self.songs)
        print(f"Shuffled {self.name}")
    
    def __str__(self):
```

```python
        """Add book to library."""
        book = {
            "title": title,
            "author": author,
            "available": True
        }

    def check_out_book(self, title):
        """Check out a book."""
        for book in self.books:
            if book["title"] == title:
                if book["available"]:
                    book["available"] = False
                    print(f"Checked out: '{title}'")
                    return True
                else:
                    print(f"'{title}' is already checked out")
                    return False
        
        print(f"'{title}' not found in library")
        return False
    
    def return_book(self, title):
        """Return a book."""
        for book in self.books:
            if book["title"] == title:
                if not book["available"]:
                    book["available"] = True
                    print(f"Returned: '{title}'")
                    return True
                else:
                    print(f"'{title}' wasn't checked out")
                    return False
        
        print(f"'{title}' not found in library")
        return False
    
    def available_books(self):
        """Get list of available books."""
        return [book for book in self.books if book["available"]]
    
    def __str__(self):
        """Display library status."""
        result = f"Library Collection ({len(self.books)} books):\n"
        for book in self.books:
            status = "✓ Available" if book["available"] else "✗ Checked out"
            result += f"  '{book['title']}' by {book['author']} - {status}\n"
        return result.strip()
```

```python
from datetime import datetime

class BankAccount:
    def __init__(self, owner, balance=0):
        """Initialize bank account with owner and balance."""
        self.owner = owner
        self.balance = balance
        self.transaction_history = []
    
    def deposit(self, amount):
        """Deposit money."""
        if amount <= 0:
            print("Amount must be positive!")
            return False
        
        self.balance += amount
        self.transaction_history.append({
            "type": "deposit",
            "amount": amount,
            "balance_after": self.balance,
            "time": datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        })
        print(f"Deposited ${amount:.2f}")
        return True
    
    def withdraw(self, amount):
        """Withdraw money."""
        if amount <= 0:
            print("Amount must be positive!")
            return False
        
        if amount > self.balance:
            print(f"Insufficient funds! Balance: ${self.balance:.2f}")
            return False
        
        self.balance -= amount
        self.transaction_history.append({
            "type": "withdrawal",
            "amount": amount,
            "balance_after": self.balance,
            "time": datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        })
        print(f"Withdrew ${amount:.2f}")
        return True
    
    def transfer(self, other_account, amount):
        """Transfer money to another account."""
        print(f"Transferring ${amount:.2f} from {self.owner} to {other_account.owner}")
        
        if self.withdraw(amount):
            other_account.deposit(amount)
            print("Transfer successful!")
            return True
        else:
            print("Transfer failed!")
            return False
    
    def show_history(self):
        """Display transaction history."""
        print(f"\nTransaction History - {self.owner}")
        print("-" * 60)
        if len(self.transaction_history) == 0:
            print("No transactions")
        else:

                print(f"{trans['time']} | {trans['type'].upper():<12} | "
                      f"${trans['amount']:>8.2f} | Balance: ${trans['balance_after']:.2f}")
        print("-" * 60)
    
    def __str__(self):
        """User-friendly representation."""
        return f"{self.owner}'s account: ${self.balance:.2f}"
    
    def __repr__(self):
        """Developer-friendly representation."""
        return f"BankAccount('{self.owner}', {self.balance})"
```

4. **Return vs Print**: Return for values, print for user feedback
5. **Validation first**: Check inputs before modifying state
6. **Independent objects**: Each object has separate state
