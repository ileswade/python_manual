### Example 1: Building a Complete Bank Account Class with Methods
**Problem:** Create a `BankAccount` class with account holder name, account number, and balance. Add methods for deposit, withdraw (with insufficient funds check), transfer to another account, and display account info. Include both `__str__` and `__repr__` methods. Create 3 accounts and demonstrate all operations.

**Detailed Solution:**

**Step 1: Understand what methods do vs what data stores**
- Data (instance variables): account holder, number, balance
- Actions (methods): deposit, withdraw, transfer, display
- Methods access and modify the object's state (its data)

**Step 2: Plan the method behaviors**
```python
deposit(amount) -> increases balance
withdraw(amount) -> decreases balance (check if sufficient)
transfer(to_account, amount) -> withdraw from self, deposit to other
get_info() -> display account details
__str__() -> user-friendly display
__repr__() -> developer-friendly representation
```

**Step 3: Understand self in each method**
- `self` refers to the specific account object the method is called on
- `self.balance` accesses THAT account's balance
- When we call `account1.deposit(100)`, self = account1

**Step 4: Implement with proper state management**

**Complete Solution:**
```python
class BankAccount:
    def __init__(self, account_holder, account_number, balance=0):
        """
        Initialize bank account with holder name, number, and balance.
        
        Parameters:
            account_holder: Name of account holder
            account_number: Unique account number
            balance: Initial balance (default 0)
        """
        self.account_holder = account_holder
        self.account_number = account_number
        self.balance = balance
    
    def deposit(self, amount):
        """Deposit money into the account."""
        if amount <= 0:
            print("Deposit amount must be positive!")
            return False
        
        self.balance += amount
        print(f"Deposited ${amount:.2f} to {self.account_holder}'s account")
        print(f"New balance: ${self.balance:.2f}")
        return True
    
    def withdraw(self, amount):
        """Withdraw money from the account."""
        if amount <= 0:
            print("Withdrawal amount must be positive!")
            return False
        
        if amount > self.balance:
            print(f"Insufficient funds! Balance: ${self.balance:.2f}, Requested: ${amount:.2f}")
            return False
        
        self.balance -= amount
        print(f"Withdrew ${amount:.2f} from {self.account_holder}'s account")
        print(f"New balance: ${self.balance:.2f}")
        return True
    
    def transfer(self, to_account, amount):
        """Transfer money to another account."""
        print(f"\nTransfer: {self.account_holder} -> {to_account.account_holder}")
        
        # Try to withdraw from this account
        if self.withdraw(amount):
            # If successful, deposit to other account
            to_account.deposit(amount)
            print("Transfer completed successfully!")
            return True
        else:
            print("Transfer failed!")
            return False
    
    def get_info(self):
        """Display account information."""
        print(f"\n{'='*50}")
        print(f"Account Holder: {self.account_holder}")
        print(f"Account Number: {self.account_number}")
        print(f"Balance: ${self.balance:.2f}")
        print(f"{'='*50}")
    
    def __str__(self):
        """Human-readable representation."""
        return f"{self.account_holder}'s account (#{self.account_number}): ${self.balance:.2f}"
    
    def __repr__(self):
        """Developer-friendly representation."""
        return f"BankAccount('{self.account_holder}', '{self.account_number}', {self.balance})"

print("\n" + "="*60)
```

**Key Concepts:**
- **Methods modify state**: `deposit()` and `withdraw()` change `self.balance`
- **self refers to specific object**: When `account1.deposit()` runs, `self = account1`
- **Methods can call other methods**: `transfer()` calls `withdraw()` and `deposit()`
- **Validation in methods**: Check for negative amounts, insufficient funds
- **Object interaction**: `transfer()` takes another account object as parameter
- **__str__ for users**: "Alice's account: $1000.00" - readable
- **__repr__ for developers**: "BankAccount('Alice', 'ACC001', 1000)" - precise
- **Return values**: Methods return True/False to indicate success/failure
- **State tracking**: Each object maintains its own balance independently

**Why this works:**
1. Each account object has its own balance (state)
2. Methods access state through `self.variable`
3. When you call `account1.deposit()`, Python passes `account1` as `self`
4. The method modifies `self.balance`, which is `account1.balance`
5. Other accounts are unaffected - each maintains separate state

### Example 2: Student Grade Tracker with Average Calculation and Letter Grade
**Problem:** Create a `Student` class with name, student ID, and a grades list. Add methods to: add a grade, remove a grade, calculate average, get letter grade, and check if passing (average >= 60). Include `__str__` and `__repr__`. Create 4 students, add grades, and generate a class report.

**Detailed Solution:**

**Step 1: Identify state vs behavior**
- State: name, student_id, grades (list)
- Behavior: add_grade, remove_grade, calculate_average, get_letter_grade, is_passing

**Step 2: Understand how methods use state**
- `add_grade()` modifies `self.grades` list
- `calculate_average()` reads `self.grades` to compute average
- `get_letter_grade()` calls `calculate_average()` then determines letter
- Methods can call other methods!

**Step 3: Plan the method dependencies**
```
get_letter_grade() needs average()
is_passing() needs average()
Both depend on self.grades having data
```

**Step 4: Implement with method chaining**

**Complete Solution:**
```python
class Student:
    def __init__(self, name, student_id):
        """
        Initialize student with name and ID.
        Grades list starts empty.
        """
        self.name = name
        self.student_id = student_id
        self.grades = []
    
    def add_grade(self, grade):
        """Add a grade to the student's record."""
        if grade < 0 or grade > 100:
            print(f"Invalid grade! Must be between 0 and 100.")
            return False
        
        self.grades.append(grade)
        print(f"Added grade {grade} for {self.name}")
        return True
    
    def remove_grade(self, grade):
        """Remove a specific grade from the record."""
        if grade in self.grades:
            self.grades.remove(grade)
            print(f"Removed grade {grade} from {self.name}'s record")
            return True
        else:
            print(f"Grade {grade} not found in {self.name}'s record")
            return False
    
    def calculate_average(self):
        """Calculate and return the average grade."""
        if len(self.grades) == 0:
            return 0
        return sum(self.grades) / len(self.grades)
    
    def get_letter_grade(self):
        """Get letter grade based on average."""
        average = self.calculate_average()  # Call another method!
        
        if average >= 90:
            return 'A'
        elif average >= 80:
            return 'B'
        elif average >= 70:
            return 'C'
        elif average >= 60:
            return 'D'
        else:
            return 'F'
    
    def is_passing(self):
        """Check if student is passing (average >= 60)."""
        return self.calculate_average() >= 60
    
    def display_report(self):
        """Display detailed student report."""
        print(f"\n{'='*50}")
        print(f"Student Report: {self.name}")
        print(f"{'='*50}")
        print(f"ID: {self.student_id}")
        print(f"Grades: {self.grades}")
        print(f"Average: {self.calculate_average():.2f}")
        print(f"Letter Grade: {self.get_letter_grade()}")
        print(f"Status: {'PASSING' if self.is_passing() else 'FAILING'}")
        print(f"{'='*50}")
    
    def __str__(self):
        """Human-readable representation."""
        avg = self.calculate_average()
        return f"{self.name} (ID: {self.student_id}) - Average: {avg:.2f} ({self.get_letter_grade()})"
    
    def __repr__(self):
        """Developer-friendly representation."""
        return f"Student('{self.name}', '{self.student_id}')"
```

### Example 3: Shopping Cart with Item Management and Price Calculation
**Problem:** Create a `ShoppingCart` class that stores items (as dictionaries with name, price, quantity). Add methods to: add item, remove item, update quantity, calculate subtotal, apply discount, calculate tax, and get final total. Include `__str__` to display cart contents. Create 2 carts, add items, apply operations, and display final bills.

**Detailed Solution:**

**Step 1: Design the data structure**
- Items stored as list of dictionaries: `[{"name": "Apple", "price": 1.99, "quantity": 5}, ...]`
- Methods will manipulate this list

**Step 2: Plan method responsibilities**
```
add_item() -> append to items list
remove_item() -> remove from items list
update_quantity() -> modify quantity in existing item
subtotal() -> sum of (price × quantity) for all items
apply_discount() -> reduce prices by percentage
calculate_tax() -> add tax to subtotal
total() -> subtotal + tax - discount
```

**Step 3: Understand state changes**
- Each method modifies or reads `self.items`
- Discount and tax stored as instance variables
- Methods cascade: total depends on subtotal, tax, discount

**Step 4: Implement with comprehensive functionality**

**Complete Solution:**
```python
class ShoppingCart:
    def __init__(self, customer_name):
        """Initialize empty shopping cart for customer."""
        self.customer_name = customer_name
        self.items = []
        self.discount_percent = 0
        self.tax_rate = 0.08  # 8% tax
    
    def add_item(self, name, price, quantity=1):
        """Add item to cart."""
        if price < 0 or quantity <= 0:
            print("Invalid price or quantity!")
            return False
        
        # Check if item already exists
        for item in self.items:
            if item["name"] == name:
                item["quantity"] += quantity
                print(f"Updated {name}: quantity now {item['quantity']}")
                return True
        
        # Add new item
        self.items.append({
            "name": name,
            "price": price,
            "quantity": quantity
        })
        print(f"Added {quantity}x {name} @ ${price:.2f} each")
        return True
    
    def remove_item(self, name):
        """Remove item from cart completely."""
        for item in self.items:
            if item["name"] == name:
                self.items.remove(item)
                print(f"Removed {name} from cart")
                return True
        
        print(f"{name} not found in cart")
        return False
    
    def update_quantity(self, name, new_quantity):
        """Update quantity of an item."""
        if new_quantity <= 0:
            return self.remove_item(name)
        
        for item in self.items:
            if item["name"] == name:
                old_qty = item["quantity"]
                item["quantity"] = new_quantity
                print(f"Updated {name}: {old_qty} -> {new_quantity}")
                return True
        
        print(f"{name} not found in cart")
        return False
    
    def subtotal(self):
        """Calculate subtotal (before tax/discount)."""
        total = 0
        for item in self.items:
            total += item["price"] * item["quantity"]
        return total
    
    def apply_discount(self, percent):
        """Apply discount percentage."""
        if percent < 0 or percent > 100:
            print("Discount must be between 0 and 100%")
            return False
        
        self.discount_percent = percent
        print(f"Applied {percent}% discount")
        return True
    
    def discount_amount(self):
        """Calculate discount amount."""
        return self.subtotal() * (self.discount_percent / 100)
    
    def tax_amount(self):
        """Calculate tax amount (after discount)."""
        subtotal_after_discount = self.subtotal() - self.discount_amount()
        return subtotal_after_discount * self.tax_rate
    
    def total(self):
        """Calculate final total."""
        return self.subtotal() - self.discount_amount() + self.tax_amount()
    
    def display_receipt(self):
        """Display detailed receipt."""
        print(f"\n{'='*60}")
        print(f"RECEIPT - {self.customer_name}")
        print(f"{'='*60}")
        
        if len(self.items) == 0:
            print("Cart is empty")
            print(f"{'='*60}")
            return
        
        print(f"{'Item':<30} {'Price':>10} {'Qty':>5} {'Total':>12}")
        print(f"{'-'*60}")
        
        for item in self.items:
            item_total = item["price"] * item["quantity"]
            print(f"{item['name']:<30} ${item['price']:>9.2f} {item['quantity']:>5} ${item_total:>11.2f}")
        
        print(f"{'-'*60}")
        print(f"{'Subtotal:':<48} ${self.subtotal():>11.2f}")
        
        if self.discount_percent > 0:
            print(f"{'Discount (' + str(self.discount_percent) + '%):':<48} -${self.discount_amount():>10.2f}")
        
        print(f"{'Tax (8%):':<48} ${self.tax_amount():>11.2f}")
        print(f"{'='*60}")
        print(f"{'TOTAL:':<48} ${self.total():>11.2f}")
        print(f"{'='*60}")
    
    def __str__(self):
        """Human-readable cart summary."""
        if len(self.items) == 0:
            return f"{self.customer_name}'s cart is empty"
        
        item_count = sum(item["quantity"] for item in self.items)
        return f"{self.customer_name}'s cart: {len(self.items)} items ({item_count} units) - Total: ${self.total():.2f}"
    
    def __repr__(self):
        """Developer-friendly representation."""
        return f"ShoppingCart('{self.customer_name}')"
```

- **Multi-step calculations**: Discount applies before tax
- **Formatted output**: Receipt uses careful alignment and formatting
- **__str__ provides summary**: Quick overview without full details
- **Business logic**: Real-world shopping cart operations

**Calculation flow:**
```
total() =
    subtotal() - discount_amount() + tax_amount()
    
Where:
    subtotal() = sum of (price × qty) for all items
    discount_amount() = subtotal() × (discount_percent / 100)
    tax_amount() = (subtotal() - discount_amount()) × tax_rate
```

## Tips for Solving These Problems

### Understanding Methods

**Method Definition Pattern:**
```python
class ClassName:
    def method_name(self, parameters):
        # Access instance variables with self.variable
        # Modify state with self.variable = new_value
        # Return value if needed
        return result
```

**Key principles:**
- Always include `self` as first parameter
- Use `self.attribute` to access instance variables
- Methods can modify object state
- Methods can return values

### Understanding `self`

**Two perspectives:**

**Perspective 1 - "This object":**
```python
class Dog:
    def __init__(self, name):
        self.name = name  # Store in THIS dog
    
    def bark(self):
        print(f"{self.name} barks")  # Use THIS dog's name

dog1 = Dog("Buddy")
dog1.bark()  # self = dog1, uses dog1.name
```

**Perspective 2 - Automatic passing:**
```python
dog1.bark()
# Python actually does: Dog.bark(dog1)
# So self receives dog1
```

### Methods That Modify State

**Pattern:**
```python
class Counter:
    def __init__(self):
        self.count = 0  # Initial state
    
    def increment(self):
        self.count += 1  # Modify state
```

**Always use `self.` to modify:**
```python
# Wrong
def increment(self):
    count += 1  # Doesn't modify instance variable!

# Right
def increment(self):
    self.count += 1  # Modifies THIS object's count
```

### Methods That Call Other Methods

**Methods can call each other:**
```python
class Student:
    def __init__(self):
        self.grades = []
    
    def add_grade(self, grade):
        self.grades.append(grade)
    
    def average(self):
        return sum(self.grades) / len(self.grades)
    
    def letter_grade(self):
        avg = self.average()  # Call another method!
        if avg >= 90:
            return 'A'
        # ...
```

### Special Methods: `__str__` and `__repr__`

**__str__ - for users:**
```python
def __str__(self):
    return "Human-readable description"

# Used by print()
print(object)  # Calls __str__
```

**__repr__ - for developers:**
```python
def __repr__(self):
    return "ClassName(params_to_recreate)"

# Used for debugging
repr(object)  # Calls __repr__
```

**Best practice:**
```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def __str__(self):
        return f"{self.name} ({self.age} years old)"
    
    def __repr__(self):
        return f"Dog('{self.name}', {self.age})"
```

### Methods with Return Values

**Return calculations:**
```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def area(self):
        return self.width * self.height  # Return calculated value
```

**Return boolean:**
```python
def is_square(self):
    return self.width == self.height  # Returns True/False
```

### Validation in Methods

**Check before modifying:**
```python
def withdraw(self, amount):
    if amount > self.balance:
        print("Insufficient funds!")
        return False
    
    self.balance -= amount
    return True
```

### Common Patterns

**Accumulator pattern:**
```python
def total(self):
    total = 0
    for item in self.items:
        total += item.price
    return total
```

**State check pattern:**
```python
def is_valid(self):
    return (self.check_length() and 
            self.has_uppercase() and 
            self.has_number())
```

**Update pattern:**
```python
def update(self, new_value):
    old_value = self.value
    self.value = new_value
    return old_value
```

### Object Interaction

**Methods can take other objects:**
```python
def transfer(self, other_account, amount):
    if self.withdraw(amount):
        other_account.deposit(amount)
```

1. **Print self attributes:**

### Problem-Solving Workflow

1. **Identify state (instance variables):**
   - What data does each object need?

2. **Identify behavior (methods):**
   - What actions should objects perform?

3. **Determine method signatures:**
   - What parameters does each method need?
   - What should it return?

4. **Implement methods:**
   - Access state with `self.attribute`
   - Modify state with `self.attribute = value`
   - Return values as needed

5. **Add special methods:**

   - `__repr__` for developer display

### Common Mistakes to Avoid

1. **Forgetting self:**
   ```python
   # Wrong
   def method(self):
       return attribute  # NameError!
   
   # Right
   def method(self):
       return self.attribute
   ```

2. **Not modifying self:**
   ```python
   # Wrong
   def increment(self):
       count += 1  # Doesn't change object!
   
   # Right
   def increment(self):
       self.count += 1
   ```

3. **Wrong self usage:**
   ```python
   # Wrong
   obj.method(obj, params)  # Don't pass self!
   
   # Right
   obj.method(params)  # Python adds self automatically
   ```

4. **Confusing __str__ and __repr__:**
   ```python
   # __str__ for users (readable)
   def __str__(self):
       return f"{self.name}: ${self.balance}"
   
   # __repr__ for developers (precise)
   def __repr__(self):
       return f"Account('{self.name}', {self.balance})"
   ```
