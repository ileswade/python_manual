## Level 1: Basic Operations (Problems 1-5)

### Problem 1: Create a Tuple

**Thinking Process:**
Tuples use parentheses and hold multiple values. Access elements with indexing like lists.

**Solution:**
```python
person = ("Alice", 25, "Calgary")

print(person[0])  # Alice
print(person[1])  # 25
print(person[2])  # Calgary
```

**Key Points:**
- Tuples created with parentheses: `(item1, item2, item3)`
- Access by index: `tuple[0]`, `tuple[1]`, etc.
- Zero-based indexing just like lists

### Problem 2: Tuple Unpacking

**Thinking Process:**
Tuple unpacking assigns each element to a separate variable in one statement. Number of variables must match number of elements.

**Solution:**
```python
numbers = (10, 20, 30)
x, y, z = numbers

print(f"x={x}, y={y}, z={z}")  # x=10, y=20, z=30
```

**Key Points:**
- Unpacking: `var1, var2, var3 = tuple`
- Number of variables must equal tuple length
- Happens in one simultaneous assignment

### Problem 3: Remove Duplicates with Set

**Thinking Process:**
Sets automatically remove duplicates. Convert list → set (removes dupes) → list (restore indexing) → sort.

**Solution:**
```python
numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4, 5]

# Convert to set (removes duplicates)
unique_set = set(numbers)

# Convert back to sorted list
unique_list = sorted(unique_set)

print(unique_list)  # [1, 2, 3, 4, 5]
```

**Key Points:**
- `set()` removes duplicates automatically
- `sorted()` returns sorted list from any iterable
- Sets are unordered, so sort after converting back to list

### Problem 4: Set Operations

**Thinking Process:**
Sets support mathematical operations. Use operators: `|` (union), `&` (intersection), `-` (difference).

**Solution:**
```python
set_a = {1, 2, 3, 4, 5}
set_b = {4, 5, 6, 7, 8}

# Union - all items from both
union = set_a | set_b
print(f"Union: {union}")  # {1, 2, 3, 4, 5, 6, 7, 8}

# Intersection - items in both
intersection = set_a & set_b
print(f"Intersection: {intersection}")  # {4, 5}

# Difference - in set_a but not set_b
difference = set_a - set_b
print(f"Difference: {difference}")  # {1, 2, 3}
```

**Key Points:**
- `|` union: all elements from both sets
- `&` intersection: only elements in both
- `-` difference: elements in first but not second
- Can also use methods: `.union()`, `.intersection()`, `.difference()`

## Level 2: Intermediate Operations (Problems 6-10)

### Problem 6: Dictionary Methods

**Thinking Process:**
Dictionaries are mutable. Add with assignment, modify by reassigning, remove with `del` or `.pop()`.

**Solution:**
```python
fruits = {"apple": 5, "banana": 3, "orange": 7}

# Add new item
fruits["grape"] = 4

# Update existing item
fruits["banana"] = 6

# Remove item
del fruits["orange"]

print(fruits)  # {'apple': 5, 'banana': 6, 'grape': 4}
```

**Key Points:**
- Add/modify: `dict["key"] = value`
- Remove: `del dict["key"]` or `dict.pop("key")`
- If key exists, assignment modifies; if not, it adds

### Problem 8: Word Frequency

**Thinking Process:**
Count occurrences using dictionary. Check if word exists, increment or initialize to 1.

**Solution:**
```python
text = "apple banana apple cherry banana apple"
words = text.split()

word_count = {}

for word in words:
    if word in word_count:
        word_count[word] = word_count[word] + 1
    else:
        word_count[word] = 1

print(word_count)  # {'apple': 3, 'banana': 2, 'cherry': 1}
```

**Key Points:**
- Check existence: `if word in dict`
- Increment if exists, initialize if not
- Pattern: counting/accumulating with dictionaries

### Problem 9: Swap with Tuple

**Thinking Process:**
Tuple unpacking allows simultaneous assignment. Right side evaluated before assignment.

**Solution:**
```python
a = 10
b = 20

# Swap using tuple unpacking
a, b = b, a

print(f"a={a}, b={b}")  # a=20, b=10
```

**Key Points:**
- `a, b = b, a` swaps without temporary variable
- Right side `(b, a)` creates tuple with current values
- Left side unpacks into variables
- All happens simultaneously

### Problem 10: Set Membership Speed Test

**Thinking Process:**
This demonstrates why sets are faster. Lists check each item; sets use hashing for instant lookup.

**Solution:**
```python
# Create list and set with same data
numbers_list = list(range(1, 1001))
numbers_set = set(range(1, 1001))

# Both work, but set is much faster for large collections
print(500 in numbers_list)  # True (checks each item)
print(500 in numbers_set)   # True (instant hash lookup)
```

**Key Points:**
- List membership: O(n) - checks each item sequentially
- Set membership: O(1) - hash lookup is instant
- Performance difference matters with large datasets
- Use sets when frequent membership testing needed

## Level 3: Nested Structures (Problems 11-15)

### Problem 11: List of Tuples

**Thinking Process:**
Sort by specific element using `key` parameter. Lambda extracts the element to sort by.

**Solution:**
```python
people = [("Alice", 25), ("Bob", 30), ("Charlie", 22)]

# Sort by age (second element, index 1)
sorted_people = sorted(people, key=lambda person: person[1])

print(sorted_people)  # [('Charlie', 22), ('Alice', 25), ('Bob', 30)]
```

**Key Points:**
- `sorted(list, key=function)` sorts by custom criteria
- `lambda person: person[1]` extracts age for comparison
- Returns new sorted list, original unchanged
- Lambda is shorthand function for simple operations

### Problem 12: 2D List (Matrix)

**Thinking Process:**
Matrix is list of lists. Each inner list is a row. Access: `matrix[row][col]`.

**Solution:**
```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Print in grid format
for row in matrix:
    for item in row:
        print(item, end=" ")
    print()  # New line after each row

# Access center element
center = matrix[1][1]
print(f"\nCenter element: {center}")  # 5
```

**Key Points:**
- Nested loops for 2D structure: outer for rows, inner for items
- Access element: `matrix[row_index][col_index]`
- Center of 3x3 is `[1][1]` (middle row, middle column)

### Problem 13: Dictionary of Lists

### Problem 17: Matrix Operations

**Thinking Process:**
Sum all: nested loops. Row sums: inner loop per row. Column sums: iterate rows for same column index.

**Solution:**
```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Sum all elements
total = 0
for row in matrix:
    for num in row:
        total += num
print(f"Total sum: {total}")  # 45

# Sum each row
print("Row sums:")
for i, row in enumerate(matrix):
    row_sum = sum(row)
    print(f"  Row {i}: {row_sum}")

# Sum each column
print("Column sums:")
for col in range(3):
    col_sum = 0
    for row in matrix:
        col_sum += row[col]
    print(f"  Column {col}: {col_sum}")
```

**Key Points:**
- Total: nested loops accumulate all values
- Row sum: `sum(row)` for each row
- Column sum: fix column index, iterate rows: `row[col]`
- `enumerate()` provides index with value

### Problem 20: Flatten Nested List

**Thinking Process:**
Nested loops: outer iterates sublists, inner iterates items in each sublist. Append all to single list.

**Solution:**
```python
nested = [[1, 2, 3], [4, 5], [6, 7, 8, 9]]
flattened = []

for sublist in nested:
    for item in sublist:
        flattened.append(item)

print(flattened)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

**Key Points:**
- Outer loop: each sublist
- Inner loop: each item in sublist
- Append to single result list
- Alternative: list comprehension `[item for sublist in nested for item in sublist]`

### Problem 23: Save and Load JSON

**Thinking Process:**
Use `json.dump()` to write to file, `json.load()` to read from file. File operations need `with open()`.

**Solution:**
```python
import json

students = [
    {"name": "Alice", "grade": 85},
    {"name": "Bob", "grade": 92}
]

# Save to file
with open("students.json", "w") as file:
    json.dump(students, file, indent=4)

# Load from file
with open("students.json", "r") as file:
    loaded_data = json.load(file)

print(loaded_data)
```

**Key Points:**
- `json.dump(data, file)` writes to file (note: `dump` not `dumps`)
- `json.load(file)` reads from file (note: `load` not `loads`)
- `with open()` handles file opening/closing
- `"w"` for write, `"r"` for read

### Problem 25: GPS Trip Calculator

**Thinking Process:**
Most complex problem. Create data structure, calculate distances, build summary dict, export to JSON.

**Solution:**
```python
import json
import math

def calculate_distance(coord1, coord2):
    """Simplified distance calculation."""
    lat1, lon1 = coord1
    lat2, lon2 = coord2
    distance = math.sqrt((lat2 - lat1)**2 + (lon2 - lon1)**2) * 111
    return distance

# Trip locations
locations = [
    ("Calgary", (51.0447, -114.0719)),
    ("Banff", (51.1784, -115.5708)),
    ("Lake Louise", (51.4254, -116.1773)),
    ("Jasper", (52.8737, -118.0814))
]

# Calculate segments
segments = []
total_distance = 0

for i in range(len(locations) - 1):
    city1, coord1 = locations[i]
    city2, coord2 = locations[i + 1]
    
    distance = calculate_distance(coord1, coord2)
    total_distance += distance
    
    segments.append({
        "from": city1,
        "to": city2,
        "distance_km": round(distance, 2)
    })

# Create summary dictionary
trip_summary = {
    "trip_name": "Alberta Tour",
    "locations": [{"city": name, "coordinates": coords} for name, coords in locations],
    "segments": segments,
    "total_distance_km": round(total_distance, 2)
}

# Save to JSON
with open("trip_summary.json", "w") as file:
    json.dump(trip_summary, file, indent=4)

print("Trip summary saved to trip_summary.json")
print(f"Total distance: {trip_summary['total_distance_km']} km")
```

**Key Points:**
- Function with tuple parameters for GPS calculations
- Loop through consecutive pairs: `range(len(list) - 1)`
- Unpack nested tuples: `city, coord = location`
- Build list of dicts with `.append()`
- List comprehension for formatting: `[{} for item in list]`
- Complete workflow: calculate, structure, serialize, save

**This combines:**
- Functions with tuple parameters
- Nested data structures (dicts, lists, tuples)
- Mathematical calculations
- Data aggregation (segments list, total)
- JSON serialization
- File I/O operations

## Key Takeaways from Solutions

### Data Structure Selection:
1. **Tuples for paired data** - coordinates, name-value pairs that shouldn't change
2. **Sets for uniqueness** - removing duplicates, fast membership testing
3. **Dictionaries for lookups** - key-value relationships, structured records
4. **Lists for ordered collections** - when order matters, needs to change

### Nesting Patterns:
5. **List of tuples** - records with fixed fields
6. **Dictionary of lists** - grouped data (student → grades)
7. **List of dictionaries** - collection of records (inventory, API results)
8. **Dictionary of dictionaries** - hierarchical data (departments → info)

### JSON Operations:
9. **Serialization** - Python → JSON with `dumps()` or `dump()`
10. **Deserialization** - JSON → Python with `loads()` or `load()`
11. **File operations** - use `dump`/`load` for files, `dumps`/`loads` for strings
12. **Pretty printing** - use `indent` parameter for readability

### Access Patterns:
13. **Chain access** - `dict["key1"]["key2"]["key3"]` for nested dicts
14. **Mixed access** - `dict["key"][index]` for list within dict
15. **Unpacking** - `for name, (x, y) in list` for nested tuples
16. **Safe access** - use `.get()` for optional keys
