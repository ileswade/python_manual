## Testing Tips

1. **Test with print statements:** Print intermediate values to understand what's happening

2. **Check types:** Use `type()` to verify what data structure you're working with

3. **Access patterns:**
   - List/Tuple: `[index]`
   - Dictionary: `["key"]` or `.get("key")`
   - Set: `in` for membership

4. **JSON gotchas:**
   - Python `True/False` → JSON `true/false`
   - Python `None` → JSON `null`
   - Tuples become lists in JSON

5. **Nested access:** Build step by step, test each level before going deeper

---

## Common Mistakes to Watch For

- **Modifying tuples:** They're immutable!
- **Duplicate keys in dictionaries:** Last value wins
- **JSON formatting:** Use `json.dumps()` with `indent` for readability
- **Nested KeyError:** Use `.get()` for safe access
- **Set ordering:** Sets are unordered, don't expect specific order
- **Tuple single item:** Need comma: `(42,)` not `(42)`
