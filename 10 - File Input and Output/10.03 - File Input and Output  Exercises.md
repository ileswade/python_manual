### Example 1: Reading and Processing a Configuration File with Error Handling
**Problem:** Create a program that reads a configuration file in the format "key=value" (one per line). Parse the file, create a dictionary, and handle FileNotFoundError and parsing errors. Use the `with` statement for proper file handling. Comments (lines starting with #) should be ignored.

**Detailed Solution:**

**Step 1: Understand the file format**
```
# Configuration file
username=admin
port=8080
debug=true
# This is a comment
timeout=30
```

**Step 2: Plan the parsing logic**
1. Open file with `with` statement
2. Read line by line
3. Skip empty lines and comments
4. Split by '=' to get key and value
5. Store in dictionary

**Step 3: Identify potential errors**
- FileNotFoundError: File doesn't exist
- ValueError: Line doesn't contain '='
- General parsing issues

**Step 4: Implement with comprehensive error handling**

**Complete Solution:**
```python
def load_config(filename):
    """
    Load configuration from file.
    Format: key=value (one per line)
    Lines starting with # are comments.
    """
    config = {}
    
    try:
        with open(filename, 'r') as file:
            line_number = 0
            
            for line in file:
                line_number += 1
                
                # Remove whitespace
                line = line.strip()
                
                # Skip empty lines and comments
                if not line or line.startswith('#'):
                    continue
                
                # Parse key=value
                if '=' not in line:
                    print(f"Warning: Line {line_number} has no '=' - skipping")
                    continue
                
                # Split by first '='
                key, value = line.split('=', 1)
                key = key.strip()
                value = value.strip()
                
                if not key:
                    print(f"Warning: Line {line_number} has empty key - skipping")
                    continue
                
                config[key] = value
                
    except FileNotFoundError:
        print(f"Error: Configuration file '{filename}' not found")
        print("Using default configuration")
        return {}
        
    except PermissionError:
        print(f"Error: No permission to read '{filename}'")
        return {}
        
    except Exception as e:
        print(f"Error reading config: {e}")
        return {}
    
    else:
        print(f"Successfully loaded {len(config)} configuration items")
        
    return config


def save_config(filename, config):
    """Save configuration dictionary to file."""
    try:
        with open(filename, 'w') as file:
            # Write header comment
            file.write("# Configuration File\n")
            file.write(f"# Generated automatically\n\n")
            
            # Write each key=value pair
            for key, value in config.items():
                file.write(f"{key}={value}\n")
                
    except PermissionError:
        print(f"Error: No permission to write to '{filename}'")
        return False
        
    except IOError as e:
        print(f"Error writing config: {e}")
        return False
        
    else:
        print(f"Configuration saved to '{filename}'")
        return True
```

**Key Concepts:**
- **with statement**: Automatically closes file
- **Line-by-line reading**: Memory efficient for large files
- **strip()**: Remove whitespace from both ends
- **split('=', 1)**: Split only on first occurrence
- **Error handling**: Specific messages for each error type
- **else clause**: Runs only on success
- **Comments**: Lines starting with # are ignored
- **Validation**: Check for empty keys, missing '='

**Why this works:**
- with guarantees file closure even on error
- Line-by-line processing handles large files
- split('=', 1) allows '=' in values
- Comprehensive error handling prevents crashes
- Returns empty dict on error (safe default)

### Example 2: Log File Analysis with Multiple File Operations
**Problem:** Create a log file analyzer that: (1) reads a log file, (2) counts occurrences of different log levels (INFO, WARNING, ERROR), (3) extracts error messages, and (4) writes a summary report to a new file. Handle all file I/O errors appropriately.

**Detailed Solution:**

**Step 1: Understand log file format**
```
[2024-01-15 10:30:45] INFO: Application started
[2024-01-15 10:31:12] ERROR: Database connection failed
[2024-01-15 10:31:30] WARNING: High memory usage
[2024-01-15 10:32:01] INFO: User logged in
[2024-01-15 10:32:45] ERROR: File not found: data.txt
```

**Step 2: Plan the analysis**
1. Read log file line by line
2. Parse each line for log level
3. Count occurrences
4. Extract error messages
5. Generate summary report

**Step 3: Implement with error handling**

**Complete Solution:**
```python
import os
from datetime import datetime

def analyze_log_file(log_filename, output_filename):
    """
    Analyze log file and create summary report.
    """
    # Initialize counters
    log_counts = {
        'INFO': 0,
        'WARNING': 0,
        'ERROR': 0,
        'OTHER': 0
    }
    
    error_messages = []
    total_lines = 0
    
    # Read and analyze log file
    try:
        print(f"Reading log file: {log_filename}")
        
        with open(log_filename, 'r') as log_file:
            for line in log_file:
                total_lines += 1
                line = line.strip()
                
                if not line:
                    continue
                
                # Determine log level
                if 'INFO:' in line:
                    log_counts['INFO'] += 1
                elif 'WARNING:' in line:
                    log_counts['WARNING'] += 1
                elif 'ERROR:' in line:
                    log_counts['ERROR'] += 1
                    # Extract error message
                    if 'ERROR:' in line:
                        error_msg = line.split('ERROR:', 1)[1].strip()
                        error_messages.append(error_msg)
                else:
                    log_counts['OTHER'] += 1
                    
    except FileNotFoundError:
        print(f"Error: Log file '{log_filename}' not found")
        return False
        
    except PermissionError:
        print(f"Error: No permission to read '{log_filename}'")
        return False
        
    except Exception as e:
        print(f"Error reading log file: {e}")
        return False
    
    # Generate summary report
    try:
        print(f"Generating report: {output_filename}")
        
        with open(output_filename, 'w') as report_file:
            # Write header
            report_file.write("=" * 50 + "\n")
            report_file.write("LOG ANALYSIS REPORT\n")
            report_file.write("=" * 50 + "\n\n")
            
            # Write timestamp
            timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
            report_file.write(f"Generated: {timestamp}\n")
            report_file.write(f"Source: {log_filename}\n\n")
            
            # Write statistics
            report_file.write("=" * 50 + "\n")
            report_file.write("STATISTICS\n")
            report_file.write("=" * 50 + "\n\n")
            report_file.write(f"Total lines processed: {total_lines}\n\n")
            
            report_file.write("Log Level Counts:\n")
            for level, count in log_counts.items():
                if count > 0:
                    percentage = (count / total_lines) * 100
                    report_file.write(f"  {level}: {count} ({percentage:.1f}%)\n")
            
            # Write error messages
            if error_messages:
                report_file.write("\n" + "=" * 50 + "\n")
                report_file.write("ERROR MESSAGES\n")
                report_file.write("=" * 50 + "\n\n")
                
                for i, error in enumerate(error_messages, 1):
                    report_file.write(f"{i}. {error}\n")
            
            # Write summary
            report_file.write("\n" + "=" * 50 + "\n")
            report_file.write("SUMMARY\n")
            report_file.write("=" * 50 + "\n\n")
            
            if log_counts['ERROR'] > 0:
                report_file.write(f"⚠ {log_counts['ERROR']} errors detected!\n")
            else:
                report_file.write("✓ No errors found\n")
            
            if log_counts['WARNING'] > 0:
                report_file.write(f"⚠ {log_counts['WARNING']} warnings found\n")
            
            report_file.write(f"\nReport complete.\n")
            
    except PermissionError:
        print(f"Error: No permission to write to '{output_filename}'")
        return False
        
    except IOError as e:
        print(f"Error writing report: {e}")
        return False
    
    else:
        print(f"✓ Report generated successfully")
        print(f"  Total lines: {total_lines}")
        print(f"  Errors found: {log_counts['ERROR']}")
        print(f"  Warnings found: {log_counts['WARNING']}")
        return True
```

### Example 3: CSV File Processing with Data Validation
**Problem:** Create a program that reads a CSV file containing student grades, validates the data, calculates statistics, and writes results to a new file. Handle malformed CSV data, missing values, and file I/O errors.

**Detailed Solution:**

**Step 1: Understand CSV format**
```
Name,Math,Science,English
Alice,85,92,88
Bob,78,invalid,85
Charlie,90,88,92
Diana,95,89
```

**Step 2: Plan data processing**
1. Read CSV file
2. Validate each row
3. Calculate averages
4. Handle missing/invalid data
5. Write results

**Step 3: Implement with validation**

**Complete Solution:**
```python
def read_student_data(filename):
    """
    Read and validate student data from CSV.
    Returns: (students_data, errors)
    """
    students = []
    errors = []
    
    try:
        with open(filename, 'r') as file:
            # Read header
            header = file.readline().strip().split(',')
            expected_cols = 4  # Name, Math, Science, English
            
            if len(header) != expected_cols:
                errors.append(f"Invalid header: expected {expected_cols} columns")
                return [], errors
            
            line_num = 1
            
            # Process each student
            for line in file:
                line_num += 1
                line = line.strip()
                
                if not line:
                    continue
                
                parts = line.split(',')
                
                # Validate column count
                if len(parts) < expected_cols:
                    errors.append(f"Line {line_num}: Missing data ({len(parts)}/{expected_cols} columns)")
                    continue
                
                name = parts[0].strip()
                
                # Validate and convert grades
                try:
                    math_grade = int(parts[1].strip())
                    science_grade = int(parts[2].strip())
                    english_grade = int(parts[3].strip())
                    
                    # Validate grade ranges
                    grades = [math_grade, science_grade, english_grade]
                    if any(g < 0 or g > 100 for g in grades):
                        errors.append(f"Line {line_num}: Grades must be 0-100")
                        continue
                    
                    # Calculate average
                    average = sum(grades) / len(grades)
                    
                    students.append({
                        'name': name,
                        'math': math_grade,
                        'science': science_grade,
                        'english': english_grade,
                        'average': average
                    })
                    
                except ValueError as e:
                    errors.append(f"Line {line_num}: Invalid grade format - {e}")
                    continue
                    
    except FileNotFoundError:
        errors.append(f"File '{filename}' not found")
        return [], errors
        
    except PermissionError:
        errors.append(f"No permission to read '{filename}'")
        return [], errors
        
    except Exception as e:
        errors.append(f"Error reading file: {e}")
        return [], errors
    
    return students, errors


def write_results(filename, students, errors):
    """Write processed results to file."""
    try:
        with open(filename, 'w') as file:
            # Write header
            file.write("=" * 60 + "\n")
            file.write("STUDENT GRADE REPORT\n")
            file.write("=" * 60 + "\n\n")
            
            # Write errors if any
            if errors:
                file.write("ERRORS ENCOUNTERED:\n")
                file.write("-" * 60 + "\n")
                for error in errors:
                    file.write(f"  • {error}\n")
                file.write("\n")
            
            # Write student data
            if students:
                file.write("STUDENT GRADES:\n")
                file.write("-" * 60 + "\n\n")
                
                # Table header
                file.write(f"{'Name':<15} {'Math':>6} {'Science':>8} {'English':>8} {'Average':>8}\n")
                file.write("-" * 60 + "\n")
                
                # Student rows
                for student in students:
                    file.write(
                        f"{student['name']:<15} "
                        f"{student['math']:>6} "
                        f"{student['science']:>8} "
                        f"{student['english']:>8} "
                        f"{student['average']:>8.1f}\n"
                    )
                
                # Statistics
                file.write("\n" + "=" * 60 + "\n")
                file.write("STATISTICS\n")
                file.write("=" * 60 + "\n\n")
                
                all_averages = [s['average'] for s in students]
                file.write(f"Total students: {len(students)}\n")
                file.write(f"Class average: {sum(all_averages)/len(all_averages):.2f}\n")
                file.write(f"Highest average: {max(all_averages):.2f}\n")
                file.write(f"Lowest average: {min(all_averages):.2f}\n")
            
            else:
                file.write("No valid student data found.\n")
                
    except PermissionError:
        print(f"Error: No permission to write to '{filename}'")
        return False
    except IOError as e:
        print(f"Error writing file: {e}")
        return False
    
    return True
```

## Tips for Solving These Problems

### File Opening Modes
```python
'r'   # Read (default)
'w'   # Write (overwrites)
'a'   # Append
'r+'  # Read and write
'w+'  # Write and read (overwrites)
'rb'  # Read binary
'wb'  # Write binary
```

### Always Use 'with' Statement
```python
# Good - file automatically closes
with open('file.txt', 'r') as f:
    content = f.read()

# Bad - must remember to close
f = open('file.txt', 'r')
content = f.read()
f.close()  # What if error occurs before this?
```

### Reading Methods
```python
content = f.read()          # Entire file as string
lines = f.readlines()       # List of lines
line = f.readline()         # One line

# Best for large files:
for line in f:              # Iterate line by line
    process(line)
```

### Common File Patterns

**Pattern 1: Read entire file**
```python
try:
    with open('file.txt', 'r') as f:
        content = f.read()
except FileNotFoundError:
    print("File not found")
```

**Pattern 2: Process line by line**
```python
with open('file.txt', 'r') as f:
    for line in f:
        print(line.strip())
```

**Pattern 3: Write to file**
```python
with open('output.txt', 'w') as f:
    f.write("Line 1\n")
    f.write("Line 2\n")
```

**Pattern 4: Append to file**
```python
with open('log.txt', 'a') as f:
    f.write(f"[{timestamp}] {message}\n")
```

**Pattern 5: Copy file**
```python
with open('source.txt', 'r') as src:
    with open('dest.txt', 'w') as dst:
        dst.write(src.read())
```

### Error Handling for Files
```python
try:
    with open('file.txt', 'r') as f:
        content = f.read()
except FileNotFoundError:
    print("File not found")
except PermissionError:
    print("No permission")
except IOError as e:
    print(f"I/O error: {e}")
```

### Best Practices
1. **Always use 'with'** - Ensures file closes
2. **Handle specific exceptions** - FileNotFoundError, PermissionError, IOError
3. **Validate data** - Check format, ranges, completeness
4. **Use text mode for text** - Binary mode only for images, etc.
5. **Close files properly** - 'with' does this automatically
6. **Check file existence** - Before operations when appropriate
7. **Create backups** - Before destructive operations
8. **Use appropriate modes** - 'w' overwrites, 'a' appends
9. **Strip whitespace** - line.strip() removes \n and spaces
10. **Use os.path** - For cross-platform paths
