# What is File I/O? 📁

**File I/O** is reading data from files and writing data to files. It's how programs save and retrieve information that **persists between runs**.

<v-clicks>

### Three Basic Operations

1. **Opening** a file - getting access to it
2. **Reading/Writing** - getting data from it or putting data into it
3. **Closing** a file - releasing it when done

### Why File I/O Matters

**Before:** Your program starts fresh every time
```
User enters data → Program processes → Program ends → Data lost!
```

**After:** Your program remembers
```
User enters data → Save to file → Program ends → Next run: Load from file!
```

</v-clicks>

# File Modes: How to Open Files 🔐

When opening a file, you must specify the **mode** - what you want to do with it:

<v-clicks>

| Mode | Description | Creates if Missing? | Truncates Existing? |
|------|-------------|---------------------|---------------------|
| `'r'` | **Read** (default) | ❌ No (raises error) | ❌ No |
| `'w'` | **Write** | ✅ Yes | ⚠️ **Yes** |
| `'a'` | **Append** | ✅ Yes | ❌ No |
| `'r+'` | **Read + Write** | ❌ No (raises error) | ❌ No |
| `'w+'` | **Write + Read** | ✅ Yes | ⚠️ **Yes** |
| `'a+'` | **Append + Read** | ✅ Yes | ❌ No |

**Binary modes:** Add `'b'` → `'rb'`, `'wb'`, `'ab'` for images, videos, etc.

</v-clicks>

<v-click>

<div class="mt-4 p-4 bg-red-100 dark:bg-red-900 rounded">
⚠️ <strong>Warning:</strong> Mode <code>'w'</code> <strong>overwrites existing files completely!</strong> Use with caution.
</div>

</v-click>

# Reading Files: Getting Data In 📖

### The Old Way (Not Recommended)

<v-clicks>

```python
# Open file
file = open("data.txt", "r")

# Read entire file
content = file.read()
print(content)

# Close file (important!)
file.close()
```

**Problems with this approach:**
- If error occurs, file might not close
- Manual cleanup required
- Easy to forget `file.close()`

</v-clicks>

---

# The Better Way: Using `with` Statement ✨

<v-clicks>

```python
with open("data.txt", "r") as file:
    content = file.read()
    print(content)
# File automatically closes when exiting the 'with' block
```

**Why `with` is better:**
- **Automatically closes file** (even if error occurs)
- No need to remember `file.close()`
- **Best practice** for file operations
- Uses **context manager** pattern for safety

</v-clicks>

<v-click>

<div class="mt-4 p-4 bg-green-100 dark:bg-green-900 rounded">
✅ <strong>Always use the `with` statement for file operations!</strong> It's safer and more professional.
</div>

</v-click>

# Reading Methods: Different Ways to Get Content 📚

### read() - Read Entire File

<v-clicks>

```python
with open("data.txt", "r") as file:
    content = file.read()  # Gets everything as one string
    print(content)
```

### readline() - Read One Line at a Time

```python
with open("data.txt", "r") as file:
    line1 = file.readline()
    line2 = file.readline()
    print(line1)
    print(line2)
```

### readlines() - Read All Lines into List

```python
with open("data.txt", "r") as file:
    lines = file.readlines()
    # Returns: ['line 1\n', 'line 2\n', 'line 3\n']

for line in lines:
    print(line.strip())  # strip() removes \n
```

</v-clicks>

---

# Best Method: Iterate Over File (Memory Efficient) 🔄

<v-clicks>

```python
with open("data.txt", "r") as file:
    for line in file:
        print(line.strip())
```

**Why this is best:**
- **Memory efficient** - reads one line at a time, not all at once
- **Works with huge files** - doesn't load everything into memory
- **Simple syntax** - clean and readable
- **Automatic handling** - no need to manage line reading

</v-clicks>

<v-click>

**Perfect for:**
- Processing large log files
- Reading CSV data
- Analyzing text files line by line
- Any file where you process sequentially

</v-click>

---

# Reading with Exception Handling 🛡️

<v-clicks>

```python
try:
    with open("data.txt", "r") as file:
        content = file.read()
        print(content)
except FileNotFoundError:
    print("Error: File 'data.txt' not found!")
except PermissionError:
    print("Error: No permission to read this file!")
except Exception as e:
    print(f"Unexpected error: {e}")
```

**Common file exceptions:**
- `FileNotFoundError` - file doesn't exist
- `PermissionError` - insufficient access rights
- `IOError` - general input/output problems
- `UnicodeDecodeError` - file encoding issues

</v-clicks>

# Writing to Files: Saving Data 💾

### Basic Writing with write()

<v-clicks>

```python
with open("output.txt", "w") as file:
    file.write("Hello, World!\n")
    file.write("This is a new file.\n")
```

**Important Notes:**
- Mode `'w'` **overwrites** existing files completely!
- Must add `\n` manually for new lines
- `write()` only accepts strings

### Writing Multiple Lines with writelines()

```python
lines = ["First line\n", "Second line\n", "Third line\n"]

with open("output.txt", "w") as file:
    file.writelines(lines)
```

**Note:** `writelines()` doesn't add newlines automatically!

</v-clicks>

---

# Appending to Files: Adding Without Overwriting ➕

<v-clicks>

Use mode `'a'` to **add to existing file** without overwriting:

```python
with open("log.txt", "a") as file:
    file.write("New log entry\n")
    file.write("Another entry\n")
```

**Append vs Write:**
- **Write mode (`'w'`)**: Erases existing content, starts fresh
- **Append mode (`'a'`)**: Keeps existing content, adds to end

</v-clicks>

<v-click>

### Writing with Exception Handling

```python
try:
    with open("output.txt", "w") as file:
        file.write("Important data\n")
        print("File written successfully!")
except PermissionError:
    print("Error: No permission to write to this file!")
except IOError as e:
    print(f"Error writing to file: {e}")
```

</v-click>

# Practical Example: Configuration File Manager 🔧

<v-clicks>

```python
def load_config(filename):
    """Load configuration from file."""
    config = {}

    try:
        with open(filename, "r") as file:
            for line in file:
                line = line.strip()
                if line and '=' in line:
                    key, value = line.split('=', 1)
                    config[key.strip()] = value.strip()
    except FileNotFoundError:
        print(f"Config file '{filename}' not found. Using defaults.")

    return config

# config.txt contents:
# username=alice
# theme=dark
# font_size=14

config = load_config("config.txt")
print(config)  # {'username': 'alice', 'theme': 'dark', 'font_size': '14'}
```

</v-clicks>

# Practical Example: Log File Writer 📋

<v-clicks>

```python
from datetime import datetime

def log_message(message, filename="app.log"):
    """Append timestamped message to log file."""
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    log_entry = f"[{timestamp}] {message}\n"

    try:
        with open(filename, "a") as file:
            file.write(log_entry)
    except IOError as e:
        print(f"Failed to write to log: {e}")

# Usage
log_message("Application started")
log_message("User logged in")
log_message("Error: Failed to connect to database")
```

**Creates entries like:**
```
[2024-03-15 14:30:22] Application started
[2024-03-15 14:30:25] User logged in
[2024-03-15 14:30:28] Error: Failed to connect to database
```

# Working with JSON: Structured Data 📊

**JSON** is perfect for saving structured data (dictionaries, lists, etc.):

<v-clicks>

import json

# Save data to JSON
data = {

with open("data.json", "w") as file:

**JSON advantages:**

# Practical Example: High Score System 🏆

<v-clicks>

```python
import json

def save_high_scores(scores, filename="highscores.json"):
    """Save high scores to JSON file."""
    try:
        with open(filename, "w") as file:
            json.dump(scores, file, indent=4)
        print(f"High scores saved to {filename}")
    except IOError as e:
        print(f"Error saving scores: {e}")

def load_high_scores(filename="highscores.json"):
    """Load high scores from JSON file."""
    try:
        with open(filename, "r") as file:
            return json.load(file)
    except FileNotFoundError:
        print("No high scores file found. Starting fresh.")
        return []
    except json.JSONDecodeError:
        print("Error: Invalid JSON format. Starting fresh.")
        return []

# Usage
high_scores = [
    {"name": "Alice", "points": 1000},
    {"name": "Bob", "points": 850},
    {"name": "Charlie", "points": 900}
]

save_high_scores(high_scores)
loaded_scores = load_high_scores()
print(loaded_scores)
```

# Working with File Paths 🗂️

Use the `os` module for cross-platform file operations:

<v-clicks>

```python
import os

# Check if file exists
if os.path.exists("data.txt"):
    print("File exists!")

# Check if it's a file (not directory)
if os.path.isfile("data.txt"):
    print("It's a file!")

# Get absolute path
abs_path = os.path.abspath("data.txt")
print(f"Absolute path: {abs_path}")

# Join paths (works on all OS)
file_path = os.path.join("folder", "subfolder", "file.txt")
print(file_path)  # folder/subfolder/file.txt (or folder\subfolder\file.txt on Windows)

# Split path into directory and filename
directory, filename = os.path.split("/path/to/file.txt")
print(f"Directory: {directory}")  # /path/to
print(f"Filename: {filename}")    # file.txt
```

# Binary Files: Images, Videos, etc. 🖼️

For non-text files (images, videos, executables), use binary mode:

<v-clicks>

### Reading Binary Files

```python
# Read image file
with open("image.jpg", "rb") as file:
    data = file.read()
    print(f"File size: {len(data)} bytes")
```

### Writing Binary Files

```python
# Copy a file
with open("source.jpg", "rb") as source:
    data = source.read()

with open("destination.jpg", "wb") as destination:
    destination.write(data)

print("File copied successfully!")
```

**Binary vs Text mode:**
- **Text mode (`'r'`, `'w'`)**: For human-readable files (text, code, JSON)
- **Binary mode (`'rb'`, `'wb'`)**: For everything else (images, videos, executables)

</v-clicks>

# File Copy Utility Example 📋

<v-clicks>

```python
def copy_file(source, destination):
    """Copy file from source to destination with error handling."""
    try:
        with open(source, "rb") as src:
            data = src.read()

        with open(destination, "wb") as dst:
            dst.write(data)

        print(f"Copied {source} to {destination}")
        return True

    except FileNotFoundError:
        print(f"Error: Source file '{source}' not found!")
        return False
    except PermissionError:
        print("Error: Permission denied!")
        return False
    except Exception as e:
        print(f"Error copying file: {e}")
        return False

# Usage
copy_file("document.pdf", "backup/document.pdf")
copy_file("image.jpg", "gallery/image.jpg")
```

</v-clicks>

# Common File Operation Patterns 🔄

### Pattern 1: Read, Process, Write

<v-clicks>

```python
def process_file(input_file, output_file):
    """Read file, process each line, write result."""
    try:
        with open(input_file, "r") as infile:
            lines = infile.readlines()

        # Process lines (example: convert to uppercase)
        processed_lines = [line.upper() for line in lines]

        with open(output_file, "w") as outfile:
            outfile.writelines(processed_lines)

        print(f"Processed {len(lines)} lines")
    except FileNotFoundError:
        print(f"Error: '{input_file}' not found!")
    except IOError as e:
        print(f"Error: {e}")

process_file("input.txt", "output.txt")
```

</v-clicks>

# Pattern 2: Safe File Update with Backup 🔄

<v-clicks>

```python
import shutil
import os

def update_file_safely(filename, new_content):
    """Update file with automatic backup."""
    backup_file = filename + ".backup"

    try:
        # Create backup if file exists
        if os.path.exists(filename):
            shutil.copy(filename, backup_file)

        # Write new content
        with open(filename, "w") as file:
            file.write(new_content)

        print("File updated successfully!")

        # Remove backup if successful
        if os.path.exists(backup_file):
            os.remove(backup_file)

    except Exception as e:
        print(f"Error updating file: {e}")
        # Restore backup if it exists
        if os.path.exists(backup_file):
            shutil.copy(backup_file, filename)
            print("Restored from backup")

update_file_safely("config.txt", "new configuration data")
```

# Best Practices: File I/O Guidelines 📝

<div class="grid grid-cols-2 gap-6 text-sm">

<div>

<v-click>

### ✅ Do's

**Always use `with` statement:**
```python
with open("file.txt", "r") as f:
    content = f.read()
```

**Handle exceptions:**
```python
try:
    with open("file.txt", "r") as f:
        content = f.read()
except FileNotFoundError:
    print("File not found!")
```

**Use appropriate modes:**
- `'r'` for reading existing files
- `'w'` for creating new files (overwrites!)
- `'a'` for appending to existing files

</v-click>

</div>

<div>

<v-click>

### ❌ Don'ts

**Don't forget to close files:**
```python
# Bad
f = open("file.txt", "r")
content = f.read()
# Forgot f.close()!
```

**Don't use 'w' without checking:**
```python
# Bad - overwrites existing file!
with open("important.txt", "w") as f:
    f.write("Oops!")
```

**Don't ignore errors:**
```python
# Bad
with open("file.txt", "r") as f:
    content = f.read()
# What if file doesn't exist?
```

</v-click>
