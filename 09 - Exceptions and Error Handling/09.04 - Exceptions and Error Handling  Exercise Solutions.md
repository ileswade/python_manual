## Basic Try-Except (Questions 1-5)

### Question 1
**Problem:** Write a program that asks for a number and converts it to int. Use try-except to handle ValueError if user enters non-numeric text.

**Solution Approach:**
- Use input() to get user input as string
- Try to convert to int inside try block
- Catch ValueError if conversion fails
- Provide helpful error message

**Complete Solution:**
```python
# Get input from user
user_input = input("Enter a number: ")

# Try to convert to integer
try:
    number = int(user_input)
    print(f"You entered the number: {number}")
except ValueError:
    print(f"Error: '{user_input}' is not a valid number!")
    print("Please enter a numeric value.")
```

**Sample Run (valid input):**
```
Enter a number: 42
You entered the number: 42
```

**Sample Run (invalid input):**
```
Enter a number: hello
Error: 'hello' is not a valid number!
Please enter a numeric value.
```

**Key Concepts:**
- ValueError raised when int() receives non-numeric string
- try block contains risky code (conversion)
- except block handles the error gracefully
- Program doesn't crash, provides feedback

### Question 6
**Problem:** Write a function that converts a string to integer. Use try-except for ValueError and else to print success message only when conversion works.

**Solution Approach:**
- Function takes string parameter
- Try to convert in try block
- Catch ValueError in except
- Use else for success message (only runs if no exception)

**Complete Solution:**
```python
def convert_to_int(string_value):
    """Convert string to integer with error handling."""
    try:
        number = int(string_value)
    except ValueError:
        print(f"Error: Cannot convert '{string_value}' to integer")
        return None
    else:
        # This only runs if conversion succeeded
        print(f"Success: Converted '{string_value}' to {number}")
        return number

# Test the function
test_values = ["42", "hello", "100", "3.14", "-5"]

for value in test_values:
    result = convert_to_int(value)
    print(f"Result: {result}\n")
```

```
Result: None

Success: Converted '-5' to -5
Result: -5
```

**Key Concepts:**
- else clause runs only if try succeeds (no exception)
- Separates success logic from error handling
- Return None on error, integer on success
- else makes it clear what happens on success

## Try-Except-Finally (Questions 11-15)

### Question 11
**Problem:** Open a file, read it, and close it using try-except-finally. Ensure the file closes even if an error occurs.

**Solution Approach:**
- Open file in try block
- Handle exceptions in except
- Use finally to ensure file closes
- finally runs whether error occurred or not

**Complete Solution:**
```python
filename = "data.txt"
file = None

try:
    print(f"Attempting to open '{filename}'...")
    file = open(filename, 'r')
    print("File opened successfully")
    
    content = file.read()
    print(f"\n=== Contents ===")
    print(content)
    
except FileNotFoundError:
    print(f"Error: File '{filename}' not found!")
except IOError as e:
    print(f"Error reading file: {e}")
finally:
    # This ALWAYS runs
    if file:
        file.close()
        print("\nFile closed in finally block")
    else:
        print("\nNo file to close (never opened)")
```

**Output (file exists):**
```
Attempting to open 'data.txt'...
File opened successfully

=== Contents ===
Sample content here

File closed in finally block
```

**Output (file not found):**
```
Attempting to open 'missing.txt'...
Error: File 'missing.txt' not found!

No file to close (never opened)
```

**Key Concepts:**
- finally always runs (error or not)
- Use finally for cleanup (closing files)
- Check if file exists before closing
- Better: use 'with' statement (auto-closes)

### Question 15
**Problem:** Create a function that opens and writes to a file. Use finally to ensure the file is always closed, even if writing fails.

**Solution Approach:**
- Open file in try block
- Write content
- Handle IOError
- Use finally to close file

**Complete Solution:**
```python
def write_to_file_with_finally(filename, content):
    """Write to file with finally clause."""
    file = None
    
    try:
        print(f"Opening '{filename}' for writing...")
        file = open(filename, 'w')
        
        print(f"Writing {len(content)} characters...")
        file.write(content)
        
        print("Write successful!")
        
    except PermissionError:
        print(f"Error: No permission to write to '{filename}'")
    except IOError as e:
        print(f"Error: {e}")
    finally:
        # Always close the file
        if file:
            file.close()
            print(f"File '{filename}' closed")
        print("Write operation complete\n")

# Test the function
test_content = "This is test data.\nLine 2\nLine 3"

write_to_file_with_finally("output.txt", test_content)
write_to_file_with_finally("/root/protected.txt", test_content)
```

```
Write successful!

Write operation complete
```
