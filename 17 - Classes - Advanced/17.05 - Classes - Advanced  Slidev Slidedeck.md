# Class Variables vs Instance Variables 📊

**Instance variables** belong to individual objects, while **class variables** are shared by ALL instances of the class:

<v-clicks>

### Instance Variables (Review)

```python
class Dog:
    def __init__(self, name, breed):
        self.name = name    # Each dog has its own name
        self.breed = breed  # Each dog has its own breed

buddy = Dog("Buddy", "Golden Retriever")
max_dog = Dog("Max", "German Shepherd")

print(buddy.name)   # Buddy
print(max_dog.name) # Max - different for each dog
```

### Class Variables: Shared Data

```python
class Dog:
    species = "Canis familiaris"  # Class variable - shared by ALL dogs

    def __init__(self, name, breed):
        self.name = name    # Instance variable
        self.breed = breed  # Instance variable

# All dogs share the same species
print(buddy.species)   # Canis familiaris
print(max_dog.species) # Canis familiaris
print(Dog.species)     # Canis familiaris (access via class too)
```

</v-clicks>

# Practical Example: Instance Counter 📈

<v-clicks>

```python
class Student:
    # Class variables
    total_students = 0      # Count all students created
    school_name = "Python University"

    def __init__(self, name, student_id):
        # Instance variables
        self.name = name
        self.student_id = student_id
        self.courses = []

    @classmethod  # We'll learn about this decorator soon!

# Create students
alice = Student("Alice Johnson", "S001")
bob = Student("Bob Smith", "S002")
charlie = Student("Charlie Brown", "S003")

# Check total count
print(f"Total students: {Student.total_students}")        # 3

print(f"Alice goes to: {alice.school_name}")              # Python University

# All students share the same school name and total count
```

# Modifying Class Variables 🔧

<v-clicks>

### Changing for All Instances

```python
class BankAccount:
    interest_rate = 0.02  # 2% interest rate for all accounts

    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance

    def apply_interest(self):
        self.balance += self.balance * BankAccount.interest_rate

    def __str__(self):
        return f"{self.owner}: ${self.balance:.2f}"

# Create accounts
alice_account = BankAccount("Alice", 1000)
bob_account = BankAccount("Bob", 2000)

# Apply interest
alice_account.apply_interest()
bob_account.apply_interest()

print(alice_account)  # Alice: $1020.00
print(bob_account)    # Bob: $2040.00

# Bank raises interest rates for all accounts!
BankAccount.interest_rate = 0.03  # 3%

alice_account.apply_interest()
print(alice_account)  # Alice: $1050.60 (now using 3% rate)
```

# Warning: Instance Variable Shadowing ⚠️

<v-clicks>

```python
class Counter:
    count = 0  # Class variable

    def __init__(self):
        pass

# Create counters
c1 = Counter()
c2 = Counter()

print(c1.count)  # 0 (accessing class variable)
print(c2.count)  # 0 (accessing class variable)

# Modify class variable
Counter.count = 5
print(c1.count)  # 5
print(c2.count)  # 5

# ⚠️ WATCH OUT: This creates an instance variable!
c1.count = 10    # Creates c1.count instance variable

print(c1.count)      # 10 (now accessing instance variable)
print(c2.count)      # 5  (still accessing class variable)
print(Counter.count) # 5  (class variable unchanged)

# c1 now has its own count, separate from the class variable!
```

**Best practice:** Modify class variables through the class name, not instances!

# Static Methods: Utility Functions 🛠️

**Static methods** are functions that belong to a class but don't access instance or class data:

<v-clicks>

```python
class MathHelper:
    @staticmethod
    def add(a, b):
        """Add two numbers - no access to self or class needed."""
        return a + b

    @staticmethod
    def is_even(number):
        """Check if a number is even."""
        return number % 2 == 0

    @staticmethod
    def celsius_to_fahrenheit(celsius):
        """Convert Celsius to Fahrenheit."""
        return (celsius * 9/5) + 32

# Call static methods without creating objects
print(MathHelper.add(5, 3))                    # 8
print(MathHelper.is_even(10))                  # True
print(MathHelper.celsius_to_fahrenheit(25))    # 77.0

# You can call on instances too, but why would you?
helper = MathHelper()
print(helper.add(2, 3))  # 5 (works but unnecessary)
```

**Key characteristics:**
- No `self` or `cls` parameter
- Can't access instance or class variables
- Just regular functions organized in a class namespace

</v-clicks>

# When to Use Static Methods 🎯

<v-clicks>

### Good Use Cases

```python
class ValidationHelper:
    @staticmethod
    def is_valid_email(email):
        """Validate email format."""
        return "@" in email and "." in email and len(email) > 5

    @staticmethod
    def is_valid_password(password):
        """Check password strength."""
        return (len(password) >= 8 and
                any(c.isupper() for c in password) and
                any(c.islower() for c in password) and
                any(c.isdigit() for c in password))

class User:
    def __init__(self, username, email, password):
        # Use static methods for validation
        if not ValidationHelper.is_valid_email(email):
            raise ValueError("Invalid email format")

        if not ValidationHelper.is_valid_password(password):
            raise ValueError("Password too weak")

        self.username = username
        self.email = email
        self.password = password

# Static methods used without creating ValidationHelper objects
print(ValidationHelper.is_valid_email("user@example.com"))  # True
print(ValidationHelper.is_valid_password("Weak123"))        # True

# Create user with validation
user = User("alice", "alice@email.com", "StrongPass123")
```

# Class Methods: Working with the Class Itself 🏭

**Class methods** receive the class (not an instance) as their first parameter:

<v-clicks>

```python
class Person:
    population = 0  # Class variable

    def __init__(self, name, age):
        self.name = name
        self.age = age
        Person.population += 1

    @classmethod
    def get_population(cls):
        """Get total population - accesses class variable."""
        return cls.population

    @classmethod
    def from_string(cls, person_string):
        """Alternative constructor - create Person from string."""
        name, age = person_string.split("-")
        return cls(name, int(age))  # cls is the Person class

    @classmethod
    def create_baby(cls, name):
        """Factory method - create baby (age 0)."""
        return cls(name, 0)

    def __str__(self):
        return f"{self.name}, age {self.age}"

# Use class methods
alice = Person("Alice", 25)
bob = Person("Bob", 30)

# Class method to check population
print(f"Population: {Person.get_population()}")  # 2

# Alternative constructor
charlie = Person.from_string("Charlie-22")
print(charlie)  # Charlie, age 22

# Factory method
baby = Person.create_baby("Emma")
print(baby)  # Emma, age 0

print(f"Final population: {Person.get_population()}")  # 4
```

# Enumerations: Named Constants 📋

**Enumerations** create a set of named constants, making code more readable and preventing invalid values:

<v-clicks>

```python
from enum import Enum

class Priority(Enum):
    LOW = 1
    MEDIUM = 2
    HIGH = 3
    CRITICAL = 4

class TaskStatus(Enum):
    TODO = "todo"
    IN_PROGRESS = "in_progress"
    DONE = "done"
    CANCELLED = "cancelled"

# Use enums instead of magic strings/numbers
class Task:
    def __init__(self, title, priority=Priority.MEDIUM):
        self.title = title
        self.priority = priority
        self.status = TaskStatus.TODO

    def start_work(self):
        if self.status == TaskStatus.TODO:
            self.status = TaskStatus.IN_PROGRESS
            print(f"Started working on: {self.title}")
        else:
            print("Task is not in TODO status")

    def complete(self):
        if self.status == TaskStatus.IN_PROGRESS:
            self.status = TaskStatus.DONE
            print(f"Completed: {self.title}")

    def __str__(self):
        return f"{self.title} - Priority: {self.priority.name}, Status: {self.status.value}"

# Create tasks with enums (prevents typos!)
task1 = Task("Fix bug", Priority.HIGH)
task2 = Task("Write documentation")

print(task1)  # Fix bug - Priority: HIGH, Status: todo
task1.start_work()  # Started working on: Fix bug
task1.complete()    # Completed: Fix bug
```

</v-clicks>

```python
from enum import Enum
```

# The Singleton Pattern 🔒

The **Singleton pattern** ensures only ONE instance of a class can exist:

<v-clicks>

### The Problem

```python
# Normal class allows multiple instances
class Database:
    def __init__(self):
        print("Connecting to database...")
        self.connection = "Connected"

db1 = Database()  # Connecting to database...
db2 = Database()  # Connecting to database... (Wasteful!)

# We might want only ONE database connection
```

### The Singleton Solution

```python
class DatabaseSingleton:
    _instance = None  # Class variable to store the single instance

    def __new__(cls):
        # __new__ controls object creation
        if cls._instance is None:
            print("Creating new database connection")
            cls._instance = super().__new__(cls)
        else:
            print("Returning existing database connection")
        return cls._instance

    def __init__(self):
        # Only initialize once
        if not hasattr(self, 'initialized'):
            print("Initializing database connection")
            self.connection = "Connected to database"
            self.initialized = True

# Try to create multiple instances
db1 = DatabaseSingleton()  # Creating new database connection
db2 = DatabaseSingleton()  # Returning existing database connection
db3 = DatabaseSingleton()  # Returning existing database connection

print(db1 is db2)  # True - same object!
print(db2 is db3)  # True - same object!
```

# Understanding __new__ vs __init__ 🏗️

<v-clicks>

### How Object Creation Works

```python
class Example:
    def __new__(cls, name):
        print(f"__new__ called with {name}")
        # Create and return the object
        instance = super().__new__(cls)
        return instance

    def __init__(self, name):
        print(f"__init__ called with {name}")
        self.name = name

# When you call Example("Alice"):
obj = Example("Alice")
# Output:
# __new__ called with Alice
# __init__ called with Alice
```

**Key points:**
- `__new__` creates the object (runs first)
- `__init__` initializes the object (runs second)
- Singleton controls `__new__` to return the same object

### Practical Singleton: Configuration Manager

```python
class Config:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance.settings = {}
        return cls._instance

    def set_setting(self, key, value):
        self.settings[key] = value

    def get_setting(self, key):
        return self.settings.get(key)

# All Config objects are the same instance
config1 = Config()
config1.set_setting("theme", "dark")

config2 = Config()  # Same object as config1
print(config2.get_setting("theme"))  # dark

print(config1 is config2)  # True
```

# Nested Classes: Organization and Encapsulation 🪆

**Nested classes** are classes defined inside other classes, useful for helper classes:

<v-clicks>

```python
class University:
    def __init__(self, name):
        self.name = name
        self.students = []
        self.courses = []

    class Student:
        """Nested class for students."""
        def __init__(self, name, student_id):
            self.name = name
            self.student_id = student_id
            self.enrolled_courses = []

        def enroll(self, course):
            if course not in self.enrolled_courses:
                self.enrolled_courses.append(course)

        def __str__(self):
            return f"Student: {self.name} (ID: {self.student_id})"

    class Course:
        """Nested class for courses."""
        def __init__(self, course_code, title, instructor):
            self.course_code = course_code
            self.title = title
            self.instructor = instructor
            self.enrolled_students = []

        def add_student(self, student):
            if student not in self.enrolled_students:
                self.enrolled_students.append(student)
                student.enroll(self)

        def __str__(self):
            return f"Course: {self.course_code} - {self.title}"

    def add_student(self, name, student_id):
        student = University.Student(name, student_id)  # Access nested class
        self.students.append(student)
        return student

    def add_course(self, course_code, title, instructor):
        course = University.Course(course_code, title, instructor)
        self.courses.append(course)
        return course
```

# Complete Advanced Example: Library System 📚

<v-clicks>

```python
from enum import Enum, auto
from datetime import datetime, timedelta

class Library:
    _instance = None  # Singleton pattern

    class BookStatus(Enum):
        AVAILABLE = auto()
        CHECKED_OUT = auto()
        RESERVED = auto()
        DAMAGED = auto()

    class Book:
        total_books = 0  # Class variable

        def __init__(self, isbn, title, author):
            self.isbn = isbn
            self.title = title
            self.author = author
            self.status = Library.BookStatus.AVAILABLE
            self.checked_out_by = None
            self.due_date = None
            Library.Book.total_books += 1

        @classmethod
        def get_total_books(cls):
            return cls.total_books

        @staticmethod
        def is_valid_isbn(isbn):
            return len(isbn) == 13 and isbn.isdigit()

        def checkout(self, patron_name, days=14):
            if self.status == Library.BookStatus.AVAILABLE:
                self.status = Library.BookStatus.CHECKED_OUT
                self.checked_out_by = patron_name
                self.due_date = datetime.now() + timedelta(days=days)
                return True
            return False

        def return_book(self):
            if self.status == Library.BookStatus.CHECKED_OUT:
                self.status = Library.BookStatus.AVAILABLE
                self.checked_out_by = None
                self.due_date = None
                return True
            return False

        def __str__(self):
            return f"'{self.title}' by {self.author} - {self.status.name}"
```

```python
    def __new__(cls):
        # Singleton - only one library instance
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance.books = {}
            cls._instance.initialized = False
        return cls._instance

    def __init__(self):

    def add_book(self, isbn, title, author):
        if Library.Book.is_valid_isbn(isbn):
            if isbn not in self.books:
                book = Library.Book(isbn, title, author)
                self.books[isbn] = book
                print(f"Added book: {book}")
                return book
            else:
                print("Book already exists in library")
        else:
            print("Invalid ISBN format")
        return None

    def checkout_book(self, isbn, patron_name):
        if isbn in self.books:
            book = self.books[isbn]
            if book.checkout(patron_name):
                print(f"'{book.title}' checked out to {patron_name}")
                return True
            else:
                print(f"'{book.title}' is not available")
        else:
            print("Book not found")
        return False

    def return_book(self, isbn):
        if isbn in self.books:
            book = self.books[isbn]
            if book.return_book():
                print(f"'{book.title}' returned successfully")
                return True
            else:
                print(f"'{book.title}' was not checked out")
        else:
            print("Book not found")
        return False

    def get_status_report(self):
        total = len(self.books)
        available = sum(1 for book in self.books.values()
                       if book.status == Library.BookStatus.AVAILABLE)
        checked_out = total - available

        print(f"\nLibrary Status Report:")
        print(f"Total books: {Library.Book.get_total_books()}")
        print(f"Available: {available}")
        print(f"Checked out: {checked_out}")

        # Show overdue books
        now = datetime.now()
        overdue = [book for book in self.books.values()
                  if book.due_date and book.due_date < now]

        if overdue:
            print(f"Overdue books: {len(overdue)}")
            for book in overdue:
                days_overdue = (now - book.due_date).days
                print(f"  '{book.title}' - {days_overdue} days overdue")
```

# When to Use Each Advanced Feature 🎯

<v-clicks>

### Class Variables
✅ **Counters** - tracking total instances
✅ **Shared configuration** - settings for all instances
✅ **Constants** - values that don't change per instance

### Static Methods
✅ **Validation functions** - input checking
✅ **Utility functions** - calculations, conversions
✅ **Helper functions** - related to class but no state needed

### Class Methods
✅ **Alternative constructors** - different ways to create objects
✅ **Factory methods** - create objects based on parameters
✅ **Access class variables** - when you need the class reference

### Enums
✅ **Fixed sets of options** - status, priority, categories
✅ **Preventing typos** - named constants instead of strings
✅ **API definitions** - clear, documented options

### Singleton
✅ **Resource managers** - database connections, file handles
✅ **Configuration systems** - global settings
✅ **Logging systems** - centralized logging
⚠️ **Use sparingly** - can make testing difficult

### Nested Classes
✅ **Helper classes** - only used within outer class
✅ **Logical grouping** - related classes together
✅ **Namespace organization** - avoid name conflicts

</v-clicks>
