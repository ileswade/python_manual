### Example 1: Building a Student Management System with Class Variables and Class Methods
**Problem:** Create a `Student` class that tracks the total number of students using a class variable. Include instance variables for name and student_id. Add a class method `get_student_count()` that returns the total, a class method `from_csv(csv_line)` as an alternative constructor, and implement both `__str__` and `__repr__`. Create 5 students (some using regular constructor, some using from_csv) and display the total count.

**Detailed Solution:**

**Step 1: Understand class variables vs instance variables**
- **Class variables**: Shared by ALL instances (like `total_students`)
- **Instance variables**: Unique to each object (like `name`, `student_id`)
- Class variable lives in the class, instance variables live in `self`

**Step 2: Understand class methods**
- Use `@classmethod` decorator
- First parameter is `cls` (the class itself)
- Can access/modify class variables
- Perfect for alternative constructors

**Step 3: Plan the implementation**
```python
class Student:
    total_students = 0  # Class variable (shared)
    
    def __init__(self, name, student_id):
        self.name = name  # Instance variable
        self.student_id = student_id  # Instance variable
        Student.total_students += 1  # Increment class variable
    
    @classmethod
    def get_student_count(cls):
        return cls.total_students
    
    @classmethod
    def from_csv(cls, csv_line):
        # Parse "name,id" format
        name, student_id = csv_line.split(',')
        return cls(name.strip(), student_id.strip())
```

**Step 4: Implement complete solution**

**Complete Solution:**
```python
class Student:
    # Class variable - shared by ALL students
    total_students = 0
    
    def __init__(self, name, student_id):
        """Initialize student with name and ID."""
        self.name = name
        self.student_id = student_id
        # Increment class variable when new student created
        Student.total_students += 1
    
    @classmethod
    def get_student_count(cls):
        """Return total number of students (class method)."""
        return cls.total_students
    
    @classmethod
    def from_csv(cls, csv_line):
        """Create student from CSV format: 'name,id' (alternative constructor)."""
        name, student_id = csv_line.split(',')
        return cls(name.strip(), student_id.strip())
    
    def __str__(self):
        """User-friendly representation."""
        return f"Student: {self.name} (ID: {self.student_id})"
    
    def __repr__(self):
        """Developer-friendly representation."""
        return f"Student('{self.name}', '{self.student_id}')"

# Create students using regular constructor
print("Creating students with regular constructor:")
student1 = Student("Alice Johnson", "S001")
student2 = Student("Bob Smith", "S002")

print(f"Total students: {Student.get_student_count()}")  # 2
print()

# Create students using alternative constructor (from_csv)
print("Creating students from CSV format:")
student3 = Student.from_csv("Charlie Brown, S003")
student4 = Student.from_csv("Diana Martinez, S004")
student5 = Student.from_csv("Eve Wilson, S005")

print(f"Total students: {Student.total_students}")  # 5 (direct access)
print()

# Display all students
print("=" * 50)
print("ALL STUDENTS")
print("=" * 50)
students = [student1, student2, student3, student4, student5]

for student in students:
    print(student)  # Uses __str__

print()
print(f"Total students enrolled: {Student.get_student_count()}")

# Debug view
print()
print("=" * 50)
print("DEBUG VIEW")
print("=" * 50)
for student in students:
    print(repr(student))  # Uses __repr__
```

**Key Concepts:**
- **Class variable**: `total_students` shared by all instances
- **Accessing class variable**: Use `Student.total_students` or `cls.total_students`
- **@classmethod decorator**: Makes method receive class as first parameter
- **cls parameter**: Refers to the class itself (like `self` refers to instance)
- **Alternative constructor**: `from_csv` creates instances in different way
- **Automatic counting**: Each new student increments counter
- **Class method vs instance method**: Class methods work with class data, instance methods work with instance data

**Why this works:**
1. `total_students` is defined in class body (not in `__init__`)
2. Every time `__init__` runs, it increments `Student.total_students`
3. All instances share this same counter
4. `@classmethod` allows methods to access class variables via `cls`
5. Alternative constructor parses CSV, then calls `cls(...)` to create instance

### Example 2: Temperature Converter with Static Methods
**Problem:** Create a `Temperature` class with static methods for conversions: `celsius_to_fahrenheit()`, `fahrenheit_to_celsius()`, `celsius_to_kelvin()`, and `kelvin_to_celsius()`. Also add a regular method `__init__` to store a temperature value in Celsius, and instance methods to convert the stored value. Demonstrate both static method usage (without creating objects) and instance method usage.

**Detailed Solution:**

**Step 1: Understand static methods**
- Use `@staticmethod` decorator
- No `self` or `cls` parameter
- Can't access instance or class variables
- Just utility functions that belong to the class

**Step 2: When to use static methods**
- Utility/helper functions related to the class
- Don't need access to instance or class data
- Organize related functions together

**Step 3: Plan the implementation**
```python
class Temperature:
    @staticmethod
    def celsius_to_fahrenheit(c):
        return (c * 9/5) + 32
    
    # Can call without creating instance:
    temp_f = Temperature.celsius_to_fahrenheit(25)
```

**Step 4: Implement with both static and instance methods**

**Complete Solution:**
```python
class Temperature:
    """Temperature conversion utility class."""
    
    # Static methods - utility functions (no self/cls)
    @staticmethod
    def celsius_to_fahrenheit(celsius):
        """Convert Celsius to Fahrenheit: (C × 9/5) + 32"""
        return (celsius * 9/5) + 32
    
    @staticmethod
    def fahrenheit_to_celsius(fahrenheit):
        """Convert Fahrenheit to Celsius: (F - 32) × 5/9"""
        return (fahrenheit - 32) * 5/9
    
    @staticmethod
    def celsius_to_kelvin(celsius):
        """Convert Celsius to Kelvin: C + 273.15"""
        return celsius + 273.15
    
    @staticmethod
    def kelvin_to_celsius(kelvin):
        """Convert Kelvin to Celsius: K - 273.15"""
        return kelvin - 273.15
    
    @staticmethod
    def is_freezing_celsius(celsius):
        """Check if temperature is at or below freezing (0°C)"""
        return celsius <= 0
    
    # Instance methods (work with stored temperature)
    def __init__(self, celsius):
        """Initialize with temperature in Celsius."""
        self.celsius = celsius
    
    def to_fahrenheit(self):
        """Convert stored temperature to Fahrenheit."""
        return Temperature.celsius_to_fahrenheit(self.celsius)
    
    def to_kelvin(self):
        """Convert stored temperature to Kelvin."""
        return Temperature.celsius_to_kelvin(self.celsius)
    
    def is_freezing(self):
        """Check if stored temperature is freezing."""
        return Temperature.is_freezing_celsius(self.celsius)
    
    def __str__(self):
        return f"{self.celsius}°C"
```

### Example 3: Order Management System with Enums and Singleton Pattern
**Problem:** Create an `OrderManager` singleton class that manages orders. Use an enum `OrderStatus` with values: PENDING, PROCESSING, SHIPPED, DELIVERED, CANCELLED. The OrderManager should: be a singleton, store orders with status, allow status updates, and prevent invalid status transitions (e.g., can't go from DELIVERED to PENDING). Create an `Order` nested class inside OrderManager. Demonstrate creating multiple OrderManager references (proving they're the same instance) and managing several orders.

**Detailed Solution:**

**Step 1: Understand the components**
- **Enum**: Fixed set of named constants (order statuses)
- **Singleton**: Only one OrderManager instance exists
- **Nested class**: Order class inside OrderManager
- **State machine**: Valid status transitions

**Step 2: Understand Singleton pattern**
```python
class Singleton:
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            # Initialize here
        return cls._instance
```

**Step 3: Understand Enum usage**
```python
from enum import Enum

class Status(Enum):
    PENDING = 1
    SHIPPED = 2

order_status = Status.PENDING
if order_status == Status.PENDING:
    # Do something
```

**Step 4: Implement complete system**

**Complete Solution:**
```python
from enum import Enum, auto

class OrderManager:
    """Singleton order management system."""
    
    # Enum for order statuses (nested)
    class OrderStatus(Enum):
        PENDING = auto()      # 1 - Order placed
        PROCESSING = auto()   # 2 - Being prepared
        SHIPPED = auto()      # 3 - In transit
        DELIVERED = auto()    # 4 - Completed
        CANCELLED = auto()    # 5 - Cancelled
    
    # Nested Order class
    class Order:
        def __init__(self, order_id, customer, items):
            self.order_id = order_id
            self.customer = customer
            self.items = items
            self.status = OrderManager.OrderStatus.PENDING
        
        def __str__(self):
            items_str = ', '.join(self.items)
            return f"Order #{self.order_id} ({self.customer}): {items_str} - Status: {self.status.name}"
    
    # Singleton implementation
    _instance = None
    
    def __new__(cls):
        """Ensure only one OrderManager instance exists."""
        if cls._instance is None:
            print("Creating new OrderManager instance")
            cls._instance = super().__new__(cls)
            cls._instance.orders = {}  # Initialize orders dict
        else:
            print("Returning existing OrderManager instance")
        return cls._instance
    
    def create_order(self, order_id, customer, items):
        """Create a new order."""
        if order_id in self.orders:
            print(f"Error: Order #{order_id} already exists")
            return None
        
        order = OrderManager.Order(order_id, customer, items)
        self.orders[order_id] = order
        print(f"Created: {order}")
        return order
    
    def update_status(self, order_id, new_status):
        """Update order status with validation."""
        if order_id not in self.orders:
            print(f"Error: Order #{order_id} not found")
            return False
        
        order = self.orders[order_id]
        old_status = order.status
        
        # Define valid transitions
        valid_transitions = {
            OrderManager.OrderStatus.PENDING: [
                OrderManager.OrderStatus.PROCESSING,
                OrderManager.OrderStatus.CANCELLED
            ],
            OrderManager.OrderStatus.PROCESSING: [
                OrderManager.OrderStatus.SHIPPED,
                OrderManager.OrderStatus.CANCELLED
            ],
            OrderManager.OrderStatus.SHIPPED: [
                OrderManager.OrderStatus.DELIVERED
            ],
            OrderManager.OrderStatus.DELIVERED: [],  # Final state
            OrderManager.OrderStatus.CANCELLED: []   # Final state
        }
        
        # Check if transition is valid
        if new_status in valid_transitions[old_status]:
            order.status = new_status
            print(f"Order #{order_id}: {old_status.name} → {new_status.name}")
            return True
        else:
            print(f"Error: Cannot change Order #{order_id} from {old_status.name} to {new_status.name}")
            return False
    
    def get_order(self, order_id):
        """Get order by ID."""
        return self.orders.get(order_id)
    
    def get_orders_by_status(self, status):
        """Get all orders with given status."""
        return [order for order in self.orders.values() if order.status == status]
    
    def display_all_orders(self):
        """Display all orders."""
        print("\n" + "=" * 70)
        print("ALL ORDERS")
        print("=" * 70)
        if not self.orders:
            print("No orders")
        else:
            for order in self.orders.values():
                print(order)
        print("=" * 70)
    
    def __str__(self):
        return f"OrderManager (Total orders: {len(self.orders)})"

# Demonstrate Singleton pattern
print("=" * 70)
print("SINGLETON DEMONSTRATION")
print("=" * 70)

manager1 = OrderManager()
manager2 = OrderManager()
manager3 = OrderManager()

print(f"\nmanager1 is manager2: {manager1 is manager2}")
print(f"manager2 is manager3: {manager2 is manager3}")
print(f"All are same object: {manager1 is manager2 is manager3}")

# Create orders using any reference (all same object)
print("\n" + "=" * 70)
print("CREATING ORDERS")
print("=" * 70)

manager1.create_order("ORD001", "Alice", ["Laptop", "Mouse"])
manager2.create_order("ORD002", "Bob", ["Phone", "Case"])
manager3.create_order("ORD003", "Charlie", ["Tablet"])

# Display all orders
manager1.display_all_orders()

# Update order statuses
print("\n" + "=" * 70)
print("UPDATING ORDER STATUSES")
print("=" * 70)

# Valid transitions
manager1.update_status("ORD001", OrderManager.OrderStatus.PROCESSING)
manager1.update_status("ORD001", OrderManager.OrderStatus.SHIPPED)
manager1.update_status("ORD001", OrderManager.OrderStatus.DELIVERED)

print()

manager2.update_status("ORD002", OrderManager.OrderStatus.CANCELLED)

print()
# Invalid transition - try to un-deliver

# Display final state
manager1.display_all_orders()

# Get orders by status
print("\n" + "=" * 70)
print("ORDERS BY STATUS")
print("=" * 70)

print(f"Delivered orders ({len(delivered)}):")
for order in delivered:
    print(f"  {order}")

cancelled = manager1.get_orders_by_status(OrderManager.OrderStatus.CANCELLED)
print(f"\nCancelled orders ({len(cancelled)}):")
for order in cancelled:
    print(f"  {order}")

print(f"\nPending orders ({len(pending)}):")
for order in pending:
    print(f"  {order}")
```

**Key Concepts:**
- **Enum with auto()**: Automatically assigns sequential values
- **Nested enum**: `OrderStatus` inside `OrderManager`
- **Nested class**: `Order` inside `OrderManager`
- **Singleton pattern**: `__new__` controls instance creation
- **State machine**: Valid transitions dictionary
- **Status validation**: Prevent invalid state changes

2. First `__new__` call creates instance, stores in `_instance`
3. Subsequent `__new__` calls return existing `_instance`

**Why Enum is useful:**
- Can't use invalid status (e.g., "SHIPPD" typo)
- IDE autocomplete helps
- Clear what values are valid
- Can iterate through all statuses

## Tips for Solving These Problems

### Class Variables vs Instance Variables

**Class variables - defined in class body:**
```python
class MyClass:
    class_var = 0  # Shared by all
    
    def __init__(self):
        self.instance_var = 0  # Unique to each
```

**Access patterns:**
```python
# Class variable
MyClass.class_var        # Through class
obj.class_var            # Through instance (reads class var)
MyClass.class_var = 10   # Modify class var

# WARNING: This creates NEW instance variable!
obj.class_var = 10  # Shadows class var for this instance
```

### Static Methods

**Pattern:**
```python
class Helper:
    @staticmethod
    def utility_function(param):
        # No self, no cls
        return result

# Call without instance
result = Helper.utility_function(value)
```

**When to use:**
- Utility functions
- No instance/class data needed
- Organize related functions

### Class Methods

**Pattern:**
```python
class MyClass:
    @classmethod
    def factory_method(cls, data):
        # Process data
        return cls(processed_data)

    @classmethod
    def modify_class_var(cls, value):
        cls.class_variable = value
```

**When to use:**
- Alternative constructors
- Access/modify class variables
- Factory methods

### Enums

**Pattern:**
```python
from enum import Enum, auto

class Status(Enum):
    PENDING = auto()
    ACTIVE = auto()
    DONE = auto()

# Usage
current = Status.PENDING
if current == Status.PENDING:
    print(current.name)   # "PENDING"
    print(current.value)  # 1
```

**Benefits:**
- No typos (PENDING vs "PENDING")
- IDE autocomplete
- Clear valid values

### Singleton Pattern

**Pattern:**
```python
class Singleton:
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            # Initialize here
        return cls._instance
```

**Key points:**
- `__new__` creates object (before `__init__`)
- Store instance in `_instance`
- Return existing instance if it exists
- All references point to same object

### Nested Classes

**Pattern:**
```python
class Outer:
    class Inner:
        def __init__(self):
            pass
    
    def __init__(self):
        self.inner = Outer.Inner()

# Create inner class
inner_obj = Outer.Inner()
```

**When to use:**
- Helper class only used by outer class
- Logical grouping
- Implementation detail

### Common Patterns

**Counting instances:**
```python
class Counter:
    count = 0
    
    def __init__(self):
        Counter.count += 1
```

**Alternative constructor:**
```python
@classmethod
def from_string(cls, string):
    # Parse string
    return cls(parsed_data)
```

**Enum iteration:**
```python
for status in Status:
    print(status.name, status.value)
```

**Singleton check:**
```python
obj1 = Singleton()
obj2 = Singleton()
print(obj1 is obj2)  # True
```

### Problem-Solving Workflow

1. **Identify what's shared vs unique:**
   - Shared → class variable
   - Unique → instance variable

2. **Determine method type:**
   - No instance/class data → static method
   - Need class data → class method
   - Need instance data → instance method

3. **Consider enums for:**
   - Fixed set of values
   - Status, categories, types

4. **Use singleton when:**
   - Only one instance needed
   - Global access required

5. **Nested classes for:**
   - Helper classes
   - Related functionality

### Common Mistakes

**1. Modifying class variable through instance:**
```python
# Wrong - creates instance variable!
obj.class_var = 10

# Right - modifies class variable
ClassName.class_var = 10
```

**2. Forgetting decorators:**
```python
# Wrong - no decorator
def static_method():
    pass

# Right
@staticmethod
def static_method():
    pass
```

**3. Wrong parameter in class method:**
```python
# Wrong
@classmethod
def method(self):  # Should be cls!
    pass

# Right
@classmethod
def method(cls):
    pass
```

**4. Comparing enums with strings:**
```python
# Wrong
if status == "PENDING":

# Right
if status == Status.PENDING:
```

### Key Concepts Checklist

✓ Class variables shared by all instances
✓ Instance variables unique to each object
✓ `@staticmethod` for utility functions (no self/cls)
✓ `@classmethod` for factory methods (receives cls)
✓ Enums for fixed sets of constants
✓ `__new__` for singleton pattern
✓ Nested classes for related functionality
✓ Access class vars with `ClassName.var`
✓ First `cls` parameter in class methods
✓ Enum comparison with `==`, access with `.name`, `.value`
