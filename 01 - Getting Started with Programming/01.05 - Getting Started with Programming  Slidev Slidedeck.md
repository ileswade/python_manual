# What is Computer Programming?

**Programming is about problem-solving.** At its core, programming is a three-step process:

<v-clicks>

<div class="grid grid-cols-1 gap-4 mt-6">

<div class="flex items-center p-4 bg-red-100 dark:bg-red-900 rounded">
  <div class="text-3xl mr-4">1️⃣</div>
  <div><strong>Recognize a problem</strong> that needs to be solved</div>
</div>

<div class="flex items-center p-4 bg-yellow-100 dark:bg-yellow-900 rounded">
  <div class="text-3xl mr-4">2️⃣</div>
  <div><strong>Identify the steps</strong> (an algorithm) a person could follow to solve it</div>
</div>

<div class="flex items-center p-4 bg-green-100 dark:bg-green-900 rounded">
  <div class="text-3xl mr-4">3️⃣</div>
  <div><strong>Translate those steps</strong> into a programming language the computer understands</div>

</div>

# Understanding Algorithms

An **algorithm** is simply a series of steps to solve a problem.

<v-click>

Think of it like a **recipe** - you follow specific steps in order to achieve a result.

</v-click>

<v-clicks>

**Key insights about algorithms:**

- 📝 There are usually **many different algorithms** that can solve the same problem
- 🔧 Some algorithms work better with certain programming languages than others
- 🧠 **The hardest part of programming** is thinking through the problem and breaking it down
- 🌟 Once you can think algorithmically, you can adapt to **any programming language**

</v-clicks>

<v-click>

<div class="mt-6 p-4 bg-purple-100 dark:bg-purple-900 rounded">
🎯 <strong>Remember:</strong> Coming up with <em>any</em> algorithm is one challenge. Coming up with an algorithm that <em>works with Python</em> is another. This takes practice!
</div>

</v-click>

# Algorithm Example: The Game of Nim

<div class="grid grid-cols-2 gap-8">

<div>

**The Game:**
- Start with 12 marbles
- Two players take turns
- Choose 1, 2, or 3 marbles
- **Winner:** Takes the last marble

</div>

<div>

<v-click>

**Algorithm Steps:**

```text
1. Start with 12 marbles
2. REPEAT until no marbles remain:
   a. Show current number of marbles
   b. Ask: "How many marbles (1, 2, or 3)?"
   c. Check if choice is valid
      - If invalid, ask again
      - If valid, remove marbles
   d. Switch to the other player
3. Announce the winner
```

</v-click>

</div>

</div>

<v-click>

**Notice the Python concepts:**
- 📦 **Variables** (marble count, player turn)
- 🔄 **Loops** (REPEAT until...)
- ❓ **Conditionals** (IF choice is valid...)
- 💬 **Input/Output** (asking questions, showing results)

</v-click>

# Algorithm Example: Tower of Hanoi

<div class="grid grid-cols-2 gap-6">

<div>

**The Puzzle:**
- Three pegs, several disks
- All disks start on one peg
- Goal: Move all to another peg

**Rules:**
- Move only one disk at a time
- Never place larger disk on smaller

</div>

<div>

<v-click>

**Algorithm (3 disks):**

```text
1. Move small: Start → Destination
2. Move medium: Start → Spare
3. Move small: Destination → Spare
4. Move large: Start → Destination
5. Move small: Spare → Start
6. Move medium: Spare → Destination
7. Move small: Start → Destination
```

</v-click>

</div>

</div>

<v-click>

**General Solution (Recursion - we'll learn this later!):**

```text
To move N disks from Start to Destination:
IF only 1 disk:
   Move it directly
ELSE:
   Move (N-1) disks Start → Spare
   Move largest disk Start → Destination
   Move (N-1) disks Spare → Destination
```

</v-click>

# Introduction to Python

### What Kind of Language is Python?

Python is an **interpreted programming language**. But what does that mean?

<div class="grid grid-cols-2 gap-6 mt-6">

<div>

<v-click>

### 🏗️ Compiled Languages
*(like C++ or Java)*

- Code converted to machine code **before** running
- Separate "compiling" step
- **Pros:** Very fast execution
- **Cons:** Extra step, less flexible

</v-click>

</div>

<div>

<v-click>

### ⚡ Interpreted Languages
*(like Python)*

- Code converted to machine code **while** running
- Line by line, as needed
- **Pros:** Immediate testing, flexible
- **Cons:** Generally slower

</v-click>

</div>

</div>

<v-click>

<div class="mt-6 p-4 bg-green-100 dark:bg-green-900 rounded">
🎓 <strong>For learning:</strong> Python's advantages (ease of use, immediate feedback) far outweigh the disadvantages!
</div>

</v-click>

# Setting Up Your Environment

Let's get Python and VS Code installed on your system!

<v-clicks>

### 🐍 Installing Python

**For Windows:**
1. Go to [python.org](https://python.org)
2. Download the latest Python 3.x version
3. Run the installer
4. **⚠️ IMPORTANT:** Check "Add Python to PATH"
5. Click "Install Now"

**For macOS:**
1. Go to [python.org](https://python.org)
2. Download Python 3.x for macOS
3. Open the .pkg file
4. Follow the installation wizard

</v-clicks>

<v-click>

**Verify Installation:**
```bash
python --version
```
You should see: `Python 3.12.x` (or similar)

</v-click>
