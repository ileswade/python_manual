## 1. Requests - HTTP Library

**Requests** makes HTTP requests simple and intuitive. Perfect for working with web APIs and fetching web content.

### Installation

```bash
pip install requests
```

### Basic GET Request

```python
import requests

# GET request
response = requests.get('https://api.github.com')

# Check status
print(response.status_code)  # 200 means success

# Get JSON data
data = response.json()
print(data)

# Get text content
text = response.text
print(text)
```

### GET with Parameters

```python
# Weather API example (hypothetical)
params = {
    'city': 'Calgary',
    'units': 'metric',
    'apikey': 'your-api-key'
}

response = requests.get('https://api.weather.com/current', params=params)
weather = response.json()
print(f"Temperature: {weather['temp']}°C")
```

### POST Request

```python
# Send data to API
data = {
    'username': 'alice',
    'email': 'alice@email.com'
}

response = requests.post('https://api.example.com/users', json=data)
print(response.status_code)
print(response.json())
```

### Downloading Files

```python
# Download an image
url = 'https://example.com/image.jpg'
response = requests.get(url)

with open('downloaded_image.jpg', 'wb') as file:
    file.write(response.content)

print("Image downloaded!")
```

### Error Handling

```python
try:
    response = requests.get('https://api.example.com/data', timeout=5)
    response.raise_for_status()  # Raises error for bad status codes
    data = response.json()
except requests.exceptions.ConnectionError:
    print("Network error - check your connection")
except requests.exceptions.Timeout:
    print("Request timed out")
except requests.exceptions.HTTPError as e:
    print(f"HTTP error: {e}")
```

### Practical Example: GitHub API

```python
def get_github_user(username):
    """Get GitHub user information."""
    url = f'https://api.github.com/users/{username}'
    response = requests.get(url)
    
    if response.status_code == 200:
        user = response.json()
        print(f"Name: {user['name']}")
        print(f"Bio: {user['bio']}")
        print(f"Public Repos: {user['public_repos']}")
        print(f"Followers: {user['followers']}")
    else:
        print(f"User '{username}' not found")

get_github_user('torvalds')
```

## 2. Python-dotenv - Environment Variables

**Python-dotenv** loads environment variables from a `.env` file, keeping sensitive data out of your code.

### Installation

```bash
pip install python-dotenv
```

### Create .env File

```
# .env
API_KEY=your-secret-api-key-here
DATABASE_URL=postgresql://user:pass@localhost/dbname
DEBUG=True
SECRET_KEY=super-secret-key
```

### Loading Environment Variables

```python
from dotenv import load_dotenv
import os

# Load environment variables
load_dotenv()

# Access variables
api_key = os.getenv('API_KEY')
database_url = os.getenv('DATABASE_URL')
debug = os.getenv('DEBUG') == 'True'

print(f"API Key: {api_key}")
print(f"Debug mode: {debug}")
```

### Practical Example: API Configuration

```python
import os
from dotenv import load_dotenv
import requests

load_dotenv()

def get_weather(city):
    """Get weather using API key from environment."""
    api_key = os.getenv('WEATHER_API_KEY')
    
    url = 'https://api.weatherapi.com/v1/current.json'
    params = {
        'key': api_key,
        'q': city
    }
    
    response = requests.get(url, params=params)
    return response.json()

# API key is safely stored in .env file
weather = get_weather('Calgary')
```

**Important:** Add `.env` to your `.gitignore` file to keep secrets out of version control!

## 3. PyPDF2 - PDF Manipulation

**PyPDF2** allows you to read, write, and manipulate PDF files.

### Installation

```bash
pip install PyPDF2
```

### Reading PDF

```python
import PyPDF2

# Open PDF
with open('document.pdf', 'rb') as file:
    reader = PyPDF2.PdfReader(file)
    
    # Get number of pages
    num_pages = len(reader.pages)
    print(f"Pages: {num_pages}")
    
    # Read first page
    page = reader.pages[0]
    text = page.extract_text()
    print(text)
```

### Extracting All Text

```python
def extract_pdf_text(pdf_path):
    """Extract all text from PDF."""
    text = ""
    
    with open(pdf_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
        for page in reader.pages:
            text += page.extract_text() + "\n"
    
    return text

content = extract_pdf_text('document.pdf')
print(content)
```

### Merging PDFs

```python
def merge_pdfs(pdf_list, output_path):
    """Merge multiple PDFs into one."""
    merger = PyPDF2.PdfMerger()
    
    for pdf in pdf_list:
        merger.append(pdf)
    
    merger.write(output_path)
    merger.close()
    print(f"Merged PDF saved to {output_path}")

# Usage
merge_pdfs(['file1.pdf', 'file2.pdf', 'file3.pdf'], 'merged.pdf')
```

### Splitting PDF

```python
def split_pdf(input_path, output_folder):
    """Split PDF into individual pages."""
    import os
    
    with open(input_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
        
        for i, page in enumerate(reader.pages):
            writer = PyPDF2.PdfWriter()
            writer.add_page(page)
            
            output_path = os.path.join(output_folder, f'page_{i+1}.pdf')
            with open(output_path, 'wb') as output_file:
                writer.write(output_file)
    
    print(f"Split into {len(reader.pages)} files")

split_pdf('document.pdf', 'output_pages/')
```

## 4. Pandas - Data Analysis (Brief Introduction)

**Pandas** is essential for data analysis and manipulation. Here's a quick introduction.

### Installation

```bash

```

### Reading Data

```python
import pandas as pd
```

### Basic Operations

```python

    'name': ['Alice', 'Bob', 'Charlie', 'Diana'],
    'age': [25, 30, 35, 28],
    'score': [85, 92, 78, 90]

sorted_df = df.sort_values('score', ascending=False)

df['grade'] = df['score'].apply(lambda x: 'A' if x >= 90 else 'B')
```

## 5. Schedule - Task Scheduling

**Schedule** lets you run Python functions at specific times or intervals.

### Installation

```bash
pip install schedule
```

### Basic Scheduling

```python
import schedule
import time

def job():
    print("Task running...")

# Run every 10 seconds
schedule.every(10).seconds.do(job)

# Run every minute
schedule.every().minute.do(job)

# Run every hour
schedule.every().hour.do(job)

# Run every day at specific time
schedule.every().day.at("10:30").do(job)

# Run every Monday
schedule.every().monday.do(job)

# Run every Wednesday at 13:15
schedule.every().wednesday.at("13:15").do(job)

# Keep running
while True:
    schedule.run_pending()
    time.sleep(1)
```

### Practical Example: Daily Backup

```python
import schedule
import shutil
import time
from datetime import datetime

def backup_files():
    """Backup important files daily."""
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    backup_name = f"backup_{timestamp}.zip"
    
    shutil.make_archive(backup_name[:-4], 'zip', 'important_files/')
    print(f"Backup created: {backup_name}")

# Run backup every day at 2 AM
schedule.every().day.at("02:00").do(backup_files)

print("Backup scheduler running...")
while True:
    schedule.run_pending()
    time.sleep(60)  # Check every minute
```

## 6. Rich - Beautiful Terminal Output

**Rich** creates beautiful formatted output in the terminal.

### Installation

```bash
pip install rich
```

### Basic Usage

```python
from rich import print

# Colored output
print("[bold red]Error:[/bold red] File not found")
print("[green]Success:[/green] Operation completed")
print("[blue]Info:[/blue] Processing data...")

# Styled text
print("[bold]Bold text[/bold]")
print("[italic]Italic text[/italic]")
print("[underline]Underlined text[/underline]")
```

### Progress Bars

```python
from rich.progress import track
import time

# Simple progress bar
for i in track(range(100), description="Processing..."):
    time.sleep(0.05)

# Or manually
from rich.progress import Progress

with Progress() as progress:
    task = progress.add_task("[cyan]Downloading...", total=100)
    
    while not progress.finished:
        progress.update(task, advance=1)
        time.sleep(0.05)
```

### Tables

```python
from rich.console import Console

console = Console()

table = Table(title="Student Grades")
table.add_column("Name", style="cyan")

table.add_row("Alice", "A", "95")
table.add_row("Bob", "B", "87")
table.add_row("Charlie", "A", "92")

console.print(table)
```

### Panels and Layout

## 7. QRCode - Generate QR Codes

**QRCode** creates QR codes for URLs, text, or any data.

### Installation

```bash

```

### Basic QR Code

```python
import qrcode

# Create QR code
data = "https://www.example.com"
img = qrcode.make(data)

# Save image
img.save("qrcode.png")
print("QR code saved!")
```

### Advanced QR Code

```python
import qrcode

# Create QR code with custom settings
qr = qrcode.QRCode(
    version=1,
    error_correction=qrcode.constants.ERROR_CORRECT_L,
    box_size=10,
    border=4,
)

qr.add_data('https://github.com')
qr.make(fit=True)

img = qr.make_image(fill_color="black", back_color="white")
img.save("github_qr.png")
```

### WiFi QR Code

```python
def create_wifi_qr(ssid, password, output_file):
    """Create WiFi QR code."""
    wifi_data = f"WIFI:T:WPA;S:{ssid};P:{password};;"
    
    qr = qrcode.QRCode(version=1, box_size=10, border=5)
    qr.add_data(wifi_data)
    qr.make(fit=True)
    
    img = qr.make_image(fill_color="black", back_color="white")
    img.save(output_file)
    print(f"WiFi QR code saved to {output_file}")

create_wifi_qr("MyNetwork", "password123", "wifi_qr.png")
```

## 9. Colorama - Colored Terminal Text

**Colorama** adds color to terminal output (cross-platform).

### Installation

```bash
pip install colorama
```

### Basic Usage

```python
from colorama import Fore, Back, Style, init

# Initialize (required on Windows)
init(autoreset=True)

# Colored text
print(Fore.RED + 'This is red text')
print(Fore.GREEN + 'This is green text')
print(Fore.BLUE + 'This is blue text')

# Background colors
print(Back.YELLOW + 'Yellow background')

# Styles
print(Style.BRIGHT + 'Bright text')
print(Style.DIM + 'Dim text')

# Combine
print(Fore.WHITE + Back.RED + Style.BRIGHT + 'ERROR!')

# Reset
print(Style.RESET_ALL + 'Back to normal')
```

### Practical Example: Colored Logger

```python
from colorama import Fore, Style, init

init(autoreset=True)

def log(level, message):
    """Simple colored logger."""
    colors = {
        'ERROR': Fore.RED,
        'WARNING': Fore.YELLOW,
        'INFO': Fore.BLUE,
        'SUCCESS': Fore.GREEN
    }
    
    color = colors.get(level, Fore.WHITE)
    print(f"{color}[{level}] {message}")

log('ERROR', 'File not found')
log('WARNING', 'Low disk space')
log('INFO', 'Processing data')
log('SUCCESS', 'Operation completed')
```

## 10. Pretty Print (pprint) - Built-in Pretty Printer

**pprint** formats complex data structures for readability. It's built into Python!

### Usage

```python
from pprint import pprint

# Complex nested structure
data = {
    'students': [
        {'name': 'Alice', 'grades': [85, 90, 92], 'info': {'age': 20, 'major': 'CS'}},
        {'name': 'Bob', 'grades': [78, 82, 88], 'info': {'age': 21, 'major': 'Math'}},
    ],
    'courses': ['Python', 'Data Structures', 'Algorithms']
}

# Regular print (hard to read)
print(data)

# Pretty print (formatted and readable)
pprint(data)

# With custom width
pprint(data, width=40)

# With depth limit
pprint(data, depth=2)
```
