# The `end` Parameter: Control Line Endings 📝

By default, `print()` adds a **newline** at the end. The `end` parameter lets you change this!

<v-clicks>

### Default Behavior

```python
print("Hello")
print("World")
```

**Output:**
```
Hello
World
```

Each `print()` goes to a new line.

</v-clicks>

<v-click>

### Changing the End Character

```python
print("Hello", end=" ")
print("World")
```

**Output:**
```
Hello World
```

Now both prints appear on the **same line** with a space between them!

</v-click>

---

# Common Uses of `end` Parameter ⚡

<v-clicks>

**Stay on the same line:**
```python
print("Loading", end="")
print(".", end="")
print(".", end="")
print(".")
```

**Output:** `Loading...`

**Custom separators:**
```python
print("Name", end=": ")
print("Alice")
```

**Output:** `Name: Alice`

**No space or newline:**
```python
for i in range(5):
    print(i, end="")
print()  # Add newline at the end
```

**Output:** `01234`

</v-clicks>

---

# The `flush` Parameter: Immediate Output 💨

Python normally **buffers** output for efficiency. `flush=True` forces immediate display.

<v-clicks>

**Without flush - might not see output immediately:**
```python
import time

print("Loading", end="")
for i in range(3):
    time.sleep(1)
    print(".", end="")
print()
```

**With flush - see each dot appear instantly:**
```python
import time

print("Loading", end="", flush=True)
for i in range(3):
    time.sleep(1)
    print(".", end="", flush=True)
print()
```

</v-clicks>

<v-click>

**When to use `flush=True`:**
- Progress indicators (dots, spinners)
- Real-time status updates
- When using `end=""` with delays

</v-click>

---

# Progress Indicator Example 🔄

<v-clicks>

```python
import time

print("Processing", end="", flush=True)
for i in range(5):
    time.sleep(0.5)  # Simulate work
    print(".", end="", flush=True)
print(" Done!")
```

**Output:** `Processing..... Done!` (each dot appears after 0.5 seconds)

</v-clicks>

<v-click>

**Key Insight:** Without `end=""` and `flush=True`, users wouldn't see the progress - just a long pause followed by all output at once!

</v-click>

# The `sep` Parameter: Control Spacing 🔗

The `sep` parameter controls what appears **between multiple values** in a single print statement.

<v-clicks>

### Default Separator

```python
print("Alice", "Bob", "Charlie")
```

**Output:** `Alice Bob Charlie`

By default, `sep` is a space: `" "`

### Changing the Separator

```python
print("Alice", "Bob", "Charlie", sep=", ")
```

**Output:** `Alice, Bob, Charlie`

</v-clicks>

---

# F-String Formatting: Precision Control 🎯

F-strings support **powerful formatting options** for precise output control.

<v-clicks>

### Basic Format Syntax

Format: `{value:format_spec}`

The format specification comes after a colon inside the braces.

### Decimal Places (Floating Point)

```python
pi = 3.14159265359

print(f"Pi: {pi:.2f}")   # 2 decimal places
print(f"Pi: {pi:.4f}")   # 4 decimal places
print(f"Pi: {pi:.0f}")   # No decimal places (rounds)
```

**Output:**
```
Pi: 3.14
Pi: 3.1416
Pi: 3
```

</v-clicks>

---

# Format Breakdown: Understanding the Syntax 📐

<div class="text-center text-xl mb-6">
`{pi:.2f}` breaks down as:
</div>

<v-clicks>

<div class="grid grid-cols-3 gap-4 mb-6">

<div class="p-4 bg-blue-100 dark:bg-blue-900 rounded text-center">
<h3>`:`</h3>
<p>Starts format specification</p>
</div>

<div class="p-4 bg-yellow-100 dark:bg-yellow-900 rounded text-center">
<h3>`.2`</h3>
<p>2 digits after decimal point</p>
</div>

<div class="p-4 bg-green-100 dark:bg-green-900 rounded text-center">
<h3>`f`</h3>
<p>Fixed-point (floating point) notation</p>
</div>

</div>

</v-clicks>

<v-click>

**More examples:**
- `{price:.2f}` → 19.99 (always 2 decimals)
- `{score:.1f}` → 87.5 (1 decimal)
- `{value:.0f}` → 100 (no decimals, rounded)

</v-click>

# Width and Alignment 📏

<div class="grid grid-cols-2 gap-6">

<div>

<v-click>

### Minimum Width

```python
num = 42
print(f"Number: {num:5}")   # 5 spaces total
print(f"Number: {num:10}")  # 10 spaces total
```

**Output:**
```
Number:    42
Number:         42
```

Numbers are **right-aligned** by default.

</v-click>

</div>

<div>

<v-click>

### Alignment Control

```python
name = "Alice"

print(f"{name:<10}!")  # Left-aligned
print(f"{name:>10}!")  # Right-aligned
print(f"{name:^10}!")  # Center-aligned
```

**Output:**
```
Alice     !
     Alice!
  Alice   !
```

</v-click>

</div>

</div>

# Combining Width and Decimal Places 🎨

<v-clicks>

```python
price = 19.99
quantity = 3

print(f"Price: ${price:8.2f}")
print(f"Qty:   {quantity:8}")
```

**Output:**
```
Price: $   19.99
Qty:          3
```

**Format breakdown:** `{price:8.2f}`
- `8` = minimum total width (including decimal point)
- `.2` = 2 decimal places
- `f` = floating point

This creates perfectly aligned columns!

</v-clicks>

# Receipt Generator Example 🧾

<v-clicks>

```python
items = [
    ("Widget", 12.99, 2),
    ("Gadget", 8.50, 1),
    ("Doohickey", 24.99, 1)
]

print("=" * 40)
print(f"{'RECEIPT':^40}")
print("=" * 40)

subtotal = 0
for name, price, qty in items:
    line_total = price * qty
    subtotal += line_total
    print(f"{name:<20} {qty:>3} x ${price:>6.2f} = ${line_total:>7.2f}")

tax = subtotal * 0.05
total = subtotal + tax

print("-" * 40)
print(f"{'Subtotal:':<30} ${subtotal:>7.2f}")
print(f"{'Tax (5%):':<30} ${tax:>7.2f}")
print(f"{'Total:':<30} ${total:>7.2f}")
print("=" * 40)
```

</v-clicks>

# Raw Strings: Handling Special Characters 📝

**Raw strings** treat backslashes as **literal characters**, not escape sequences.

<v-clicks>

### The Problem

```python
path = "C:\new\test"
print(path)  # C:
#ew	est (interprets \n and \t as escape sequences!)
```

**Problem:** `\n` and `\t` are interpreted as newline and tab.

### The Solution

```python
path = r"C:\new\test"
print(path)  # C:\new\test (correct!)
```

The `r` prefix tells Python: **"treat backslashes literally."**

</v-clicks>

---

# When to Use Raw Strings 🛠️

<v-clicks>

**File paths (Windows):**
```python
file_path = r"C:\Users\Alice\Documents\file.txt"
print(file_path)  # C:\Users\Alice\Documents\file.txt
```

**Regular expressions (later topic):**
```python
pattern = r"\d{3}-\d{3}-\d{4}"  # Phone number pattern
```

**LaTeX or special formatting:**
```python
latex = r"\frac{1}{2} \times \pi"
print(latex)  # \frac{1}{2} \times \pi
```

</v-clicks>

---

# Progress Bar Example 📈

<v-clicks>

```python
def print_progress(current, total):
    percentage = (current / total) * 100
    bar_length = 40
    filled = int((current / total) * bar_length)
    bar = "█" * filled + "-" * (bar_length - filled)
    print(f"\r[{bar}] {percentage:5.1f}%", end="", flush=True)

# Simulate progress
import time
for i in range(101):
    print_progress(i, 100)
    time.sleep(0.05)
print()  # New line when done
```

This creates a live-updating progress bar:
```
[████████████████████----------] 80.0%
```

</v-clicks>
