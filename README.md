# Introduction to Python Programming

A comprehensive Python programming course covering fundamentals through advanced object-oriented programming concepts.

## 📚 About This Course

This course material was created to teach programming fundamentals using Python as the implementation language. While we use Python, the focus is on universal programming concepts that apply across all modern languages—variables, control structures, functions, data structures, and object-oriented programming.

**Key Philosophy:** Learn to think like a programmer, not just memorize syntax. The concepts you learn here translate directly to Java, C++, JavaScript, Rust, and other languages.

## 📖 Course Structure

The course is organized into 18 chapters (00-17) covering:

- **Chapters 0-10:** Programming fundamentals, variables, control flow, loops, lists, error handling, and file I/O
- **Chapters 11-12:** Functions, recursion, and advanced parameter handling
- **Chapters 13-14:** Data structures (tuples, sets, dictionaries) and JSON
- **Chapters 15-17:** Object-oriented programming (classes, objects, methods, design patterns)
- **Chapters 90+:** Problem sets and practice exercises
- **Chapters 99+:** Appendices covering Python libraries and advanced concepts

Each chapter folder contains up to 5 files:

- `##.01 - [Topic] Manual.md` - Main course content (Markdown format)
- `##.02 - [Topic] Manual.pdf` - PDF version of the manual
- `##.03 - [Topic] Exercises.md` - Practice exercises
- `##.04 - [Topic] Exercise Solutions.md` - Solutions to exercises
- `##.05 - [Topic] Slidev Slidedeck.md` - Interactive presentation slides

## 🚀 Getting Started

### Prerequisites

- **Python 3.8+** - [Download Python](https://www.python.org/downloads/)
- **Visual Studio Code** - [Download VS Code](https://code.visualstudio.com/)
- **Python Extension for VS Code** - Install from the VS Code marketplace

### Viewing the Course Materials

#### Reading Markdown Files

The primary course content is in Markdown (`.md`) files. You have several options:

**Option 1: VS Code (Recommended)**
- Open the folder in VS Code
- Right-click any `.md` file and select "Open Preview" (or press `Ctrl+Shift+V` / `Cmd+Shift+V`)
- VS Code provides excellent Markdown rendering with syntax highlighting

**Option 2: GitHub**
- View files directly on GitHub with automatic rendering
- Perfect for browsing without downloading

**Option 3: Dedicated Markdown Viewers**
- [Obsidian](https://obsidian.md/) - Feature-rich with graph view and linking
- [Typora](https://typora.io/) - Clean WYSIWYG editor
- [Mark Text](https://github.com/marktext/marktext) - Free and open-source
- [MacDown](https://macdown.uranusjr.com/) - macOS only

#### Running Slidev Presentations

The `.05` files are interactive presentations powered by [Slidev](https://sli.dev/).

**Setup Slidev:**

```bash
# Install Node.js first (https://nodejs.org/)
# Then install Slidev globally
npm install -g @slidev/cli

# Navigate to the course directory
cd "introduction-to-python-programming"

# Run any slidedeck
slidev "01 - Getting Started with Programming/01.05 - Getting Started with Programming  Slidev Slidedeck.md"
```

**Slidev Features:**
- 🎨 Syntax highlighting for code examples
- 📊 Interactive components and animations
- 📝 Speaker notes and presenter mode
- 🎥 Recording and export capabilities
- 📱 Mobile-friendly viewing

**Slidev Controls:**
- Arrow keys or space to navigate
- Press `d` for dark mode
- Press `o` for slides overview
- Press `f` for fullscreen
