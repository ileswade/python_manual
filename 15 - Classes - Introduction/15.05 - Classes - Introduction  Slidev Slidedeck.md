# What Are Classes and Objects? 🏗️

Think of **classes** as blueprints or templates, and **objects** as things built from those blueprints:

<v-clicks>

### Real-World Analogy

```python
# Class = Blueprint for a house
# Object = Actual house built from that blueprint

# House Blueprint (Class) defines:
# - Number of rooms
# - Square footage
# - Color
# - Address

# Actual Houses (Objects) created from blueprint:
# - 123 Main St: 3 bedrooms, 1500 sq ft, blue
# - 456 Oak Ave: 4 bedrooms, 2000 sq ft, white
# - 789 Pine Rd: 2 bedrooms, 1200 sq ft, red
```

### In Programming Terms

- **Class**: Template that defines what data and functions an object will have
- **Object**: Specific instance created from a class
- **Instance**: Another word for object

</v-clicks>

# Your First Class: Student 👨‍🎓

<v-clicks>

```python
class Student:
    """A simple student class."""

    def __init__(self, name, age, student_id):
        """Initialize a new student."""
        self.name = name
        self.age = age
        self.student_id = student_id

# Create objects (instances) from the class
alice = Student("Alice Johnson", 20, "S001")
bob = Student("Bob Smith", 19, "S002")
charlie = Student("Charlie Brown", 21, "S003")

# Access object attributes
print(alice.name)        # Alice Johnson
print(bob.age)           # 19
print(charlie.student_id) # S003
```

**Key components:**
- `class Student:` defines the class
- `__init__()` is the constructor - runs when creating objects
- `self` refers to the specific object being created
- `self.name`, `self.age` are **attributes** - data stored in the object

</v-clicks>

# Understanding __init__ and self 🔧

<v-clicks>

### The Constructor: __init__

```python
class Student:
    def __init__(self, name, age, student_id):
        """This runs automatically when creating a new Student."""
        print(f"Creating student: {name}")
        self.name = name          # Store name in this object
        self.age = age            # Store age in this object
        self.student_id = student_id  # Store ID in this object

# When you call Student(), __init__ runs automatically
alice = Student("Alice", 20, "S001")  # Prints: Creating student: Alice
```

### What is 'self'?

```python
# When you create: alice = Student("Alice", 20, "S001")
# Python automatically calls: Student.__init__(alice, "Alice", 20, "S001")
#                                              ↑
#                                           'self' is alice

# self.name = name  means: alice.name = "Alice"
# self.age = age    means: alice.age = 20
```

**self always refers to the specific object being worked with**

</v-clicks>

# Class vs Object: Multiple Instances 👥

<v-clicks>

```python
class Car:
    def __init__(self, make, model, year, color):
        """Initialize a new car."""
        self.make = make
        self.model = model
        self.year = year
        self.color = color
        self.mileage = 0  # All cars start with 0 mileage

# Create multiple car objects from the same class
car1 = Car("Toyota", "Camry", 2020, "Red")
car2 = Car("Honda", "Civic", 2019, "Blue")
car3 = Car("Ford", "Mustang", 2021, "Black")

# Each object has its own separate data
print(f"Car 1: {car1.make} {car1.model}, {car1.color}")
print(f"Car 2: {car2.make} {car2.model}, {car2.color}")
print(f"Car 3: {car3.make} {car3.model}, {car3.color}")

# Modify one object - doesn't affect others
car1.mileage = 15000
car2.color = "Green"

print(f"Car 1 mileage: {car1.mileage}")  # 15000
print(f"Car 2 mileage: {car2.mileage}")  # 0 (unchanged)
print(f"Car 2 color: {car2.color}")      # Green
print(f"Car 1 color: {car1.color}")      # Red (unchanged)
```

# Adding Methods to Classes ⚙️

**Methods** are functions that belong to a class. They can work with the object's data:

<v-clicks>

```python
class BankAccount:
    def __init__(self, account_holder, initial_balance=0):
        """Initialize a bank account."""
        self.account_holder = account_holder
        self.balance = initial_balance
        self.transaction_history = []

    def deposit(self, amount):
        """Add money to the account."""
        if amount > 0:
            self.balance += amount
            self.transaction_history.append(f"Deposited ${amount}")
            print(f"Deposited ${amount}. New balance: ${self.balance}")
        else:
            print("Deposit amount must be positive")

    def withdraw(self, amount):
        """Remove money from the account."""
        if amount > 0:
            if amount <= self.balance:
                self.balance -= amount
                self.transaction_history.append(f"Withdrew ${amount}")
                print(f"Withdrew ${amount}. New balance: ${self.balance}")
            else:
                print("Insufficient funds")
        else:
            print("Withdrawal amount must be positive")

    def get_balance(self):
        """Return the current balance."""
        return self.balance
```

</v-clicks>

# Using Methods on Objects 💳

<v-clicks>

```python
# Create bank account objects
alice_account = BankAccount("Alice Johnson", 1000)
bob_account = BankAccount("Bob Smith", 500)

# Use methods on the objects
alice_account.deposit(250)    # Deposited $250. New balance: $1250
alice_account.withdraw(100)   # Withdrew $100. New balance: $1150

bob_account.deposit(50)       # Deposited $50. New balance: $550
bob_account.withdraw(600)     # Insufficient funds

# Check balances
print(f"Alice's balance: ${alice_account.get_balance()}")  # $1150
print(f"Bob's balance: ${bob_account.get_balance()}")      # $550

# Each object maintains its own state
print(f"Alice's transactions: {alice_account.transaction_history}")
# ['Deposited $250', 'Withdrew $100']

print(f"Bob's transactions: {bob_account.transaction_history}")
# ['Deposited $50']
```

**Key insight:** Methods are called ON objects using dot notation: `object.method()`

</v-clicks>

# Method vs Function: The Difference 🔍

<v-clicks>

### Regular Function
```python
def calculate_area(length, width):
    """Regular function - not tied to any class."""
    return length * width

# Call function directly
area = calculate_area(10, 5)
```

### Method (Function in a Class)
```python
class Rectangle:
    def __init__(self, length, width):
        self.length = length
        self.width = width

    def calculate_area(self):
        """Method - belongs to Rectangle class."""
        return self.length * self.width  # Uses object's own data

# Create object and call method
rect = Rectangle(10, 5)
area = rect.calculate_area()  # Method called ON the object
```

**Key differences:**
- Methods always have `self` as first parameter
- Methods are called on objects: `object.method()`
- Methods can access object's attributes through `self`

</v-clicks>

# Practical Example: Student Class with Methods 🎓

<v-clicks>

```python
class Student:
    def __init__(self, name, student_id, major):
        """Initialize a student."""
        self.name = name
        self.student_id = student_id
        self.major = major
        self.courses = []
        self.grades = {}

    def enroll_in_course(self, course_name):
        """Enroll student in a course."""
        if course_name not in self.courses:
            self.courses.append(course_name)
            print(f"{self.name} enrolled in {course_name}")
        else:
            print(f"{self.name} is already enrolled in {course_name}")

    def add_grade(self, course_name, grade):
        """Add a grade for a course."""
        if course_name in self.courses:
            self.grades[course_name] = grade
            print(f"Added grade {grade} for {self.name} in {course_name}")
        else:
            print(f"{self.name} is not enrolled in {course_name}")

    def calculate_gpa(self):
        """Calculate GPA from current grades."""
        if not self.grades:
            return 0.0

        # Convert letter grades to points (simplified)
        grade_points = {"A": 4.0, "B": 3.0, "C": 2.0, "D": 1.0, "F": 0.0}
        total_points = sum(grade_points.get(grade, 0) for grade in self.grades.values())
        return total_points / len(self.grades)

    def get_transcript(self):
        """Get student's academic record."""
        print(f"\nTranscript for {self.name} (ID: {self.student_id})")
        print(f"Major: {self.major}")
        print("Courses and Grades:")

        for course in self.courses:
            grade = self.grades.get(course, "No grade")
            print(f"  {course}: {grade}")

        gpa = self.calculate_gpa()
        print(f"Current GPA: {gpa:.2f}")
```

# Class Attributes vs Instance Attributes 📊

<v-clicks>

### Instance Attributes (Different for Each Object)

```python
class Dog:
    def __init__(self, name, breed, age):
        # These are INSTANCE attributes - each dog has its own
        self.name = name      # Alice's dog: "Buddy", Bob's dog: "Rex"
        self.breed = breed    # Alice's dog: "Golden Retriever", Bob's dog: "Beagle"
        self.age = age        # Different for each dog
```

### Class Attributes (Shared by All Objects)

```python
class Dog:
    # Class attribute - shared by ALL dogs
    species = "Canis familiaris"

    def __init__(self, name, breed, age):
        # Instance attributes - unique to each dog
        self.name = name
        self.breed = breed
        self.age = age

# All dogs share the same species
buddy = Dog("Buddy", "Golden Retriever", 3)
rex = Dog("Rex", "Beagle", 2)

print(buddy.species)  # Canis familiaris
print(rex.species)    # Canis familiaris
print(Dog.species)    # Canis familiaris (can access through class too)

print(buddy.name)     # Buddy (different for each dog)
print(rex.name)       # Rex (different for each dog)
```

# When to Use Classes 🤔

<v-clicks>

### Use Classes When You Need To:

✅ **Model real-world entities** - students, bank accounts, cars, etc.
✅ **Group related data and functions** - keep everything organized
✅ **Create multiple similar objects** - many students, accounts, etc.
✅ **Maintain state** - objects that remember their data between function calls
✅ **Hide complexity** - provide simple interface for complex operations

### Examples of Good Class Use:

```python
# ✅ Good uses of classes
class User:           # Represents a person using your app
class ShoppingCart:   # Manages items someone wants to buy
class GameCharacter:  # Player in a video game
class DatabaseConnection:  # Manages connection to database
class EmailMessage:   # Represents an email with sender, recipient, body
```

### Don't Use Classes For:

❌ **Simple calculations** - just use functions
❌ **One-time scripts** - classes add unnecessary complexity
❌ **Pure data containers** - dictionaries might be simpler

</v-clicks>

# Real-World Example: Book Class 📖

<v-clicks>

```python
class Book:
    def __init__(self, title, author, isbn, pages):
        """Initialize a book."""
        self.title = title
        self.author = author
        self.isbn = isbn
        self.pages = pages
        self.is_borrowed = False
        self.borrower = None
        self.current_page = 0

    def borrow(self, borrower_name):
        """Borrow the book."""
        if not self.is_borrowed:
            self.is_borrowed = True
            self.borrower = borrower_name
            print(f"'{self.title}' borrowed by {borrower_name}")
        else:
            print(f"'{self.title}' is already borrowed by {self.borrower}")

    def return_book(self):
        """Return the book."""
        if self.is_borrowed:
            print(f"'{self.title}' returned by {self.borrower}")
            self.borrower = None
            self.is_borrowed = False
            self.current_page = 0  # Reset bookmark
        else:
            print(f"'{self.title}' is not currently borrowed")

    def set_bookmark(self, page_number):
        """Set a bookmark."""
        if self.is_borrowed and 0 <= page_number <= self.pages:
            self.current_page = page_number
            print(f"Bookmark set to page {page_number}")
        else:
            print("Invalid page number or book not borrowed")

    def get_info(self):
        """Get book information."""
        status = f"Borrowed by {self.borrower}" if self.is_borrowed else "Available"
        return f"'{self.title}' by {self.author} - {status}"
```

</v-clicks>

# Using the Book Class 📚

<v-clicks>

```python
# Create book objects
book1 = Book("Python Programming", "John Smith", "978-0123456789", 350)
book2 = Book("Data Structures", "Jane Doe", "978-0987654321", 420)

# Use the books
print(book1.get_info())  # 'Python Programming' by John Smith - Available

book1.borrow("Alice")    # 'Python Programming' borrowed by Alice
book1.set_bookmark(45)   # Bookmark set to page 45

print(book1.get_info())  # 'Python Programming' by John Smith - Borrowed by Alice

# Try to borrow again
book1.borrow("Bob")      # 'Python Programming' is already borrowed by Alice

# Return the book
book1.return_book()      # 'Python Programming' returned by Alice

# Now Bob can borrow it
book1.borrow("Bob")      # 'Python Programming' borrowed by Bob

# Work with second book
book2.borrow("Charlie")  # 'Data Structures' borrowed by Charlie
book2.set_bookmark(120)  # Bookmark set to page 120

# Show final status
print(book1.get_info())  # 'Python Programming' by John Smith - Borrowed by Bob
print(book2.get_info())  # 'Data Structures' by Jane Doe - Borrowed by Charlie
```

This demonstrates how objects maintain their own state (who borrowed them, current page, etc.)

# Organizing Code with Classes 🗂️

<v-clicks>

### Before Classes (Procedural Programming)

```python
# Data and functions are separate
alice_name = "Alice"
alice_balance = 1000
alice_transactions = []

def deposit_money(name, balance, transactions, amount):
    balance += amount
    transactions.append(f"Deposited {amount}")
    return balance

def withdraw_money(name, balance, transactions, amount):
    if amount <= balance:
        balance -= amount
        transactions.append(f"Withdrew {amount}")
    return balance

# Have to pass all data to every function
alice_balance = deposit_money(alice_name, alice_balance, alice_transactions, 100)
```

### With Classes (Object-Oriented Programming)

```python
class BankAccount:
    def __init__(self, name, balance=0):
        self.name = name
        self.balance = balance
        self.transactions = []

    def deposit(self, amount):
        self.balance += amount
        self.transactions.append(f"Deposited {amount}")

    def withdraw(self, amount):
        if amount <= self.balance:
            self.balance -= amount
            self.transactions.append(f"Withdrew {amount}")

# Clean and organized
alice = BankAccount("Alice", 1000)
alice.deposit(100)  # Data and methods together!
```

# Class Design Best Practices ✅

<v-clicks>

### 1. Use Clear, Descriptive Names

```python
# ❌ Unclear names
class P:
    def __init__(self, n, a):
        self.n = n
        self.a = a

# ✅ Clear names
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

### 2. Initialize All Attributes in __init__

```python
class Student:
    def __init__(self, name, student_id):
        self.name = name
        self.student_id = student_id
        # Initialize all attributes, even if empty
        self.courses = []
        self.grades = {}
        self.gpa = 0.0
```

### 3. Keep Methods Focused

```python
# ✅ Each method does one thing well
class Calculator:
    def add(self, a, b):
        return a + b

    def subtract(self, a, b):
        return a - b

    def multiply(self, a, b):
        return a * b
```

# Common Beginner Mistakes ⚠️

<v-clicks>

### 1. Forgetting 'self'

```python
class Student:
    def __init__(self, name):
        name = name  # ❌ Wrong! Should be: self.name = name

    def get_name():  # ❌ Wrong! Missing 'self' parameter
        return name  # ❌ Wrong! Should be: self.name
```

### 2. Calling Methods Incorrectly

```python
class Dog:
    def bark(self):
        print("Woof!")

dog = Dog()
Dog.bark()       # ❌ Wrong! Needs an object
dog.bark()       # ✅ Correct!
```

### 3. Confusing Class and Instance Attributes

```python
class Counter:
    count = 0  # Class attribute - shared!

    def __init__(self):
        self.count = 0  # Instance attribute - separate for each object

# Each counter should be independent
c1 = Counter()
c2 = Counter()
c1.count = 5  # Only affects c1, not c2 ✅
```
