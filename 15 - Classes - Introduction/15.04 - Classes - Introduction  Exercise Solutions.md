## Basic Class Creation (Questions 1-5)

### Question 1
**Problem:** Create a `Person` class with `first_name`, `last_name`, and `age` attributes. Create 3 person objects and print their information.

**Solution Approach:**
- Define a Person class with three attributes
- Create `__init__` method to initialize the attributes
- Create three separate person objects
- Access and display each person's information

**Complete Solution:**
```python
class Person:
    def __init__(self, first_name, last_name, age):
        """Initialize a person with name and age."""
        self.first_name = first_name
        self.last_name = last_name
        self.age = age

# Create three person objects
person1 = Person("Alice", "Johnson", 28)
person2 = Person("Bob", "Smith", 35)
person3 = Person("Charlie", "Brown", 42)

# Display information
print("Person Information:")
print("-" * 40)
print(f"{person1.first_name} {person1.last_name}, Age: {person1.age}")
print(f"{person2.first_name} {person2.last_name}, Age: {person2.age}")
print(f"{person3.first_name} {person3.last_name}, Age: {person3.age}")
```

**Sample Run:**
```
Person Information:
----------------------------------------
Alice Johnson, Age: 28
Bob Smith, Age: 35
Charlie Brown, Age: 42
```

**Key Concepts:**
- **Class definition**: `class Person:` creates the template
- **Initializer**: `__init__` sets up each person object
- **Instance variables**: `self.first_name`, `self.last_name`, `self.age` store data
- **Object creation**: `Person(args)` creates new instances
- **Attribute access**: Use dot notation to get values
- Each object is independent with its own data

## Summary: Key Class Patterns and Techniques

### Class Definition Pattern
```python
class ClassName:
    def __init__(self, param1, param2, ...):
        self.attribute1 = param1
        self.attribute2 = param2
```

### Object Creation and Storage
```python
# Create individual objects
obj1 = ClassName(args)
obj2 = ClassName(args)

# Store in list for processing
objects = [obj1, obj2]
# OR
objects = []
objects.append(ClassName(args))
```

### Common Operations

**Finding Maximum:**
```python
max_obj = objects[0]
for obj in objects:
    if obj.attribute > max_obj.attribute:
        max_obj = obj
```

**Filtering:**
```python
filtered = []
for obj in objects:
    if obj.attribute > threshold:
        filtered.append(obj)
```

**Calculating Totals:**
```python
total = 0
for obj in objects:
    total += obj.attribute
# OR
total = sum(obj.attribute for obj in objects)
```

**Categorizing:**
```python
category1 = []
category2 = []
for obj in objects:
    if obj.category_attr == "value1":
        category1.append(obj)
    elif obj.category_attr == "value2":
        category2.append(obj)
```

### Key Principles

1. **Template-Instance Relationship**: Class defines structure, objects hold data
2. **Independence**: Each object has its own copy of all attributes
3. **Dot Notation**: Access attributes with `object.attribute`
4. **Self Parameter**: Always first in `__init__`, refers to the object being created
5. **Lists of Objects**: Store multiple objects for batch processing
6. **Derived Values**: Calculate values from object attributes (area from width/height)
7. **Object Comparison**: Compare objects by their attributes
8. **Filtering and Sorting**: Process collections based on criteria

### Problem-Solving Workflow

1. **Design**: Identify what attributes each object needs
2. **Create**: Write the class with `__init__` method
3. **Instantiate**: Create objects with specific data
4. **Process**: Loop through objects, access attributes, perform operations
5. **Display**: Format and present results

Remember: Classes organize related data into reusable templates. Objects are specific instances created from those templates. Each object maintains its own independent data while sharing the same structure defined by the class.
