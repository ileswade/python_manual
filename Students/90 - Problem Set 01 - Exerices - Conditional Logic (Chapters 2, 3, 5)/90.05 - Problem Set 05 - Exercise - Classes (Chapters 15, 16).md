# Introduction to Python Programming
## Problem Set 05 - Exercise - Classes

### Instructions

These 25 problems progressively test your understanding of classes from Chapters 12 and 13. They start with simple classes and build to complex objects with methods, state management, and special functions.

**How to use this problem set:**
- Work through them in order - difficulty increases gradually
- Problems 1-5: Basic class structure
- Problems 6-10: Adding instance variables
- Problems 11-15: Adding methods
- Problems 16-20: Methods that modify state
- Problems 21-25: Special methods and complex behavior
- Find where you struggle to identify what needs more practice!

## Level 1: Basic Class Structure (Problems 1-5)

### Problem 1: Empty Class
Create a class called `EmptyBox` with no methods or variables. Create an instance of it and print its type using `type()`.

### Problem 2: Class with One Variable
Create a class called `SimpleCounter` with just an `__init__` method that sets `self.count = 0`. Create an instance and print `instance.count`.

### Problem 3: Class with Multiple Variables
Create a class called `Point` with an `__init__` that takes `x` and `y` parameters and stores them as instance variables. Create a point at (5, 10) and print both coordinates.

### Problem 4: Multiple Instances
Create a class called `Color` that stores `red`, `green`, and `blue` values. Create three different color objects and print their values.

### Problem 5: Access and Print
Create a class called `Person` with `name` and `age` in `__init__`. Create two people and print their information in format: "Name: [name], Age: [age]"

## Level 2: Basic Methods (Problems 6-10)

### Problem 6: Simple Method
Create a class called `Greeter` with a `name` instance variable and a method `say_hello()` that prints "Hello, I'm [name]!". Create an instance and call the method.

### Problem 7: Method with Parameter
Create a class called `Calculator` with a method `double(number)` that returns the number multiplied by 2. The method doesn't use any instance variables.

### Problem 8: Method Using Instance Variables
Create a class called `Dog` with `name` and `breed`. Add a method `bark()` that prints "[name] the [breed] says: Woof!"

### Problem 9: Multiple Methods
Create a class called `Rectangle` with `width` and `height`. Add two methods:
- `area()` - returns width × height
- `perimeter()` - returns 2 × (width + height)

### Problem 10: Method Returning Boolean
Create a class called `Student` with `name` and `grade`. Add method `is_passing()` that returns True if grade >= 60, False otherwise.

## Level 3: Modifying State (Problems 11-15)

### Problem 11: Increment Counter
Create a class called `Counter` with initial value 0. Add methods:
- `increment()` - adds 1 to the count
- `get_value()` - returns current count

### Problem 12: Bank Account
Create a class called `BankAccount` with initial balance. Add methods:
- `deposit(amount)` - adds to balance
- `get_balance()` - returns current balance

### Problem 13: Traffic Light
Create a class called `TrafficLight` with initial color "red". Add method `change()` that cycles: red → green → yellow → red. Add `get_color()` to return current color.

### Problem 14: Inventory Item
Create a class called `Product` with `name` and `quantity`. Add methods:
- `restock(amount)` - increases quantity
- `sell(amount)` - decreases quantity (if enough available)
- `in_stock()` - returns True if quantity > 0

### Problem 15: Temperature Tracker
Create a class called `TemperatureLog` with an empty list of temperatures. Add methods:
- `add_reading(temp)` - appends to list
- `average()` - returns average of all readings
- `count()` - returns number of readings

## Level 4: Working with State (Problems 16-20)

### Problem 16: Shopping Cart
Create a class called `ShoppingCart` with empty items list. Each item is a dictionary with keys: "name", "price", "quantity". Add methods:
- `add_item(name, price, qty)` - adds item dict to list
- `total()` - returns sum of (price × quantity) for all items
- `item_count()` - returns total number of items

### Problem 17: Grade Book
Create a class called `GradeBook` with `student_name` and empty grades list. Add methods:
- `add_grade(grade)` - appends to grades list
- `average()` - returns average (or 0 if no grades)
- `letter_grade()` - returns "A", "B", "C", "D", or "F" based on average

### Problem 18: Playlist Manager
Create a class called `Playlist` with `name` and empty songs list. Add methods:
- `add_song(song_name)` - adds song to list
- `remove_song(song_name)` - removes first occurrence
- `song_count()` - returns number of songs
- `has_song(song_name)` - returns True if song in list

### Problem 19: Task List
Create a class called `TaskList` with empty tasks list. Each task is a dict with "description" and "completed" (boolean). Add methods:
- `add_task(description)` - adds task (completed=False)
- `complete_task(description)` - sets completed=True for matching task
- `remaining()` - returns count of incomplete tasks

### Problem 20: Score Tracker
Create a class called `Game` with `player_name` and `score` starting at 0. Add methods:
- `add_points(points)` - increases score
- `subtract_points(points)` - decreases score (minimum 0)
- `reset()` - sets score back to 0
- `get_score()` - returns current score

## Level 5: Special Methods (Problems 21-25)

### Problem 21: String Representation
Create a class called `Book` with `title` and `author`. Add `__str__` method that returns: '"[title]" by [author]'

Test by creating a book and printing it.

### Problem 22: Both __str__ and __repr__
Create a class called `Coordinate` with `x` and `y`. Add:
- `__str__` - returns "(x, y)"
- `__repr__` - returns "Coordinate(x, y)"

Test both with `print()` and `repr()`.

### Problem 23: Complete Student Class
Create a class called `Student` with `name`, `student_id`, and empty grades list. Add:
- `add_grade(grade)` - appends to grades
- `average()` - returns average grade
- `__str__` - returns "Student: [name] (ID: [student_id])"
- `__repr__` - returns "Student('[name]', '[id]')"

### Problem 24: Bank Account with String
Create a class called `Account` with `account_number` and `balance`. Add:
- `deposit(amount)` - increases balance
- `withdraw(amount)` - decreases if sufficient funds, else print error
- `__str__` - returns "Account [number]: $[balance]"
- `__repr__` - returns "Account('[number]', [balance])"

### Problem 25: Complete Shopping System
Create a class called `Order` with `order_id` and empty items list. Each item dict has: "name", "price", "quantity". Add:
- `add_item(name, price, qty)` - adds item
- `remove_item(name)` - removes all items with that name
- `subtotal()` - returns sum before tax
- `tax(rate)` - returns subtotal × rate
- `total(tax_rate)` - returns subtotal + tax
- `__str__` - returns formatted order:
  ```
  Order #[id]
  Items: [count]
  Total: $[amount]
  ```
- `__repr__` - returns "Order('[id]', [item_count] items)"

## Testing Tips

1. **Test incrementally:** After writing `__init__`, create an object and print its attributes

2. **Test each method:** Call each method separately to verify it works

3. **Print state:** Add temporary print statements to see how state changes

4. **Test edge cases:**
   - What if balance is 0?
   - What if list is empty?
   - What if quantity is negative?

5. **Test special methods:**
   - Use `print(object)` to test `__str__`
   - Use `repr(object)` to test `__repr__`

---

## Common Mistakes to Watch For

- **Forgetting `self`:** Always use `self.variable` to access instance variables
- **Not using `self` in methods:** First parameter must be `self`
- **Returning vs printing:** Methods should usually `return`, not `print`
- **Modifying wrong variable:** Make sure you're changing `self.variable`, not a local variable
- **Forgetting to call methods:** Use `object.method()` not `object.method`
- **String representation:** `__str__` should return a string, not print it
