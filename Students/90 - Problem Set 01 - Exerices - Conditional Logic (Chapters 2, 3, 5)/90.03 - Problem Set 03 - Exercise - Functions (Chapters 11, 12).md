# Introduction to Python Programming
## Problem Set 03 - Exercise - Functions

### Instructions

These 25 problems progressively test your understanding of functions from Chapters 8 and 9. They start with simple no-parameter functions and build to advanced recursive functions with optional parameters.

**How to use this problem set:**
- Work through them in order - difficulty increases gradually
- Problems 1-8 focus on basic functions and parameters
- Problems 9-16 introduce return values and validation
- Problems 17-21 cover optional parameters and named arguments
- Problems 22-25 combine recursion with advanced concepts
- Don't expect to solve all 25 - find your skill level!

---

## Level 1: Basic Functions (Problems 1-5)

### Problem 1: Simple Greeting
Create a function called `say_hello()` that prints "Hello, World!" when called. Call it three times.

### Problem 2: Display Menu
Create a function called `show_menu()` that displays a menu with 3 options:
```
1. Start Game
2. Settings
3. Quit
```
Call the function once.

### Problem 3: Print Pattern
Create a function called `print_stars()` that prints 5 asterisks in a row: `*****`
Call it 3 times to make 3 rows.

### Problem 4: Name Greeter
Create a function called `greet_user(name)` that takes a name parameter and prints: "Welcome, [name]!"
Call it with three different names.

### Problem 5: Add Two Numbers
Create a function called `add(a, b)` that takes two numbers and prints their sum.
Call it with different number pairs.

## Level 2: Return Values (Problems 6-10)

### Problem 6: Multiply Function
Create a function called `multiply(x, y)` that returns the product of x and y.
Store the result in a variable and print it.

### Problem 7: Calculate Area
Create a function called `rectangle_area(width, height)` that returns the area.
Use it to calculate and print the area of a 5x10 rectangle.

### Problem 8: Is Adult
Create a function called `is_adult(age)` that returns True if age >= 18, False otherwise.
Test it with ages 15, 18, and 25.

### Problem 9: Find Maximum
Create a function called `find_max(a, b, c)` that returns the largest of three numbers.
Print the maximum of 5, 12, and 8.

### Problem 10: Grade Letter
Create a function called `get_grade(score)` that returns a letter grade:
- 90+: "A"
- 80-89: "B"
- 70-79: "C"
- 60-69: "D"
- Below 60: "F"

## Level 3: Validation and Logic (Problems 11-15)

### Problem 11: Validate Range
Create a function `is_in_range(number, low, high)` that returns True if number is between low and high (inclusive), False otherwise.

### Problem 12: Calculate Discount
Create a function `apply_discount(price, discount_percent)` that returns the price after discount.
For example: price=100, discount=20 should return 80.

### Problem 13: Even or Odd (Compact)
Create a function `is_even(number)` that returns the boolean result directly without if/else.
Use: `return number % 2 == 0`

### Problem 14: Temperature Converter
Create a function `celsius_to_fahrenheit(celsius)` that converts and returns Fahrenheit.
Formula: F = (C × 9/5) + 32

### Problem 15: Count Vowels
Create a function `count_vowels(text)` that returns how many vowels (a,e,i,o,u) are in the text.
Use a loop and counter.

## Level 4: Optional Parameters (Problems 16-20)

### Problem 16: Power with Default
Create a function `power(base, exponent=2)` that returns base raised to exponent.
Default exponent should be 2 (squaring).
Test: power(5) should return 25, power(5, 3) should return 125.

### Problem 17: Greeting with Options
Create a function `greet(name, greeting="Hello", punctuation="!")` that returns a formatted greeting.
Example: greet("Alice") returns "Hello, Alice!"
Test with different combinations of arguments.

### Problem 18: Calculate Total
Create a function `calculate_total(price, quantity=1, tax_rate=0.05)` that returns total with tax.
Formula: (price × quantity) × (1 + tax_rate)

### Problem 19: Format Name
Create a function `format_name(first, last, middle="")` that returns formatted full name.
If middle is provided: "First Middle Last"
If not: "First Last"

### Problem 20: Create Rectangle Info
Create a function `rectangle_info(width, height, unit="cm")` that returns a string:
"Rectangle: [width] x [height] [unit], Area: [area] [unit]²"
Example: rectangle_info(5, 10) returns "Rectangle: 5 x 10 cm, Area: 50 cm²"

## Level 5: Named Arguments and Complex Logic (Problems 21-22)

### Problem 21: Pizza Order
Create a function `order_pizza(size, toppings=1, delivery=False, tip_percent=15)` that calculates total cost:
- Small: $10, Medium: $15, Large: $20
- Each topping: $2
- Delivery fee: $5 (if delivery=True)
- Calculate subtotal, then add tip based on tip_percent
Return the total cost.

Call it using named arguments in different orders.

### Problem 22: Student Report
Create a function `create_report(name, grade, subject="Math", passed=True, extra_credit=0)` that returns a formatted string:
```
Student: [name]
Subject: [subject]
Grade: [grade + extra_credit]
Status: [Passed/Failed]
```
Test with various combinations of positional and named arguments.

## Level 6: Recursion (Problems 23-25)

### Problem 23: Recursive Countdown
Create a recursive function `countdown(n)` that prints numbers from n down to 1, then prints "Blastoff!"
Base case: when n <= 0
Recursive case: print n, then call countdown(n-1)

### Problem 24: Factorial with Validation
Create a recursive function `factorial(n, show_steps=False)` that:
- Returns factorial of n (n!)
- If show_steps is True, prints each step
- Handles invalid input (n < 0) by returning "Invalid input"

Base case: n = 0 or 1, return 1
Recursive case: return n × factorial(n-1)

### Problem 25: Advanced Fibonacci
Create a recursive function `fibonacci(n, starting_values=(0, 1))` that:
- Calculates the nth Fibonacci number
- Allows custom starting values (optional parameter as tuple)
- Standard: (0, 1) gives 0, 1, 1, 2, 3, 5, 8...
- Custom: (2, 3) gives 2, 3, 5, 8, 13...

Requirements:
- Handle base cases for n=0 and n=1 using the starting_values
- Use recursion for n >= 2
- Return the calculated number

Hint: For custom starting values, you'll need to think about how to access tuple elements.

## Testing Tips

1. **Test edge cases:**
   - What if a number is 0? Negative?
   - What if a string is empty?
   - What about the minimum/maximum values?

2. **Verify return vs print:**
   - Can you use the function's result in a calculation?
   - Or does it just display something?

3. **Check parameter order:**
   - Are positional arguments working correctly?
   - Do named arguments work in any order?

4. **Test defaults:**
   - Does the function work without optional arguments?
   - Does it work when you override defaults?

5. **Debug recursion:**
   - Does it reach the base case?
   - Is it making progress toward the base case?
   - Try with small values first (n=1, n=2, n=3)

---

## Common Mistakes to Watch For

- **Forgetting to return:** Function does calculation but doesn't return result
- **Calling without parentheses:** `greet` instead of `greet()`
- **Wrong parameter order:** Positional arguments in wrong sequence
- **Default parameter position:** Defaults not at the end of parameter list
- **Infinite recursion:** No base case or not progressing toward it
- **Mutable defaults:** Using list or dict as default value
- **Named before positional:** Named argument before positional argument
