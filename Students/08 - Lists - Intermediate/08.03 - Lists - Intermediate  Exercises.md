### Example 1: Understanding References vs Copies with Practical Implications
**Problem:** Create two lists: one containing student names and another containing their scores. Demonstrate the difference between assignment (reference) and copying. Show what happens when you modify each version, and explain why understanding this is critical for avoiding bugs.

**Detailed Solution:**

**Step 1: Understand the core concept**
When you write `list_b = list_a`, Python does NOT create a new list. Instead, both variables point to the SAME list in memory. This is called a **reference**.

```python
list_a = [1, 2, 3]
list_b = list_a  # Reference, not a copy!
```

In memory:
```
list_a ──→ [1, 2, 3]
           ↑
list_b ────┘
```

**Step 2: Demonstrate the problem**
```python
scores = [85, 92, 78]
backup_scores = scores  # Trying to "backup" - WRONG!

backup_scores[0] = 100  # Modify backup

print(f"Original: {scores}")        # [100, 92, 78] - Changed!
print(f"Backup: {backup_scores}")   # [100, 92, 78]
```

Both changed because they're the same list!

**Step 3: The correct way - using .copy()**
```python
scores = [85, 92, 78]
backup_scores = scores.copy()  # Create independent copy

backup_scores[0] = 100  # Modify backup

print(f"Original: {scores}")        # [85, 92, 78] - Unchanged!
print(f"Backup: {backup_scores}")   # [100, 92, 78]
```

Now they're separate lists.

**Step 4: Real-world scenario**

**Complete Solution:**
```python
# Student grade management system
print("=== Grade Management System ===\n")

# Original grades
students = ["Alice", "Bob", "Charlie"]
grades = [85, 92, 78]

print("Original Data:")
print(f"Students: {students}")
print(f"Grades: {grades}\n")

# WRONG: Trying to create a backup with assignment
print("--- Using Assignment (Reference) ---")
backup_grades = grades  # This creates a reference!

# Curve grades up by 5 points
for i in range(len(backup_grades)):
    backup_grades[i] = backup_grades[i] + 5

print(f"After curving 'backup':")
print(f"Original grades: {grades}")      # [90, 97, 83] - CHANGED!
print(f"Backup grades: {backup_grades}") # [90, 97, 83]
print("Problem: Both changed because they're the same list!\n")

# Reset for next example
grades = [85, 92, 78]

# CORRECT: Creating an actual copy
print("--- Using .copy() (Independent Copy) ---")
backup_grades = grades.copy()  # This creates a separate list!

# Curve grades up by 5 points
for i in range(len(backup_grades)):
    backup_grades[i] = backup_grades[i] + 5

print(f"After curving backup:")
print(f"Original grades: {grades}")      # [85, 92, 78] - Unchanged!
print(f"Backup grades: {backup_grades}") # [90, 97, 83]
print("Success: Original preserved!\n")

# Demonstrating with ID (memory address)
print("--- Understanding Memory Addresses ---")
grades = [85, 92, 78]

reference = grades
copy = grades.copy()

print(f"Original ID: {id(grades)}")
print(f"Reference ID: {id(reference)}")  # Same ID!
print(f"Copy ID: {id(copy)}")            # Different ID!

print(f"\nSame memory? Reference: {id(grades) == id(reference)}")  # True
print(f"Same memory? Copy: {id(grades) == id(copy)}")              # False
```

**Output:**
```
=== Grade Management System ===

Original Data:
Students: ['Alice', 'Bob', 'Charlie']
Grades: [85, 92, 78]

--- Using Assignment (Reference) ---
After curving 'backup':
Original grades: [90, 97, 83]
Backup grades: [90, 97, 83]
Problem: Both changed because they're the same list!

--- Using .copy() (Independent Copy) ---
After curving backup:
Original grades: [85, 92, 78]
Backup grades: [90, 97, 83]
Success: Original preserved!

--- Understanding Memory Addresses ---
Original ID: 140234567891234
Reference ID: 140234567891234
Copy ID: 140234567898765

Same memory? Reference: True
Same memory? Copy: False
```

**Key Concepts:**
- **Assignment (=) creates a reference**: Both variables point to the same list
- **.copy() creates an independent copy**: New list in different memory location
- **Modifying a reference affects the original**: Because they're the same list
- **id() function shows memory address**: Same id = same object in memory
- **Why this matters**: Prevents accidental data corruption

**When to use each:**
- Use **reference** when: You want two names for the same list, changes should affect both
- Use **.copy()** when: You need an independent backup, protecting original data

**Common mistake:**
```python
# Trying to protect data
original = [1, 2, 3]
backup = original  # WRONG - not actually a backup!
```

### Example 2: List Slicing for Data Manipulation
**Problem:** You have a list of 20 daily temperatures. Use slicing to: (1) get the first week's data, (2) get the last week's data, (3) get every other day, (4) reverse the list, and (5) split into two halves. Show the slice notation and explain how it works.

**Detailed Solution:**

**Step 1: Understand slicing syntax**
Format: `list[start:stop:step]`
- **start**: Where to begin (inclusive)
- **stop**: Where to end (exclusive)
- **step**: How many to skip (default 1)

**Step 2: Review key slicing rules**
- `[:n]` - First n items
- `[n:]` - From n to end
- `[-n:]` - Last n items
- `[:-n]` - All but last n items
- `[::step]` - Every step-th item
- `[::-1]` - Reverse the list

**Step 3: Generate sample data**
```python
# 20 days of temperatures
temps = [72, 75, 73, 68, 70, 74, 76, 78, 80, 77,
         79, 81, 75, 73, 71, 69, 72, 74, 76, 78]
```

**Step 4: Apply different slicing operations**

**Complete Solution:**
```python
# 20 days of temperature data
temperatures = [72, 75, 73, 68, 70, 74, 76, 78, 80, 77,
                79, 81, 75, 73, 71, 69, 72, 74, 76, 78]

print("=== Temperature Data Analysis ===")
print(f"Full dataset ({len(temperatures)} days): {temperatures}\n")

# 4. Reverse the list

print(f"Slice: temperatures[::-1]")
print(f"Result: {reversed_temps}")
print(f"Explanation: Step of -1 goes backwards from end to start\n")

# 5. Split into two halves
print("--- Split into Two Halves ---")

first_half = temperatures[:midpoint]

print(f"First half: temperatures[:{midpoint}]")
print(f"  Result: {first_half}")
print(f"Second half: temperatures[{midpoint}:]")
print(f"  Result: {second_half}\n")

print(f"Trimmed [1:-1]: {trim}")

# Reverse every other element
reverse_alt = temperatures[::-2]
print(f"Reverse, every other [::-2]: {reverse_alt}")

# Calculate statistics on slices
print("\n--- Statistics ---")
print(f"First week average: {sum(first_week) / len(first_week):.1f}°")
print(f"Last week average: {sum(last_week) / len(last_week):.1f}°")
print(f"Overall average: {sum(temperatures) / len(temperatures):.1f}°")
```

- **Slicing creates a new list**: Original is unchanged

**Slice notation memory aid:**

     |     |    └─ How many to skip (default: 1)
     |     └────── Where to end (not included)
     └──────────── Where to begin (included)

### Example 3: List Methods and Modifications
**Problem:** Start with an empty list and build a todo list application. Demonstrate append(), insert(), extend(), remove(), pop(), sort(), and reverse(). Show when each method modifies the original list vs returning a new one. Handle the case where remove() is called on a non-existent item.

**Detailed Solution:**

**Step 1: Understand list methods**
**Modifying methods** (change original list):
- `append(item)` - Add to end
- `insert(index, item)` - Add at position
- `extend(list)` - Add multiple items
- `remove(value)` - Remove first occurrence
- `pop(index)` - Remove and return item
- `sort()` - Sort in place
- `reverse()` - Reverse in place

**Non-modifying functions** (return new list):
- `sorted(list)` - Return sorted copy
- `list[::-1]` - Return reversed copy

**Step 2: Build incrementally**

**Complete Solution:**
```python
# Todo List Application
print("=== TODO LIST APPLICATION ===\n")

# Start with empty list
todos = []
print(f"Starting list: {todos}\n")

# 1. APPEND - Add items to end
print("--- Using append() ---")
todos.append("Buy groceries")
print(f"After append('Buy groceries'): {todos}")

todos.append("Walk dog")
print(f"After append('Walk dog'): {todos}")

todos.append("Finish homework")
print(f"After append('Finish homework'): {todos}\n")

# 2. INSERT - Add at specific position
print("--- Using insert() ---")
todos.insert(0, "Wake up")  # Add at beginning
print(f"After insert(0, 'Wake up'): {todos}")

todos.insert(2, "Eat breakfast")  # Add at index 2
print(f"After insert(2, 'Eat breakfast'): {todos}\n")

# 3. EXTEND - Add multiple items
print("--- Using extend() ---")
more_tasks = ["Call mom", "Read book"]
todos.extend(more_tasks)
print(f"After extend({more_tasks}): {todos}\n")

# 4. REMOVE - Remove by value
print("--- Using remove() ---")
print(f"Current list: {todos}")

# Safe removal with check
task_to_remove = "Walk dog"
if task_to_remove in todos:
    todos.remove(task_to_remove)
    print(f"Removed '{task_to_remove}': {todos}")
else:
    print(f"'{task_to_remove}' not in list")

# Demonstrate error handling
print("\nTrying to remove non-existent item:")
try:
    todos.remove("Go to gym")
except ValueError as e:
    print(f"Error: {e}")
    print("Item not in list - no change made\n")

# 5. POP - Remove by index and return it
print("--- Using pop() ---")
completed_task = todos.pop(0)  # Remove first item
print(f"Completed and removed: '{completed_task}'")
print(f"After pop(0): {todos}")

last_task = todos.pop()  # Remove last item (no index)
print(f"Completed and removed: '{last_task}'")
print(f"After pop(): {todos}\n")

# 6. SORT - Alphabetical order (modifies original)
print("--- Using sort() ---")
print(f"Before sort: {todos}")
todos.sort()
print(f"After sort(): {todos}")
print(f"Original list was modified: {todos}\n")

# 7. SORTED - Create sorted copy (doesn't modify original)
print("--- Using sorted() ---")
todos = ["Finish homework", "Buy groceries", "Eat breakfast", "Call mom"]
print(f"Original: {todos}")

sorted_todos = sorted(todos)
print(f"Sorted copy: {sorted_todos}")
print(f"Original unchanged: {todos}\n")

# 8. REVERSE - Flip order (modifies original)
print("--- Using reverse() ---")
print(f"Before reverse: {todos}")
todos.reverse()
print(f"After reverse(): {todos}\n")

# 9. Reverse with slicing (doesn't modify original)
print("--- Reversing with slicing ---")
todos = ["Task A", "Task B", "Task C", "Task D"]
print(f"Original: {todos}")

reversed_copy = todos[::-1]
print(f"Reversed copy: {reversed_copy}")
print(f"Original unchanged: {todos}\n")

# Complete example with error handling
print("=== COMPLETE TODO MANAGER ===\n")

def add_task(tasks, task):
    """Add task to list."""
    tasks.append(task)
    print(f"Added: '{task}'")

def remove_task(tasks, task):
    """Safely remove task from list."""
    if task in tasks:
        tasks.remove(task)
        print(f"Removed: '{task}'")
        return True
    else:
        print(f"Task '{task}' not found!")
        return False

def complete_task(tasks, index):
    """Remove and return task at index."""
    try:
        task = tasks.pop(index)
        print(f"Completed: '{task}'")
        return task
    except IndexError:
        print(f"No task at index {index}")
        return None

def show_tasks(tasks):
    """Display all tasks."""
    if not tasks:
        print("No tasks in list!")
    else:
        print("Current tasks:")
        for i, task in enumerate(tasks, 1):
            print(f"  {i}. {task}")

# Demo the manager
my_todos = []

add_task(my_todos, "Morning jog")
add_task(my_todos, "Team meeting")
add_task(my_todos, "Lunch")
add_task(my_todos, "Code review")

print()
show_tasks(my_todos)

print()
remove_task(my_todos, "Lunch")

print()
complete_task(my_todos, 0)

print()
show_tasks(my_todos)
```

**Output:**

**Key Concepts:**
- **Modifying methods change original**: append, insert, extend, remove, pop, sort, reverse
- **Functions return new list**: sorted(), [::-1] slicing
- **remove() raises ValueError**: If item not in list (check first!)
- **pop() returns the removed item**: Useful for processing
- **sort() vs sorted()**: sort() modifies, sorted() creates copy
- **reverse() vs [::-1]**: reverse() modifies, [::-1] creates copy
- **Always check before remove()**: Use `if item in list:` to avoid errors

**Method comparison:**
| Method | Modifies Original? | Returns Value? | Purpose |
|--------|-------------------|----------------|---------|
| append() | Yes | None | Add to end |
| insert() | Yes | None | Add at position |
| extend() | Yes | None | Add multiple |
| remove() | Yes | None | Remove by value |
| pop() | Yes | Item | Remove & return |
| sort() | Yes | None | Sort in place |
| reverse() | Yes | None | Reverse in place |
| sorted() | No | New list | Return sorted copy |
| [::-1] | No | New list | Return reversed copy |

## Tips for Solving These Problems

### Understanding References
1. **Assignment (=) creates reference**: Both variables point to same memory location
2. **Use .copy() for independence**: Creates new list in different memory
3. **Test with id()**: Same id = same object
4. **Modify and observe**: Change one, check if both changed
5. **Shallow vs deep copy**: .copy() only copies outer list, not nested structures

### Adding Elements Patterns
```python
# Append to end
my_list.append(item)

# Insert at position
my_list.insert(index, item)

# Add multiple items
my_list.extend([item1, item2, item3])

# Concatenate (creates new list)
new_list = list1 + list2
```

### Removing Elements Safely
```python
# Check before remove
if item in my_list:
    my_list.remove(item)

# Pop with error handling
try:
    item = my_list.pop(index)
except IndexError:
    print("Index out of range")

# Del by index
del my_list[index]

# Clear all
my_list.clear()
```

### Slicing Mastery
```python
# Basic slicing
my_list[start:stop]       # From start to stop-1
my_list[:n]               # First n items
my_list[n:]               # From n to end
my_list[-n:]              # Last n items
my_list[:-n]              # All but last n

# With step
my_list[::2]              # Every 2nd item
my_list[1::2]             # Every 2nd, starting at 1
my_list[::-1]             # Reverse
my_list[::-2]             # Every 2nd, reversed
```

### Sorting Guidelines
```python
# Modify original
my_list.sort()            # Sort in place
my_list.reverse()         # Reverse in place

# Create new list
sorted_copy = sorted(my_list)
reversed_copy = my_list[::-1]

# Sort with reverse
my_list.sort(reverse=True)
sorted_desc = sorted(my_list, reverse=True)
```

### Problem-Solving Strategy
1. **Understand if modification is needed**: Sort vs sorted, reverse vs [::-1]
2. **Check for side effects**: Will original list change?
3. **Handle errors**: Check existence before remove, try-except for pop
4. **Test with id()**: Verify reference vs copy behavior
5. **Preserve data when needed**: Make copies before destructive operations

### Common Pitfalls to Avoid
1. **Forgetting .copy()**: Thinking assignment creates a copy
2. **Modifying while iterating**: Changing list size during loop
3. **Index errors with del**: Indices shift after deletion
4. **ValueError with remove()**: Removing non-existent items
5. **Confusing sort() and sorted()**: One modifies, one returns new

### Debugging Tips
1. **Print before and after**: See what changed
   ```python
   print(f"Before: {my_list}")
   # operation
   print(f"After: {my_list}")
   ```

2. **Use id() to check identity**:
   ```python
   print(f"ID of list_a: {id(list_a)}")
   print(f"ID of list_b: {id(list_b)}")
   ```

3. **Test slicing with small lists**:
