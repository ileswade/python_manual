### Example 1: Building a Course Management System with Nested Dictionaries
**Problem:** Create a system that manages multiple courses, each with students who have grades. Build a nested dictionary structure and implement functions to: (1) add a student to a course, (2) record a grade for a student, and (3) calculate the average grade for each student in a course.

**Detailed Solution:**

**Step 1: Understand the data structure needed**
We need to organize data hierarchically:
- Top level: courses (dictionary with course names as keys)
- Second level: each course contains student information
- Third level: each student has multiple grades

Structure: `{course_name: {student_name: [grades]}}`

**Step 2: Plan the functions**
- `add_student()`: Check if course exists, create if needed, add student with empty grade list
- `add_grade()`: Verify course and student exist, append grade to their list
- `calculate_averages()`: Iterate through students, compute average of their grades

**Step 3: Consider edge cases**
- What if course doesn't exist when adding student?
- What if student doesn't exist when adding grade?
- What if student has no grades when calculating average?

**Step 4: Implement with validation**

**Complete Solution:**
```python
def add_student(courses, course_name, student_name):
    """Add a student to a course."""
    # Create course if it doesn't exist
    if course_name not in courses:
        courses[course_name] = {}
    
    # Add student with empty grade list
    if student_name not in courses[course_name]:
        courses[course_name][student_name] = []
        print(f"Added {student_name} to {course_name}")
    else:
        print(f"{student_name} already in {course_name}")


def add_grade(courses, course_name, student_name, grade):
    """Add a grade for a student in a course."""
    # Check if course exists
    if course_name not in courses:
        print(f"Course {course_name} doesn't exist")
        return
    
    # Check if student exists in course
    if student_name not in courses[course_name]:
        print(f"{student_name} not enrolled in {course_name}")
        return
    
    # Add the grade
    courses[course_name][student_name].append(grade)
    print(f"Added grade {grade} for {student_name} in {course_name}")


def calculate_averages(courses, course_name):
    """Calculate and display average grades for all students in a course."""
    if course_name not in courses:
        print(f"Course {course_name} doesn't exist")
        return
    
    print(f"\n{course_name} - Student Averages:")
    print("-" * 40)
    
    for student, grades in courses[course_name].items():
        if len(grades) == 0:
            print(f"{student}: No grades yet")
        else:
            average = sum(grades) / len(grades)
            print(f"{student}: {average:.2f} (grades: {grades})")


# Test the system

# Add students

add_student(courses, "Python 101", "Bob")
add_student(courses, "Data Science", "Alice")

add_grade(courses, "Python 101", "Alice", 88)
add_grade(courses, "Python 101", "Bob", 78)
add_grade(courses, "Python 101", "Bob", 85)

# Calculate averages
calculate_averages(courses, "Python 101")

# Show the complete structure
print("\nComplete structure:")
print(courses)
```

### Example 2: GPS Route Optimizer with Distance Calculations
**Problem:** Create a GPS route optimizer that: (1) stores multiple locations as tuples of (name, lat, lon), (2) calculates distances between all pairs of locations using the Haversine formula, (3) finds the shortest route visiting all locations, and (4) calculates the total distance.

**Detailed Solution:**

**Step 1: Understand the problem components**
- Store locations as tuples (immutable coordinates)
- Calculate pairwise distances (n × n comparisons)
- Find optimal route (simplified: try all permutations for small sets)
- Report total distance

**Step 2: Break down the Haversine formula**
The formula calculates great-circle distance between two points on a sphere:
1. Convert coordinates to radians
2. Calculate differences in latitude and longitude
3. Apply Haversine formula: a = sin²(Δlat/2) + cos(lat1) × cos(lat2) × sin²(Δlon/2)
4. Calculate distance: d = 2R × arcsin(√a), where R is Earth's radius

**Step 3: Plan the route optimization**
For a small number of locations, we can:
- Generate all possible routes
- Calculate distance for each route
- Return the shortest one

**Step 4: Implement with clear structure**

**Complete Solution:**
```python
import math
from itertools import permutations

def haversine_distance(coord1, coord2):
    """Calculate distance between two GPS coordinates in km."""
    lat1, lon1 = coord1
    lat2, lon2 = coord2
    
    R = 6371  # Earth's radius in km
    
    # Convert to radians
    lat1, lon1, lat2, lon2 = map(math.radians, [lat1, lon1, lat2, lon2])
    
    # Haversine formula
    dlat = lat2 - lat1
    dlon = lon2 - lon1
    a = math.sin(dlat/2)**2 + math.cos(lat1) * math.cos(lat2) * math.sin(dlon/2)**2
    c = 2 * math.asin(math.sqrt(a))
    
    return R * c


def calculate_route_distance(route, locations):
    """Calculate total distance for a route."""
    total = 0
    for i in range(len(route) - 1):
        loc1 = locations[route[i]]
        loc2 = locations[route[i + 1]]
        total += haversine_distance(loc1[1], loc2[1])
    return total


def find_shortest_route(locations):
    """Find the shortest route visiting all locations."""
    # Extract location names
    names = list(locations.keys())
    
    # Start from first location, permute the rest
    start = names[0]
    remaining = names[1:]
    
    best_route = None
    best_distance = float('inf')
    
    # Try all permutations
    for perm in permutations(remaining):
        route = [start] + list(perm)
        distance = calculate_route_distance(route, locations)
        
        if distance < best_distance:
            best_distance = distance
            best_route = route
    
    return best_route, best_distance


def display_route(route, locations):
    """Display route with distances between stops."""
    print("\nRoute Details:")
    print("=" * 50)
    
    for i in range(len(route)):
        name = route[i]
        lat, lon = locations[name][1]
        print(f"{i+1}. {name}: ({lat:.4f}°, {lon:.4f}°)")
        
        if i < len(route) - 1:
            next_name = route[i + 1]
            dist = haversine_distance(locations[name][1], locations[next_name][1])
            print(f"   ↓ {dist:.2f} km")
    
    print("=" * 50)


# Define locations (name, (lat, lon))
locations = {
    "Calgary": ("Calgary", (51.0447, -114.0719)),
    "Banff": ("Banff", (51.1784, -115.5708)),
    "Lake Louise": ("Lake Louise", (51.4254, -116.1773)),
    "Jasper": ("Jasper", (52.8737, -118.0814))
}

# Find optimal route
best_route, total_distance = find_shortest_route(locations)

print(f"Optimal route starting from {best_route[0]}:")
print(" → ".join(best_route))
print(f"\nTotal distance: {total_distance:.2f} km")

# Show detailed route
display_route(best_route, locations)
```

**Output:**

```
Route Details:
==================================================
1. Calgary: (51.0447°, -114.0719°)
   ↓ 104.58 km
2. Banff: (51.1784°, -115.5708°)
   ↓ 57.89 km
3. Lake Louise: (51.4254°, -116.1773°)
   ↓ 124.98 km
4. Jasper: (52.8737°, -118.0814°)
==================================================
```

**Key Concepts:**
- **Tuples for coordinates**: Immutable pairs perfect for (lat, lon) data
- **Haversine formula**: Standard method for calculating distances on a sphere
- **Permutations**: Generate all possible orderings to find optimal route
- **Tuple unpacking**: Clean syntax for extracting coordinate pairs
- **Practical algorithms**: Route optimization is a real-world logistics problem

### Example 3: JSON Configuration Manager for Application Settings
**Problem:** Create a configuration manager that: (1) loads settings from a JSON file, (2) validates the settings structure, (3) provides safe access to nested settings with defaults, (4) saves modified settings back to JSON.

**Detailed Solution:**

**Step 1: Understand JSON configuration patterns**
Applications often use JSON for configuration:
- Hierarchical settings (database → host, port, username)
- Lists of items (allowed users, feature flags)
- Nested structures (logging → level, file, format)

**Step 2: Plan validation strategy**
- Check required keys exist
- Verify data types
- Validate value ranges (e.g., port numbers)
- Provide helpful error messages

**Step 3: Implement safe access pattern**
Use `.get()` with defaults to prevent KeyError on missing keys. Support nested access like "database.host".

**Step 4: Build complete system**

**Complete Solution:**
```python
import json

class ConfigManager:
    """Manage application configuration with JSON storage."""
    
    def __init__(self, config_file):
        """Initialize and load configuration."""
        self.config_file = config_file
        self.config = {}
        self.load()
    
    def load(self):
        """Load configuration from JSON file."""
        try:
            with open(self.config_file, 'r') as f:
                self.config = json.load(f)
            print(f"Configuration loaded from {self.config_file}")
        except FileNotFoundError:
            print(f"Config file not found, using defaults")
            self.config = self._default_config()
        except json.JSONDecodeError as e:
            print(f"Error parsing JSON: {e}")
            self.config = self._default_config()
    
    def _default_config(self):
        """Return default configuration."""
        return {
            "database": {
                "host": "localhost",
                "port": 5432,
                "name": "myapp"
            },
            "logging": {
                "level": "INFO",
                "file": "app.log"
            },
            "features": {
                "debug_mode": False,
                "max_users": 100
            }
        }
    
    def get(self, key_path, default=None):
        """
        Get configuration value with dot notation.
        Example: get("database.host") returns "localhost"
        """
        keys = key_path.split('.')
        value = self.config
        
        for key in keys:
            if isinstance(value, dict) and key in value:
                value = value[key]
            else:
                return default
        
        return value
    
    def set(self, key_path, value):
        """Set configuration value with dot notation."""
        keys = key_path.split('.')
        config = self.config
        
        # Navigate to the parent dictionary
        for key in keys[:-1]:
            if key not in config:
                config[key] = {}
            config = config[key]
        
        # Set the value
        config[keys[-1]] = value
        print(f"Set {key_path} = {value}")
    
    def validate(self):
        """Validate configuration structure and values."""
        errors = []
        
        # Check required keys
        required = [
            ("database", dict),
            ("database.host", str),
            ("database.port", int),
            ("logging", dict),
            ("logging.level", str)
        ]
        
        for key_path, expected_type in required:
            value = self.get(key_path)
            if value is None:
                errors.append(f"Missing required key: {key_path}")
            elif not isinstance(value, expected_type):
                errors.append(f"Invalid type for {key_path}: expected {expected_type.__name__}")
        
        # Validate port range
        port = self.get("database.port")
        if port and (port < 1 or port > 65535):
            errors.append(f"Invalid port number: {port}")
        
        # Validate log level
        valid_levels = ["DEBUG", "INFO", "WARNING", "ERROR"]
        log_level = self.get("logging.level")
        if log_level and log_level not in valid_levels:
            errors.append(f"Invalid log level: {log_level}")
        
        if errors:
            print("Configuration errors found:")
            for error in errors:
                print(f"  - {error}")
            return False
        else:
            print("Configuration is valid")
            return True
    
    def save(self):
        """Save configuration to JSON file."""
        with open(self.config_file, 'w') as f:
            json.dump(self.config, f, indent=4)
        print(f"Configuration saved to {self.config_file}")
    
    def display(self):
        """Display configuration in readable format."""
        print("\nCurrent Configuration:")
        print("=" * 50)
        print(json.dumps(self.config, indent=2))
        print("=" * 50)


# Demo usage
config = ConfigManager("app_config.json")

# Display initial configuration
config.display()

# Access values safely
db_host = config.get("database.host", "localhost")
db_port = config.get("database.port", 5432)
print(f"\nDatabase: {db_host}:{db_port}")

# Modify settings
config.set("database.host", "production-server.com")
config.set("features.debug_mode", True)

# Validate configuration
config.validate()

# Save changes
config.save()

# Show updated configuration
config.display()
```

## Tips for Solving These Problems

### Working with Nested Structures

**Pattern 1: Safe nested access**
```python
# Instead of: value = data["level1"]["level2"]["level3"]
# Use:
value = data.get("level1", {}).get("level2", {}).get("level3", default_value)
```

**Pattern 2: Building nested structures incrementally**
```python
# Initialize outer structure
data = {}

# Check and create nested levels as needed
if key1 not in data:
    data[key1] = {}
if key2 not in data[key1]:
    data[key1][key2] = []

# Now safe to append
data[key1][key2].append(value)
```

**Pattern 3: Iterating nested dictionaries**
```python
for outer_key, outer_value in data.items():
    if isinstance(outer_value, dict):
        for inner_key, inner_value in outer_value.items():
            # Process nested items
            pass
```

### GPS Calculation Patterns

**Distance calculation template:**
```python
import math

def distance(coord1, coord2):
    lat1, lon1 = coord1
    lat2, lon2 = coord2
    
    R = 6371  # Earth's radius in km
    
    # Convert to radians
    lat1, lon1, lat2, lon2 = map(math.radians, [lat1, lon1, lat2, lon2])
    
    # Haversine formula
    dlat = lat2 - lat1
    dlon = lon2 - lon1
    a = math.sin(dlat/2)**2 + math.cos(lat1) * math.cos(lat2) * math.sin(dlon/2)**2
    c = 2 * math.asin(math.sqrt(a))
    
    return R * c
```

**Finding closest location:**
```python
def find_closest(target, locations):
    closest = None
    min_distance = float('inf')
    
    for name, coords in locations.items():
        dist = distance(target, coords)
        if dist < min_distance:
            min_distance = dist
            closest = name
    
    return closest, min_distance
```

### Common Pitfalls to Avoid

1. **Mutable default arguments**
```python
# WRONG
def add_item(item, items=[]):
    items.append(item)
    return items

# RIGHT
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

2. **Modifying while iterating**
```python
# WRONG
for key in dict:
    if condition:
        del dict[key]  # Error!

# RIGHT
keys_to_delete = [key for key in dict if condition]
for key in keys_to_delete:
    del dict[key]
```

3. **Forgetting JSON limitations**
```python
# JSON doesn't support:
# - Tuples (become lists)
# - Sets (must convert to lists)
# - Complex numbers
# - Custom objects (unless you write custom encoders)
```

4. **Not handling missing keys**
```python
# WRONG
value = nested_dict["level1"]["level2"]  # KeyError if missing!

# RIGHT
value = nested_dict.get("level1", {}).get("level2", default)
```

```python
def explore_structure(data, indent=0):
    prefix = "  " * indent
    if isinstance(data, dict):
        for key, value in data.items():
            print(f"{prefix}{key}: {type(value).__name__}")
            if isinstance(value, (dict, list)):
                explore_structure(value, indent + 1)
    elif isinstance(data, list):
        print(f"{prefix}List with {len(data)} items")
        if data:
            explore_structure(data[0], indent + 1)
```

**Validate structure:**
```python
def validate_nested_structure(data, schema):
    """
    schema example: {
        "name": str,
        "grades": list,
        "contact": {"email": str, "phone": str}
    }
    """
    for key, expected_type in schema.items():
        if key not in data:
            return False, f"Missing key: {key}"
        
        if isinstance(expected_type, dict):
            # Nested validation
            is_valid, msg = validate_nested_structure(data[key], expected_type)
            if not is_valid:
                return False, msg
        elif not isinstance(data[key], expected_type):
            return False, f"Wrong type for {key}"
    
    return True, "Valid"
```
