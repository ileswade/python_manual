### Example 1: Creating a Personalized Calculator Function
**Problem:** Create a function called `calculate_total` that takes a price and a tax rate as parameters, calculates the total with tax, and returns the result. The function should handle edge cases like negative prices or tax rates above 100%.

**Detailed Solution:**

**Step 1: Understand what the function needs to do**
- Take two inputs: price and tax_rate
- Calculate: total = price + (price × tax_rate)
- Validate inputs (no negative prices, tax rate reasonable)
- Return the calculated total

**Step 2: Plan the validation**
- Check if price is negative → return error message
- Check if tax_rate is unreasonable (< 0 or > 1.0) → return error message
- If valid, calculate and return total

**Step 3: Understand the math**
- If price = $100 and tax_rate = 0.08 (8%)
- Tax amount = 100 × 0.08 = $8
- Total = 100 + 8 = $108

**Step 4: Implement with clear logic**

**Complete Solution:**
```python
def calculate_total(price, tax_rate):
    """
    Calculate total price including tax.
    
    Parameters:
        price: The base price (must be non-negative)
        tax_rate: Tax rate as decimal (e.g., 0.08 for 8%)
    
    Returns:
        Total price with tax, or error message string
    """
    # Validate price
    if price < 0:
        return "Error: Price cannot be negative"
    
    # Validate tax rate
    if tax_rate < 0:
        return "Error: Tax rate cannot be negative"
    if tax_rate > 1.0:
        return "Error: Tax rate cannot exceed 100%"
    
    # Calculate total
    tax_amount = price * tax_rate
    total = price + tax_amount
    
    return total


# Test the function
print("=== Price Calculator ===\n")

# Valid inputs
result1 = calculate_total(100, 0.08)
print(f"Price: $100, Tax: 8%")
print(f"Total: ${result1:.2f}\n")

# Edge case: 0% tax
result2 = calculate_total(50, 0)
print(f"Price: $50, Tax: 0%")
print(f"Total: ${result2:.2f}\n")

# Error case: negative price
result3 = calculate_total(-20, 0.08)
print(f"Price: $-20, Tax: 8%")
print(f"Result: {result3}\n")

# Error case: invalid tax rate
result4 = calculate_total(100, 1.5)
print(f"Price: $100, Tax: 150%")
print(f"Result: {result4}")
```

**Output:**
```
=== Price Calculator ===

Price: $100, Tax: 8%
Total: $108.00

Price: $50, Tax: 0%
Total: $50.00

Price: $-20, Tax: 8%
Result: Error: Price cannot be negative

Price: $100, Tax: 150%
Result: Error: Tax rate cannot exceed 100%
```

**Key Concepts:**
- **Input validation**: Check parameters before processing
- **Early returns**: Return error messages immediately when validation fails
- **Docstrings**: Document what the function does
- **Return types**: Can return different types (number or string) based on conditions
- **Edge cases**: Test with 0, negative, and extreme values

**Why this approach works:**
- Validates inputs first, preventing bad calculations
- Returns error messages as strings (alternative: could raise exceptions)
- Clear variable names make the math obvious
- Handles realistic business logic requirements

### Example 2: Temperature Range Checker with Multiple Conditions
**Problem:** Create a function `check_temperature` that takes a temperature in Celsius and returns a string describing the condition: "Freezing" (below 0), "Cold" (0-15), "Comfortable" (16-25), "Warm" (26-35), or "Hot" (above 35). Also create a helper function to convert Fahrenheit to Celsius.

**Detailed Solution:**

**Step 1: Break down the problem**
- Need TWO functions: converter and checker
- Converter: F to C formula: C = (F - 32) × 5/9
- Checker: Return string based on temperature ranges

**Step 2: Plan the range checking logic**
- Use if/elif/else chain
- Check from most specific to least specific
- Return immediately when condition matches

**Step 3: Design the functions**

**Complete Solution:**
```python
def fahrenheit_to_celsius(fahrenheit):
    """Convert Fahrenheit to Celsius."""
    celsius = (fahrenheit - 32) * 5 / 9
    return celsius


def check_temperature(celsius):
    """
    Return temperature description based on Celsius value.
    
    Parameters:
        celsius: Temperature in Celsius
    
    Returns:
        String describing the temperature condition
    """
    if celsius < 0:
        return "Freezing"
    elif celsius <= 15:
        return "Cold"
    elif celsius <= 25:
        return "Comfortable"
    elif celsius <= 35:
        return "Warm"
    else:
        return "Hot"


def check_temperature_fahrenheit(fahrenheit):
    """
    Check temperature given in Fahrenheit.
    Converts to Celsius first, then checks condition.
    """
    celsius = fahrenheit_to_celsius(fahrenheit)
    condition = check_temperature(celsius)
    return condition


# Demonstrate usage
print("=== Temperature Checker ===\n")

# Test Celsius function
temps_c = [-5, 0, 10, 20, 30, 40]

print("Celsius Temperatures:")
for temp in temps_c:
    condition = check_temperature(temp)
    print(f"  {temp}°C: {condition}")

print("\nFahrenheit Temperatures:")
# Test Fahrenheit function
temps_f = [32, 59, 68, 86, 104]

for temp in temps_f:
    celsius = fahrenheit_to_celsius(temp)
    condition = check_temperature_fahrenheit(temp)
    print(f"  {temp}°F ({celsius:.1f}°C): {condition}")

# Interactive example
print("\n--- Temperature Converter ---")
temp_input = float(input("Enter temperature in Fahrenheit: "))
celsius_value = fahrenheit_to_celsius(temp_input)
result = check_temperature(celsius_value)

print(f"{temp_input}°F = {celsius_value:.1f}°C")
print(f"Condition: {result}")
```

**Output:**
```
=== Temperature Checker ===

Celsius Temperatures:
  -5°C: Freezing
  0°C: Cold
  10°C: Cold
  20°C: Comfortable
  30°C: Warm
  40°C: Hot

Fahrenheit Temperatures:
  32°F (0.0°C): Cold
  59°F (15.0°C): Cold
  68°F (20.0°C): Comfortable
  86°F (30.0°C): Warm
  104°F (40.0°C): Hot

--- Temperature Converter ---
Enter temperature in Fahrenheit: 75
75.0°F = 23.9°C
Condition: Comfortable
```

**Key Concepts:**
- **Helper functions**: Small functions that support larger ones
- **Function composition**: One function calls another
- **Range checking**: Use if/elif for ordered conditions
- **Order matters**: Check conditions from specific to general
- **Boundary values**: 0, 15, 25, 35 are on boundaries - decide which category they belong to

**Why this works:**
- Separate concerns: conversion vs checking
- Reusable: Can use converter independently
- Clear boundaries: Each range is well-defined
- The `<=` operator includes the boundary in the lower condition

### Example 3: List Processing with Return Values
**Problem:** Create a function `analyze_numbers` that takes a list of numbers and returns a dictionary containing: count, sum, average, minimum, and maximum. Handle empty lists appropriately. Also create a function `find_outliers` that identifies numbers more than 2 standard deviations from the mean.

**Detailed Solution:**

**Step 1: Understand what we're returning**
- Return a dictionary with multiple statistics
- Need to handle empty list edge case
- Calculate: count, sum, average, min, max

**Step 2: Plan the calculations**
- Count: len(numbers)
- Sum: sum(numbers)
- Average: sum / count
- Min/Max: min(numbers), max(numbers)
- Empty list: return special message or empty dict

**Step 3: Implement with validation**

**Complete Solution:**
```python
def analyze_numbers(numbers):
    """
    Analyze a list of numbers and return statistics.
    
    Parameters:
        numbers: List of numbers
    
    Returns:
        Dictionary with statistics, or None if empty list
    """
    # Handle empty list
    if not numbers:
        return None
    
    # Calculate statistics
    count = len(numbers)
    total = sum(numbers)
    average = total / count
    minimum = min(numbers)
    maximum = max(numbers)
    
    # Create result dictionary
    stats = {
        'count': count,
        'sum': total,
        'average': average,
        'min': minimum,
        'max': maximum,
        'range': maximum - minimum
    }
    
    return stats


def find_outliers(numbers):
    """
    Find numbers that are outliers (far from average).
    An outlier is more than 2 standard deviations from mean.
    
    Parameters:
        numbers: List of numbers
    
    Returns:
        List of outlier values
    """
    if not numbers or len(numbers) < 3:
        return []
    
    # Calculate mean
    mean = sum(numbers) / len(numbers)
    
    # Calculate standard deviation
    squared_diffs = [(x - mean) ** 2 for x in numbers]
    variance = sum(squared_diffs) / len(numbers)
    std_dev = variance ** 0.5
    
    # Find outliers (more than 2 std devs from mean)
    outliers = []
    for num in numbers:
        if abs(num - mean) > 2 * std_dev:
            outliers.append(num)
    
    return outliers


def display_analysis(numbers):
    """Display complete analysis of numbers."""
    print(f"Numbers: {numbers}\n")
    
    # Get basic statistics
    stats = analyze_numbers(numbers)
    
    if stats is None:
        print("Error: Empty list!")
        return
    
    print("=== Statistics ===")
    print(f"Count:   {stats['count']}")
    print(f"Sum:     {stats['sum']}")
    print(f"Average: {stats['average']:.2f}")
    print(f"Minimum: {stats['min']}")
    print(f"Maximum: {stats['max']}")
    print(f"Range:   {stats['range']}")
    
    # Find outliers
    outliers = find_outliers(numbers)
    
    print(f"\n=== Outlier Analysis ===")
    if outliers:
        print(f"Outliers found: {outliers}")
    else:
        print("No outliers detected")


# Test the functions
print("=== Number Analysis System ===\n")

# Test case 1: Normal data
data1 = [10, 12, 15, 14, 13, 11, 16, 12, 14, 15]
display_analysis(data1)

print("\n" + "="*50 + "\n")

# Test case 2: Data with outlier
data2 = [20, 22, 21, 23, 19, 21, 100, 20, 22]
display_analysis(data2)

print("\n" + "="*50 + "\n")

# Test case 3: Empty list
data3 = []
display_analysis(data3)
```

**Output:**
```

=== Statistics ===
Count:   10
Sum:     132
Average: 13.20
Minimum: 10
Maximum: 16

=== Outlier Analysis ===
No outliers detected

==================================================

Numbers: [20, 22, 21, 23, 19, 21, 100, 20, 22]

=== Statistics ===
Count:   9
Sum:     268
Average: 29.78
Minimum: 19
Maximum: 100
Range:   81

=== Outlier Analysis ===
Outliers found: [100]

==================================================

Numbers: []

Error: Empty list!
```

**Key Concepts:**
- **Dictionary returns**: Functions can return complex data structures
- **Multiple statistics**: Calculate several values, return as dict
- **Guard clauses**: Check for empty/invalid input first
- **Mathematical operations**: Standard deviation, variance
- **Function coordination**: Multiple functions working together
- **List comprehension**: `[(x - mean) ** 2 for x in numbers]` creates new list

**Why this approach works:**
- Dictionary return provides organized, labeled results
- Handles edge cases (empty list, too few numbers)
- Clear mathematical logic for outlier detection
- Reusable functions for different datasets
- Display function separates calculation from presentation

## Tips for Solving These Problems

### Function Creation Checklist
```python
# 1. Define function with def keyword
def function_name(parameters):
    
    # 2. Validate inputs (if needed)
    if invalid_condition:
        return error_or_default
    
    # 3. Process/calculate
    result = do_something(parameters)
    
    # 4. Return result (if needed)
    return result
```

### Return vs Print
- **Use return when**: You need the value for further calculations
- **Use print when**: You just want to display information

```python
# Return - value can be used
def add(a, b):
    return a + b

result = add(3, 4) * 2  # Can use the result!

# Print - just shows info
def add_print(a, b):
    print(a + b)

result = add_print(3, 4) * 2  # Error! None * 2
```

### Boolean Return Shortcut
```python
# Long way
def is_even(n):
    if n % 2 == 0:
        return True
    else:
        return False

# Short way (same result!)
def is_even(n):
    return n % 2 == 0
```

### Common Patterns

**Pattern 1: Validation First**
```python
def divide(a, b):
    if b == 0:
        return "Error"
    return a / b
```

**Pattern 2: Build Result, Then Return**
```python
def create_full_name(first, last):
    full_name = first + " " + last
    return full_name
```

**Pattern 3: Process List, Return Result**
```python
def count_positives(numbers):
    count = 0
    for num in numbers:
        if num > 0:
            count += 1
    return count
```

**Pattern 4: Multiple Conditions**
```python
def categorize(value):
    if condition1:
        return "Category A"
    elif condition2:
        return "Category B"
    else:
        return "Category C"
```

### Testing Your Functions
Always test with:
- **Normal inputs**: Expected use cases
- **Edge cases**: Empty lists, zero, boundaries
- **Invalid inputs**: Negative when expecting positive, etc.

```python
def my_function(x):
    # ... function code ...

# Test normal
print(my_function(5))

# Test edge cases
print(my_function(0))
print(my_function(-1))

# Test boundaries
print(my_function(100))
```

### Debugging Tips
1. **Print intermediate values** inside function during development
2. **Test one thing at a time** - simplify complex functions
3. **Check your math** - calculate expected result by hand first
4. **Verify return type** - make sure returning what you expect

### Common Mistakes to Avoid
- **Forgetting to return**: Function returns None
- **Returning inside loop**: Exits too early
- **Not handling edge cases**: Crashes on unexpected input
- **Wrong parameter order**: Arguments passed in wrong sequence
- **Defining after calling**: Function must be defined first
