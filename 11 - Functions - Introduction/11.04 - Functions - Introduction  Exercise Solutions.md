- Return the largest

```python
def find_largest(numbers):
```

### Question 19: Reverse List
**Problem:** Create a function `reverse_list` that takes a list and returns a new list with elements in reverse order (don't use reverse()).

**Solution Approach:**
- Create new empty list
- Loop through original backwards
- Add each element to new list
- Return new list

**Complete Solution:**
```python
def reverse_list(original):
    """Return new list with elements in reverse order."""
    reversed_list = []
    
    # Loop backwards through original
    for i in range(len(original) - 1, -1, -1):
        reversed_list.append(original[i])
    
    return reversed_list

# Alternative using slicing-like logic
def reverse_list_v2(original):
    """Return reversed list using different approach."""
    reversed_list = []
    
    for item in original:
        reversed_list.insert(0, item)  # Insert at beginning
    
    return reversed_list

# Test both versions
list1 = [1, 2, 3, 4, 5]
print(f"Original: {list1}")
print(f"Reversed: {reverse_list(list1)}")
print(f"Reversed v2: {reverse_list_v2(list1)}")

list2 = ["apple", "banana", "cherry"]
print(f"\nOriginal: {list2}")
print(f"Reversed: {reverse_list(list2)}")

# Verify original unchanged
print(f"Original still: {list1}")
```

**Sample Output:**

**Solution Approach:**
- Create new empty list for unique items
- Loop through original
- Only add if not already in new list
- Return new list

**Complete Solution:**
```python
def remove_duplicates(original):
    """Return new list with duplicates removed, order preserved."""
    unique = []
    
    for item in original:
        if item not in unique:

    return unique
```

### Question 21: Palindrome Number
**Problem:** Create a function `is_palindrome_number` that checks if a number reads the same forwards and backwards (e.g., 121, 1331).

**Solution Approach:**
- Convert number to string
- Reverse the string
- Compare original to reversed
- Return True if same

**Complete Solution:**
```python
def is_palindrome_number(number):
    """Return True if number is palindrome."""
    # Convert to string
    num_str = str(number)
    
    # Reverse the string
    reversed_str = num_str[::-1]
    
    # Compare
    return num_str == reversed_str

# Test the function
test_numbers = [121, 1331, 123, 1221, 12321, 100, 0, 7]

print("=== Palindrome Number Checker ===\n")

for num in test_numbers:
    result = is_palindrome_number(num)

    print(f"{num}: {status}")
```

**Problem:** Write a function `fibonacci` that takes n and returns the nth Fibonacci number (0, 1, 1, 2, 3, 5, 8...).

**Solution Approach:**
- First two numbers are 0 and 1
- Each subsequent number is sum of previous two
- Use variables to track previous two numbers
- Return the nth number

**Complete Solution:**
```python
def fibonacci(n):
    """Return nth Fibonacci number (0-indexed)."""
    # Handle first two cases
    if n == 0:
        return 0
    if n == 1:
        return 1
    
    # Calculate nth Fibonacci number
    prev2 = 0  # fib(0)
    prev1 = 1  # fib(1)
    
    for i in range(2, n + 1):
        current = prev1 + prev2
        prev2 = prev1
        prev1 = current
    
    return prev1
```

### Question 25: Prime Factors
**Problem:** Create a function `prime_factors` that takes a number and returns a list of its prime factors. For example, 12 → [2, 2, 3].

**Solution Approach:**
- Start with smallest prime (2)
- Divide number by factor while divisible
- Add factor to list each time
- Move to next potential factor
- Continue until number becomes 1

**Complete Solution:**
```python
def prime_factors(n):
    """Return list of prime factors of n."""
    if n < 2:
        return []
    
    factors = []
    factor = 2
    
    # Try each potential factor
    while n > 1:
        # Divide by factor while possible
        while n % factor == 0:
            factors.append(factor)
            n = n // factor
        
        # Move to next potential factor
        factor += 1
        
        # Optimization: if factor squared > n, n is prime
        if factor * factor > n and n > 1:
            factors.append(n)
            break
    
    return factors

# Helper function to display factorization
def show_factorization(n):
    """Display prime factorization."""
    factors = prime_factors(n)
    
    if not factors:
        print(f"{n}: No prime factors (less than 2)")
        return
    
    # Create multiplication string
    factor_str = ' × '.join(map(str, factors))
    print(f"{n} = {factor_str}")

# Test the function
print("=== Prime Factorization ===\n")

test_numbers = [12, 30, 17, 100, 97, 56, 1, 0, 2]

for num in test_numbers:
    show_factorization(num)

    elif len(factors) > 1:

                 for p, c in unique.items()]
        print(f"Factorization: {n} = {' × '.join(parts)}")
```

### Essential Concepts Reinforced

1. **Function Definition Order**
   - Always define functions before calling them
   - Python reads top to bottom
   - Defining doesn't execute the code inside

2. **Parameters vs Arguments**
   - Parameters: placeholders in definition
   - Arguments: actual values passed when calling
   - Order matters when passing arguments

3. **Return vs Print**
   - return: sends value back to caller
   - print: displays on screen, returns None
   - Use return when value needed for calculations

4. **Boolean Returns**
   - Can return comparison directly: `return x > 0`
   - No need for if/else when returning boolean
   - More concise and Pythonic

5. **Edge Cases**
   - Empty lists/strings
   - Negative numbers when expecting positive
   - Zero as boundary value
   - Very large or very small inputs

6. **List Processing**
   - Counter pattern for counting
   - Accumulator pattern for summing
   - Build new list pattern for filtering/transforming
   - Don't modify list while iterating

7. **Input Validation**
   - Check for invalid input first
   - Return error message or default value
   - Prevents crashes and unexpected behavior

8. **Function Composition**
   - Functions can call other functions
   - Break complex problems into smaller functions
   - Each function should do one thing well

### Common Mistakes and How to Avoid Them

**Mistake 1: Forgetting to return**
```python
# Wrong - returns None
def add(a, b):
    a + b  # Calculation but no return!

# Right - returns the sum
def add(a, b):
    return a + b
```

**Mistake 2: Returning in a loop too early**
```python
# Wrong - returns after first iteration
def has_even(numbers):
    for num in numbers:
        if num % 2 == 0:
            return True
        return False  # Wrong! Exits after first number

# Right - check all numbers
def has_even(numbers):
    for num in numbers:
        if num % 2 == 0:
            return True
    return False  # Only if no evens found
```

**Mistake 3: Modifying list while iterating**
```python
# Wrong - unpredictable behavior
def remove_odds(numbers):
    for num in numbers:
        if num % 2 == 1:
            numbers.remove(num)  # Modifying while iterating!

# Right - create new list
def remove_odds(numbers):
    evens = []
    for num in numbers:
        if num % 2 == 0:
            evens.append(num)
    return evens
```

**Mistake 4: Not handling edge cases**
```python
# Wrong - crashes on empty list
def find_max(numbers):
    maximum = numbers[0]  # IndexError if empty!
    for num in numbers:
        if num > maximum:
            maximum = num
    return maximum

# Right - check for empty list
def find_max(numbers):
    if not numbers:
        return None
    maximum = numbers[0]
    for num in numbers:
        if num > maximum:
            maximum = num
    return maximum
```

**Mistake 5: Using = instead of == in conditions**
```python
# Wrong - assignment, not comparison
def is_ten(num):
    if num = 10:  # SyntaxError!
        return True

# Right - comparison
def is_ten(num):
    return num == 10
```
