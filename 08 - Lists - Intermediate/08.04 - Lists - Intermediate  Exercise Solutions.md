## Mutability and References (Questions 1-5)

### Question 1
**Problem:** Create a list of numbers. Make two variables point to it using assignment. Modify the list through one variable and print both. Explain what you observe.

**Solution Approach:**
- Create one list with numbers
- Use assignment (=) to create second variable
- Modify through one variable
- Both variables show the change (they point to same list)

**Complete Solution:**
```python
# Create a list
numbers = [10, 20, 30, 40, 50]
print(f"Original list: {numbers}")

# Create a reference (not a copy!)
numbers_ref = numbers

print(f"numbers ID: {id(numbers)}")
print(f"numbers_ref ID: {id(numbers_ref)}")
print(f"Same object? {id(numbers) == id(numbers_ref)}")

# Modify through the reference
numbers_ref[0] = 999

# Print both
print(f"\nAfter modifying numbers_ref[0] = 999:")
print(f"numbers: {numbers}")
print(f"numbers_ref: {numbers_ref}")
```

**Output:**
```
Original list: [10, 20, 30, 40, 50]
numbers ID: 140234567891234
numbers_ref ID: 140234567891234
Same object? True

After modifying numbers_ref[0] = 999:
numbers: [999, 20, 30, 40, 50]
numbers_ref: [999, 20, 30, 40, 50]
```

**Key Concepts:**
- Assignment creates a reference, not a copy
- Both variables point to same memory location (same id)
- Modifying through either variable affects both
- This is Python's default behavior for efficiency

### Question 3
**Problem:** Write a function that takes a list and accidentally modifies it (showing the reference problem). Then fix it using .copy().

**Solution Approach:**
- Create function that modifies list parameter
- Show how it affects original (reference problem)
- Fix by having function work on a copy
- Demonstrate the difference

**Complete Solution:**
```python
# WRONG: Function that accidentally modifies original
def double_values_wrong(numbers):
    """Double all values - MODIFIES ORIGINAL!"""
    for i in range(len(numbers)):
        numbers[i] = numbers[i] * 2
    return numbers

# CORRECT: Function that doesn't modify original
def double_values_correct(numbers):
    """Double all values - PRESERVES ORIGINAL"""
    numbers_copy = numbers.copy()
    for i in range(len(numbers_copy)):
        numbers_copy[i] = numbers_copy[i] * 2
    return numbers_copy

# Test the wrong version
print("=== WRONG VERSION ===")
original = [1, 2, 3, 4, 5]
print(f"Before: {original}")

result = double_values_wrong(original)
print(f"Result: {result}")
print(f"Original: {original}")  # Oops! Changed!
print("Problem: Original was modified!\n")

# Test the correct version
print("=== CORRECT VERSION ===")
original = [1, 2, 3, 4, 5]
print(f"Before: {original}")

result = double_values_correct(original)
print(f"Result: {result}")
print(f"Original: {original}")  # Safe! Unchanged
print("Success: Original preserved!")
```

**Output:**
```
=== WRONG VERSION ===
Before: [1, 2, 3, 4, 5]
Result: [2, 4, 6, 8, 10]
Original: [2, 4, 6, 8, 10]
Problem: Original was modified!

=== CORRECT VERSION ===
Before: [1, 2, 3, 4, 5]
Result: [2, 4, 6, 8, 10]
Original: [1, 2, 3, 4, 5]
Success: Original preserved!
```

**Key Concepts:**
- Functions receive references to lists, not copies
- Modifying parameter modifies the original
- Use .copy() inside function to work on independent copy
- Caller's data is protected when function uses copy

### Question 4
**Problem:** Create a list of lists (nested). Make a shallow copy with .copy(). Modify an inner list and discover that shallow copy doesn't protect nested structures.

**Solution Approach:**
- Create nested list (list containing lists)
- Use .copy() to make shallow copy
- Modify an inner list
- Discover both are affected (shallow copy limitation)

**Complete Solution:**
```python
# Create nested list
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
print(f"Original: {matrix}")

# Make shallow copy
matrix_copy = matrix.copy()

# Check outer list IDs
print(f"\nOuter list IDs:")
print(f"Original ID: {id(matrix)}")
print(f"Copy ID: {id(matrix_copy)}")
print(f"Different outer lists? {id(matrix) != id(matrix_copy)}")

# Check inner list IDs (the problem!)
print(f"\nInner list IDs:")
print(f"Original[0] ID: {id(matrix[0])}")
print(f"Copy[0] ID: {id(matrix_copy[0])}")
print(f"Same inner list? {id(matrix[0]) == id(matrix_copy[0])}")

# Modify inner list through copy
matrix_copy[0][0] = 999

# Both are affected!
print(f"\nAfter modifying matrix_copy[0][0] = 999:")
print(f"Original: {matrix}")
print(f"Copy: {matrix_copy}")
print("\nProblem: Shallow copy only copies outer list!")
print("Inner lists are still references!")

# Solution: Deep copy
import copy
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
matrix_deep = copy.deepcopy(matrix)

matrix_deep[0][0] = 999

print(f"\n=== Using Deep Copy ===")
print(f"Original: {matrix}")
print(f"Deep copy: {matrix_deep}")
print("Success: Deep copy protects nested structures!")
```

**Output:**
```
Original: [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

Outer list IDs:
Original ID: 140234567891234
Copy ID: 140234567898765
Different outer lists? True

Inner list IDs:
Original[0] ID: 140234567801234
Copy[0] ID: 140234567801234
Same inner list? True

After modifying matrix_copy[0][0] = 999:
Original: [[999, 2, 3], [4, 5, 6], [7, 8, 9]]
Copy: [[999, 2, 3], [4, 5, 6], [7, 8, 9]]

Problem: Shallow copy only copies outer list!
Inner lists are still references!

=== Using Deep Copy ===
Original: [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
Deep copy: [[999, 2, 3], [4, 5, 6], [7, 8, 9]]
Success: Deep copy protects nested structures!
```

**Key Concepts:**
- .copy() is a shallow copy - only copies outer container
- Inner lists are still references (same objects)
- For nested structures, use copy.deepcopy()
- Shallow copy: new outer list, same inner lists
- Deep copy: everything is independent

### Question 13
**Problem:** Write code that safely removes an item from a list, checking if it exists first to avoid ValueError.

**Solution Approach:**
- Check if item exists using `in` operator
- Only call remove() if item exists
- Handle case where item doesn't exist gracefully

**Complete Solution:**
```python
def safe_remove(lst, item):
    """Safely remove item from list."""
    if item in lst:
        lst.remove(item)
        print(f"Removed '{item}' from list")
        return True
    else:
        print(f"'{item}' not in list - no action taken")
        return False

# Test the function
fruits = ["apple", "banana", "cherry", "date"]
print(f"Starting list: {fruits}\n")

# Remove existing item
safe_remove(fruits, "banana")
print(f"List: {fruits}\n")

# Try to remove non-existent item
safe_remove(fruits, "grape")
print(f"List: {fruits}\n")

# Remove another existing item
safe_remove(fruits, "cherry")
print(f"List: {fruits}")
```

**Alternative with try-except:**
```python
def safe_remove_alt(lst, item):
    """Safely remove using try-except."""
    try:
        lst.remove(item)
        print(f"Removed '{item}'")
        return True
    except ValueError:
        print(f"'{item}' not found")
        return False
```

**Output:**
```
Starting list: ['apple', 'banana', 'cherry', 'date']

Removed 'banana' from list
List: ['apple', 'cherry', 'date']

'grape' not in list - no action taken
List: ['apple', 'cherry', 'date']

Removed 'cherry' from list
List: ['apple', 'date']
```

**Key Concepts:**
- Check existence before remove() to avoid ValueError
- `if item in list:` is cleaner than try-except for this
- Function returns True/False to indicate success
- Provides user-friendly feedback

### Question 14
**Problem:** Use del to remove items at indices 1, 3, and 5 from a list (be careful about changing indices!).

**Solution Approach:**
- Start with list of at least 6 items
- Remove indices in reverse order (5, 3, 1)
- This prevents index shifting problems

**Complete Solution:**
```python
# Create list
letters = ['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
print(f"Starting list: {letters}")
print("Goal: Remove indices 1, 3, 5\n")

# WRONG WAY: Remove from left to right
wrong_list = letters.copy()
print("--- Wrong approach (left to right) ---")
print(f"Start: {wrong_list}")

del wrong_list[1]  # Removes 'B'
print(f"After del[1]: {wrong_list}")  # ['A', 'C', 'D', 'E', 'F', 'G', 'H']

del wrong_list[3]  # We want to remove original index 3 ('D')
                   # But now 'E' is at index 3!
print(f"After del[3]: {wrong_list}")  # Removed 'E' instead!

# This is wrong!

# RIGHT WAY: Remove from right to left
correct_list = letters.copy()
print("\n--- Correct approach (right to left) ---")
print(f"Start: {correct_list}")

# Remove index 5 first
del correct_list[5]  # Removes 'F'
print(f"After del[5]: {correct_list}")

# Remove index 3
del correct_list[3]  # Removes 'D'
print(f"After del[3]: {correct_list}")

# Remove index 1
del correct_list[1]  # Removes 'B'
print(f"After del[1]: {correct_list}")

print(f"\nFinal result: {correct_list}")
print("Successfully removed items at original indices 1, 3, 5")
```

**Output:**
```
Starting list: ['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
Goal: Remove indices 1, 3, 5
```

## Summary: Key List Manipulation Patterns

### Reference vs Copy
```python
# Reference (same object)
b = a

# Copy (independent object)
b = a.copy()
```

### Adding Elements
```python
lst.append(item)          # Add to end
lst.insert(index, item)   # Add at position
lst.extend(other_list)    # Add multiple
new = lst1 + lst2         # Concatenate (new list)
```

### Removing Elements
```python
lst.remove(value)         # Remove first occurrence
item = lst.pop(index)     # Remove and return
del lst[index]            # Delete by index
lst.clear()               # Empty the list
```

### Slicing
```python
lst[start:stop:step]      # General form
lst[:n]                   # First n
lst[-n:]                  # Last n
lst[::2]                  # Every 2nd
lst[::-1]                 # Reverse
```

### Sorting
```python
lst.sort()                # Modify in place
new = sorted(lst)         # Return new sorted list
lst.reverse()             # Reverse in place
new = lst[::-1]           # Return reversed copy
```
