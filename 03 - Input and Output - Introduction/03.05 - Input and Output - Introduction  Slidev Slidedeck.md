# The Print Statement 📤

The `print()` function displays information on the screen. It's the most common way to show output to users.

<v-clicks>

### Basic Print with Strings

```python
print("Hello, World!")
print('Hello, World!')
```

Both single and double quotes work the same way!

### Why Have Both Quote Types?

Having both allows you to include quotes inside strings:

```python
print("She said, 'Hello!'")        # Double outside, single inside
print('He said, "Good morning!"')  # Single outside, double inside

# Without this flexibility:
print("She said, "Hello!"")  # ❌ ERROR! Python gets confused
```

</v-clicks>

---

# Printing Numbers and Variables 📊

<v-clicks>

### Printing Numbers Directly

```python
print(42)
print(3.14159)
print(100 + 50)  # Prints: 150
```

### Printing Variables

```python
name = "Alice"
age = 25
price = 19.99

print(name)    # Alice
print(age)     # 25
print(price)   # 19.99
```

</v-clicks>

<v-click>

**Key Point:** `print()` automatically converts most data types to strings for display!

</v-click>

# Method 1: Concatenation with + ➕

You can "glue" strings together using the `+` operator:

<v-clicks>

```python
name = "Bob"
message = "Hello, " + name + "!"
print(message)  # Hello, Bob!

# All in one line
print("Hello, " + name + "!")
```

**IMPORTANT LIMITATION:** You can only concatenate strings with strings!

```python
age = 25
print("Age: " + age)  # ❌ ERROR! Can't concatenate string and integer
```

To fix this, convert the number to a string:

```python
age = 25
print("Age: " + str(age))  # ✅ Age: 25
```

</v-clicks>

---

# Method 2: Using Commas 🔗

You can separate values with commas in a print statement:

<v-clicks>

```python
name = "Alice"
age = 25
print("Name:", name, "Age:", age)  # Name: Alice Age: 25
```

**Key Advantages of Commas:**
- Automatically convert values to strings (no need for `str()`)
- Add spaces between items automatically

```python
# With comma - NO casting needed!
age = 25
print("Age:", age)  # Age: 25

# Compare to concatenation - casting required
print("Age: " + str(age))  # Age: 25
```

</v-clicks>

<v-click>

**When to use:** Quick and dirty output, debugging, when you want automatic spacing

</v-click>

---

# Method 3: F-Strings (Recommended!) 🚀

**F-strings** (formatted string literals) are the modern, preferred way to format output in Python.

<v-clicks>

Add an `f` before the opening quote, then put variables inside `{}`:

```python
name = "Alice"
age = 25
print(f"Name: {name}, Age: {age}")  # Name: Alice, Age: 25
```

**Why f-strings are better:**

1. **No casting needed** - works with any data type
2. **Much more readable** - no confusing quotes and + signs
3. **Can include expressions** - do calculations right inside

```python
# No casting needed
name = "Bob"
age = 30
height = 5.9
print(f"{name} is {age} years old and {height} feet tall")

# Expressions inside f-strings
price = 19.99
quantity = 3
print(f"Total: ${price * quantity}")  # Total: $59.97
```

</v-clicks>

---

# F-String Power Examples 💪

F-strings can do calculations and formatting right inside the braces:

<v-clicks>

```python
# Mathematical expressions
width = 10
height = 5
print(f"Area: {width * height} square feet")  # Area: 50 square feet

# Multiple variables and calculations
price = 29.99
tax_rate = 0.08
total = price + (price * tax_rate)
print(f"Price: ${price}, Tax: ${price * tax_rate:.2f}, Total: ${total:.2f}")

# Conditional expressions (preview of coming chapters!)
score = 85
print(f"Grade: {score} ({'Pass' if score >= 60 else 'Fail'})")
```

</v-clicks>

<v-click>

**Notice:** `:.2f` formats floats to 2 decimal places - there's much more formatting power available!

</v-click>

# Comparison of All Three Methods 📊

Let's see the same output using all three approaches:

<v-clicks>

```python
name = "Charlie"
age = 28

# Method 1: Concatenation - requires str(), lots of quotes
print("Hello " + name + ", you are " + str(age) + " years old")

# Method 2: Commas - automatic conversion, adds spaces
print("Hello", name + ", you are", age, "years old")

# Method 3: F-string - cleanest and most readable!
print(f"Hello {name}, you are {age} years old")
```

**All produce:** `Hello Charlie, you are 28 years old`

</v-clicks>

<v-click>

<div class="mt-4 p-4 bg-green-100 dark:bg-green-900 rounded">
🏆 <strong>Winner:</strong> F-strings are the modern standard - use them whenever possible!
</div>

</v-click>

# Escape Characters (Bonus) 🔤

Special characters in strings that start with `\` have special meanings:

<v-clicks>

```python
print("Line 1\nLine 2")    # \n = newline
print("Hello\tWorld")      # \t = tab
print("She said \"Hi\"")   # \" = quote inside quotes
print("C:\\Users\\Name")   # \\ = actual backslash
```

**Output:**
```
Line 1
Line 2
Hello	World
She said "Hi"
C:\Users\Name
```

</v-clicks>

<v-click>

We won't use these much right now, but it's good to know they exist when you see them in code!

</v-click>

# Getting Input from Users 📥

The `input()` function allows users to type information into your program.

<v-clicks>

### Basic Input

```python
name = input()
print(f"Hello, {name}!")
```

**Process:**
1. Program waits for user to type something
2. User types input and presses Enter
3. Whatever they typed gets stored in the variable

</v-clicks>

<v-click>

### Input with a Prompt (Better!)

```python
name = input("Enter your name: ")
age = input("Enter your age: ")
```

This is much cleaner than:
```python
print("Enter your name: ")
name = input()
```

</v-click>

---

# 🚨 CRITICAL CONCEPT: Input Always Returns a String

<div class="text-center text-2xl mb-6">
⚠️ **This is extremely important:** No matter what the user types, `input()` ALWAYS gives you a string!
</div>

<v-clicks>

```python
age = input("Enter your age: ")  # User types: 25
print(type(age))  # <class 'str'> - it's STRING "25", not number 25!
```

**Why does this matter?** If you want to do math, you MUST convert it:

```python
# ❌ WRONG - will cause an error!
age = input("Enter your age: ")  # User types: 25 (stored as "25")
next_year = age + 1              # ERROR! Can't add string and number

# ✅ CORRECT - convert to integer first
age = input("Enter your age: ")  # User types: 25
age = int(age)                   # Convert "25" to 25
next_year = age + 1              # Now this works! 26
```

</v-clicks>

---

# Casting Input: Converting User Data 🔄

Since `input()` always returns a string, you often need to cast it:

<v-clicks>

```python
# Method 1: Two steps
age = input("Enter your age: ")
age = int(age)  # Convert string to integer

# Method 2: One line (nested casting)
age = int(input("Enter your age: "))

# For decimal numbers
height = float(input("Enter your height in meters: "))

# For text (no conversion needed)
name = input("Enter your name: ")  # Already a string
```

</v-clicks>

<v-click>

**Best Practice:** Use the one-line method when you're sure about the data type:
```python
age = int(input("Enter your age: "))
price = float(input("Enter price: "))
name = input("Enter name: ")  # No casting needed
```

</v-click>

---

# ⚠️ WARNING: Input Casting Can Crash Your Program!

When you cast user input, you're assuming users will enter the right type. **If they don't, your program will crash!**

<v-clicks>

```python
age = int(input("Enter your age: "))
# If user types "twenty" instead of "20" → CRASH!
# If user types "20.5" instead of "20" → CRASH!
```

**Why does this happen?**

```python
int("20")      # ✅ Works! Returns 20
int("20.5")    # ❌ CRASH! Can't convert decimal string to int
int("hello")   # ❌ CRASH! Can't convert word to int

float("20.5")  # ✅ Works! Returns 20.5
float("20")    # ✅ Works! Returns 20.0
float("hello") # ❌ CRASH! Can't convert word to float
```

</v-clicks>

# Putting It Together: Calculator Example 🧮

Let's build a simple calculator that demonstrates input, output, and type conversion:

<v-clicks>

```python
# Get two numbers from the user
print("=== Simple Calculator ===")
num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))

# Perform all basic operations
addition = num1 + num2
subtraction = num1 - num2
multiplication = num1 * num2
division = num1 / num2
floor_division = num1 // num2
modulus = num1 % num2
exponent = num1 ** num2

# Display results using f-strings
print(f"\n=== Results ===")
print(f"{num1} + {num2} = {addition}")
print(f"{num1} - {num2} = {subtraction}")
print(f"{num1} * {num2} = {multiplication}")
print(f"{num1} / {num2} = {division}")
print(f"{num1} // {num2} = {floor_division}")
print(f"{num1} % {num2} = {modulus}")
print(f"{num1} ** {num2} = {exponent}")
```

</v-clicks>
