# ⚠️ White Space Matters in Python!

<div class="text-center text-xl mb-6">
🚨 **This is crucial:** Python is a **white space dependent** language!
</div>

<v-clicks>

### What Does This Mean?

In many languages, indentation is just for looks. In Python, **indentation is part of the syntax** - it's how Python understands which code belongs together.

```python
# ✅ CORRECT - no indentation at the start
name = "Alice"
age = 20

# ❌ WRONG - random space at the beginning
 name = "Bob"  # This will cause an error!
```

</v-clicks>

<v-click>

**Code Blocks:** When you indent code, you create a **code block** - related statements that belong together.

**For now:** Don't randomly add spaces or tabs at the beginning of lines!

</v-click>

# Variables: Containers for Data 📦

Variables are labeled boxes where you can store information.

<v-clicks>

### Creating Variables

```python
age = 25
name = "Sarah"
price = 19.99
is_student = True
```

### Key Points About Variables

- **No declaration needed** - just assign a value
- **Dynamic typing** - can change types during execution
- **Meaningful names** - make your code readable
- **Case sensitive** - `age` and `Age` are different variables

</v-clicks>

# Python Naming Conventions 🏷️

Python has specific rules for naming variables that help keep code consistent and readable.

<div class="grid grid-cols-2 gap-6">

<div>

<v-click>

### ✅ Good Variable Names

```python
# Use snake_case for variables
student_name = "John"
total_price = 99.99
is_logged_in = True
user_age = 30

# Use UPPERCASE for constants
MAX_STUDENTS = 30
PI = 3.14159
TAX_RATE = 0.05
```

</v-click>

</div>

<div>

<v-click>

### ❌ Poor Variable Names

```python
# Too vague
x = "John"           # What is x?
n = "John"           # Not descriptive
a = 25               # What does 'a' represent?

# Wrong case style
studentName = "Bob"  # This is camelCase
StudentName = "Sue"  # This is PascalCase
```

</v-click>

</div>

</div>

<v-click>

**Remember:** For Python, use **snake_case** for variables and **UPPERCASE** for constants!

</v-click>

# Comments: Notes for Humans 📝

Comments are lines Python ignores - they're notes for humans (including future you!).

<v-clicks>

### Single-Line Comments

```python
# This is a comment
age = 25  # This is also a comment

# Calculate the area of a rectangle
width = 10
height = 5
area = width * height  # area = 50
```

### When to Use Comments
- Explain **what** a section does
- Note **why** you made certain choices
- Temporarily disable code while testing

</v-clicks>

# Multi-Line Comments & Docstrings

<div class="grid grid-cols-2 gap-6">

<div>

<v-click>

### Multi-Line Comments

```python
# This is a longer comment
# that spans multiple lines
# to explain something complex

```

</v-click>

</div>

<div>

<v-click>

### Docstrings (Professional Documentation)

```python
"""
This is a docstring.
It can span multiple lines.
Used for professional documentation.

    Calculate the area of a rectangle.

    Args:
        width: Rectangle width
```

# Comment Best Practices 💡

<v-clicks>

```python
# ✅ GOOD: Explains WHY
# Use floor division because we can't have partial students
students_per_group = total_students // num_groups

# ❌ BAD: Just repeats what the code says
# Divide total_students by num_groups
students_per_group = total_students // num_groups

# ✅ GOOD: Clarifies complex logic
# Check if user is eligible: must be 18+ AND have valid ID
if age >= 18 and has_valid_id:
    print("Access granted")
```

</v-clicks>

<v-click>

<div class="mt-6 p-4 bg-yellow-100 dark:bg-yellow-900 rounded">
💡 <strong>Remember:</strong> Comments should explain <em>why</em> you're doing something, not just <em>what</em> the code does. Good code should be readable enough that the "what" is obvious.
</div>

</v-click>

# Keywords: Python's Reserved Words 🔒

Python has special **keywords** that have specific meanings - you **cannot** use these as variable names.

<v-clicks>

### Common Keywords

```text
for    if      while   def     class   return
in     and     or      not     True    False
import from    as      try     except  finally
```

### How to Recognize Keywords

- Most code editors **color keywords differently**
- Try typing `for` in VS Code - notice the special color
- Try typing `apple` - different color = not a keyword

</v-clicks>

<v-click>

```python
for = 5   # ❌ ERROR! 'for' is a keyword
if = 10   # ❌ ERROR! 'if' is a keyword
apple = 5 # ✅ OK! 'apple' is not a keyword
```

**Don't memorize them all!** Your editor will warn you with colors.

</v-click>

# Dynamic Typing: Variables Can Change! 🔄

**Important:** Python variables can change type! The same variable can hold different types at different times.

<v-clicks>

```python
x = 5           # x is an integer
print(x)        # 5
print(type(x))  # <class 'int'>

x = "hello"     # now x is a string
print(x)        # hello
print(type(x))  # <class 'str'>

x = 3.14        # now x is a float
print(x)        # 3.14
print(type(x))  # <class 'float'>
```

</v-clicks>

<v-click>

<div class="mt-4 p-4 bg-blue-100 dark:bg-blue-900 rounded">
⚡ <strong>Dynamic Typing:</strong> The type can change as the program runs. This is flexible but requires you to be careful!
</div>

</v-click>

# Checking Variable Types 🔍

You can check what type a variable is using the `type()` function:

<v-clicks>

```python
age = 25
print(type(age))          # <class 'int'>

price = 19.99
print(type(price))        # <class 'float'>

name = "Bob"
print(type(name))         # <class 'str'>

is_student = True
print(type(is_student))   # <class 'bool'>
```

</v-clicks>

<v-click>

**When is this useful?**
- Debugging when variables aren't behaving as expected
- Understanding what type of data you're working with
- Later: validating user input and preventing errors

</v-click>

# Basic Math Operations 🧮

Python can perform mathematical calculations using standard operators.

<div class="grid grid-cols-2 gap-6">

<div>

<v-clicks>

### Basic Operators

```python
# Addition
result = 5 + 3        # 8

# Subtraction
result = 10 - 4       # 6

# Multiplication
result = 6 * 7        # 42

# Division (always gives float)
result = 15 / 3       # 5.0
result = 10 / 4       # 2.5
```

</v-clicks>

</div>

<div>

<v-clicks>

### Special Operators

```python
# Floor Division (rounds down)
result = 10 // 3      # 3
result = 15 // 4      # 3

# Modulus (remainder)
result = 10 % 3       # 1
result = 17 % 5       # 2

# Exponent (power)
result = 2 ** 3       # 8 (2³)
result = 5 ** 2       # 25 (5²)
```

</v-clicks>

# Using Variables in Calculations 📊

<v-clicks>

```python
# Basic calculation with variables
price = 100
tax_rate = 0.07
tax = price * tax_rate       # 7.0
total = price + tax          # 107.0

width = 10
height = 5
area = width * height        # 50

# Updating variables
count = 5
count = count + 1            # 6

# Shorthand for updating
count += 1    # Same as: count = count + 1
count -= 2    # Same as: count = count - 2
count *= 3    # Same as: count = count * 3
count /= 2    # Same as: count = count / 2
```

</v-clicks>

# Order of Operations (PEMDAS) 📐

Python follows standard mathematical order of operations:

<v-clicks>

1. **P**arentheses
2. **E**xponents
3. **M**ultiplication and **D**ivision (left to right)
4. **A**ddition and **S**ubtraction (left to right)

```python
result = 5 + 3 * 2          # 11 (multiplication first)
result = (5 + 3) * 2        # 16 (parentheses first)
result = 10 / 2 + 3         # 8.0 (division first)
result = 2 ** 3 + 5         # 13 (exponent first)
```

</v-clicks>

<v-click>

<div class="mt-4 p-4 bg-yellow-100 dark:bg-yellow-900 rounded">
💡 <strong>Pro Tip:</strong> When in doubt, use parentheses to make your intentions clear!
</div>

</v-click>

# Type Casting: Converting Between Types 🔄

Sometimes you need to convert a value from one type to another. This is called **type casting** or **type conversion**.

<div class="grid grid-cols-2 gap-6">

<div>

<v-click>

### Casting Functions

```python
# String to Integer
age_str = "25"
age_int = int(age_str)      # 25

# String to Float
price_str = "19.99"
price_float = float(price_str)  # 19.99

# Integer to String
age = 25
age_str = str(age)          # "25"
```

</v-click>

</div>

<div>

<v-click>

### More Casting Examples

```python
# Float to Integer (loses decimal!)
price = 19.99
price_int = int(price)      # 19

# Integer to Float
age = 25
age_float = float(age)      # 25.0

# Boolean conversions
bool(1)      # True
bool(0)      # False
bool("hi")   # True
bool("")     # False
```

</v-click>

</div>

</div>

---

# ⚠️ Lossy Conversions

**Be careful!** Some conversions lose data - this is called a **lossy conversion**:

<v-clicks>

```python
# Float to Integer - LOSES decimal places
price = 19.99
price_int = int(price)     # 19 (lost the .99!)

score = 87.8
score_int = int(score)     # 87 (lost the .8!)

# This is NOT rounding - it just cuts off the decimal
value = 9.9
value_int = int(value)     # 9 (not 10!)
```

</v-clicks>

<v-click>

<div class="mt-4 p-4 bg-red-100 dark:bg-red-900 rounded">
⚠️ <strong>Warning:</strong> <code>int()</code> truncates (cuts off) decimals - it doesn't round! <code>int(9.9)</code> gives <code>9</code>, not <code>10</code>.
</div>

</v-click>

---

# Implicit (Automatic) Casting ⚡

Sometimes Python automatically converts types for you:

<v-clicks>

```python
# Integer + Float = Float
result = 5 + 2.5           # 7.5 (Python converts 5 to 5.0)

# Division always returns Float
result = 10 / 2            # 5.0 (not 5!)

# Mixing types in calculation
x = 10        # integer
y = 3.5       # float
z = x * y     # 35.0 (Python converts x to float)
```

</v-clicks>

<v-click>

**Key Point:** Python tries to be helpful by automatically converting types when it makes sense, but you should still be aware of what types you're working with!

</v-click>

# When Do You Need to Cast? 🤔

You'll often need to cast in these situations:

<v-clicks>

### 1. Getting User Input
```python
age = input("Enter age: ")     # age is string "25"
age = int(age)                 # now age is integer 25
# Or in one line:
age = int(input("Enter age: "))
```

### 2. Combining Different Types
```python
age = 25
message = "You are " + str(age) + " years old"
# Must convert age to string to concatenate
```

### 3. Performing Calculations
```python
num1 = input("Enter first number: ")
num2 = input("Enter second number: ")
total = int(num1) + int(num2)  # Must convert to do math
```

</v-clicks>

# Putting It All Together: Examples 🚀

<v-clicks>

### Example 1: Basic Calculations

```python
# Calculate area of a rectangle
width = 10
height = 5
area = width * height
print(f"Area: {area}")  # Using f-string for output

# Calculate with floats
price = 19.99
quantity = 3

print(f"Total: ${total}")
```

### Example 2: Working with Different Types

```python
# Mix different types
name = "Alice"
age = 25
is_student = True

print(f"Name: {name} (type: {type(name).__name__})")
print(f"Age: {age} (type: {type(age).__name__})")
print(f"Student: {is_student} (type: {type(is_student).__name__})")
```

</v-clicks>

# Example 3: Type Conversion in Action

<v-clicks>

```python
# Simulating user input (normally from input())
age_input = "25"
years_until_30 = 30 - int(age_input)
print(f"Years until 30: {years_until_30}")

# Converting for different operations
score = 87.5
score_int = int(score)              # 87 (truncated)
score_str = str(score)              # "87.5"

print(f"Original: {score} (type: {type(score).__name__})")
print(f"As int: {score_int} (type: {type(score_int).__name__})")
print(f"As string: {score_str} (type: {type(score_str).__name__})")
```

</v-clicks>

<v-click>

**Notice:** We're using `type().__name__` to get a cleaner type name for display!

</v-click>
